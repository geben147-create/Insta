## 편집 기법
- 딥 투 블랙(짧은 암전)으로 장소·시간 점프: FFmpeg: 앞 컷 끝에 fade=t=out:d=0.4:color=black, 다음 컷 시작에 fade=t=in:d=0.4 (HyperFrames면 0.4초 블랙 트랜지션)
- 화면 속 화면 인서트(욕망 대상 실물 제시): 생성: 러그 위 태블릿 탑샷, 화면 안에서 손이 스퀴시를 누르는 키프레임 → Flow 8초 생성 후 2~3초만 사용
- 재료 발견 인서트 연타(창고→서랍 탑샷→욕실 CU): 장소만 바꾼 MS·탑샷·CU를 3~6초씩 이어 붙이고, 매 컷 '재료 이름' 대사 1줄
- 손 클로즈업 촉감(ASMR) 인서트: 얼굴은 프레임 위로 잘라내고 손·재질만 크게, 느린 움직임으로 생성 + 효과음(자르기·문지르기·누르기) 얹기
- 어깨 너머(OTS)로 설명·주장 듣기: 전경에 듣는 아이 뒷머리/등을 흐리게 두고 말하는 인물을 화면 중앙~우측에 배치
- 충격·멍 리액션 투샷 홀드: 두 인물 정면 나란히 MS, 대사 없이 1~5초 버티기(과장 표정 모델 권장), 다음 컷에서 대사
- AI 클립 이음새 미세 컷(0.1~0.27초): 생성 클립을 붙일 때 남은 앞뒤 몇 프레임 — 재현할 때는 FFmpeg trim으로 3~6프레임 잘라 매끈하게 이을 것
- 네온 퀴즈 그래픽 + 카운트다운 + 정답 종·컨페티: HyperFrames: 'QUICK QUIZ!' 네온 글자 페이드인, A~D 둥근 박스+'3… 2… 1…', 정답 B 하이라이트 + 종 아이콘 흔들기 + 컨페티 파티클
