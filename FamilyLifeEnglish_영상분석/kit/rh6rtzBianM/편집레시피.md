1. edl.csv 의 img_prompt_en 으로 컷별 키프레임 이미지(Nano Banana 2) → motion_prompt_en 으로 영상(모델 열 참고)

## 편집 기법
- 암전 디졸브(0.2~0.4초 dip to black) 장면 전환: FFmpeg xfade=transition=fadeblack:duration=0.3 — 앞 컷 끝 0.15초 어둡게, 다음 컷 0.15초 밝게. 장소·시간이 바뀔 때만 사용.
- 생성 클립 1개 = 1컷 = 대사 1~2줄: Flow 8초(시작+끝 프레임)로 생성 후 대사 길이에 맞춰 5~7초로 트림, 같은 구도 이어 붙일 땐 끝 프레임을 다음 시작 프레임으로.
- 핵심 소품 인서트 클로즈업: 상자·지퍼·반쪽 장난감만 꽉 차게 INSERT 생성(또는 still + zoompan 느린 줌)으로 관객에게만 정보를 먼저 준다.
- 결과 규모를 보여 주는 와이드 붕괴 샷: 같은 와이드 구도로 시작 프레임=부푼 성, 끝 프레임=쪼그라든 성을 주고 Flow로 생성.
- 집중선(스피드 라인) 오버레이: 흰 방사형 선 투명 PNG를 0.5초 overlay + 2~3px 흔들림(FFmpeg overlay 또는 HyperFrames).
- 어깨 너머(OTS) 타격 샷: 맞는 쪽 어깨를 전경 왼쪽에 걸고 때리는 쪽 얼굴을 오른쪽에 — 프롬프트에 over-the-shoulder 명시, 물 튀김은 veo-3-1.
- 단어 카드 패널 오버레이 + 가리키기: HyperFrames로 빛나는 유리 패널(그림 카드 3장+발음기호) 합성, 캐릭터는 옆에서 가리키는 동작만 생성.
- 타이틀 카드 페이드인: 성 앞 남매 샷 위에 3D풍 'ENGLISH VOCABULARY TIME' 글자 PNG를 페이드인(0.3초).
- (주의) 0.1~0.2초 클립 이음새 조각: 같은 구도 클립을 붙일 때 생긴 번쩍임 — 재현하지 말고 편집에서 잘라 낸다.
