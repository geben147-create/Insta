## 현재 결론과 완료 경계

실제 원본 두 편을 확보해 OpenCV로 전 프레임을 측정하고, 설치한 Watch 로컬 엔진이 고른 프레임 23장을 모두 열람했다. 생성은 진행하지 않았다. 내 영상 칸은 URL·파일이 지정되지 않아 비어 있다. 앞서 만든 v7의 호텔 이미지 두 장은 정지 이미지 비교에만 사용했다. 이를 사용자 영상으로 임의 지정하지 않았다.

`watch` 설치·실행과 OpenCV 측정은 완료했다. `build-video-development-course`는 설치된 경로·공식 카탈로그·정확한 이름의 공개 검색에서 배포본을 찾지 못했다. 이 스킬을 실행했다고 표시하지 않는다. Watch의 음성 전사 폴백은 끄고 로컬로 실행했다. 별도의 유료 호출과 음성 업로드는 하지 않았다. 따라서 대사·BGM 이름·효과음 종류를 확정하지 않는다.

0.1초 CSV는 밝기·채도·프레임 차이·광류·오디오 에너지의 측정 간격이다. 모든 인물·자막·효과음이 0.1초 정확도로 수작업 검증됐다는 뜻은 아니다. 인물·효과음·속도 변화의 완전한 합산, 사용자 영상과의 역할별 대조, 실제 카메라 A/B 렌더는 아직 미완료다. 확인할 수 없는 항목을 0회로 채우지 않는다.

## v7 정지 이미지에서 어색했던 이유와 수정 우선순위

아래는 실제 사용자 영상에 대한 진단이 아니라 이전 생성 이미지 두 장을 보고 내린 시각적 판단이다.

1. **행동과 복장.** 풀 앞에 흰 재킷·긴 바지·로퍼·가방을 착용하고 서 있다. 시설을 이용하는 동작이 없어 물과 인물이 따로 읽힌다. 새 물놀이 에피소드는 같은 성인 캐릭터의 차콜·딥와인 계열 비키니로 장소에 맞춘다. 이동 장면의 재킷을 물속 장면까지 고정하지 않는다. 같은 에피소드 내 얼굴·체형·수영복은 유지한다.
2. **인물과 시설의 관계.** 세 장 모두 카메라를 등지고 멈춰 선 구도라 발견·반응이 없다. 새 장면은 자연스러운 3/4 옆뒷모습, 한 손으로 실제 난간을 잡는 동작, 물을 손끝으로 건드리는 동작 중 하나만 택한다. 원본의 양팔 벌림이나 그네 행동을 그대로 복제하지 않는다.
3. **합성의 물리성.** 발바닥 접점·그림자 방향·피부의 물 반사광·가림·수면 굴절을 같은 광원으로 묶어야 한다. 물속 다리는 굴절로 위치가 달라져 보일 수 있으므로 길이 왜곡과 구분해 검증한다. 접지선의 실측 오차는 아직 측정하지 않았다.
4. **예쁜 인물의 비율.** 외모를 개선하면서 다리만 늘리면 인체가 깨진다. 새로운 성인 캐릭터는 자연스러운 어깨·골반·무릎·발목 연결과 우아한 옆선, 단정한 헤어로 설계한다. 기준 체형 승인 이미지가 없는 상태에서 사용자 메타휴먼과 같다고 하지 않는다.
5. **빛과 건물.** 풀의 청록과 피부의 따뜻한 반사광을 분리하고 하이라이트를 보존한다. 실제 판매 숙소 소개에서는 건물 형태·창·풀 크기를 더 화려한 가상 시설로 바꾸지 않는다. 미관은 촬영 방향·시간대·명암·색보정으로 개선한다. 색보정 수치는 아래 제안이며 원본 역산값이 아니다.

## 첫 카메라 A/B — 다른 조건은 고정

아직 렌더 전인 실험 설계다. 1080×1920, 30fps, 3.0초(90프레임), 같은 승인 이미지·성인 캐릭터·수영복·렌즈·시간대·색보정·시드(지원할 때)·피사체 행동·오디오를 고정한다. A는 정지 카메라, B는 작은 Dolly In 하나다. 제목·BGM·의상·노출도·타이밍을 함께 바꾸지 않는다. 실제 생성 모델이 물리적 거리나 시드를 보장하는지는 별도 확인한다.

| 항목 | A | B |
|---|---|---|
| Higgsfield 지시 | locked camera, same pose, no zoom | one slow dolly in, same pose and lighting, no orbit or tilt |
| 0.0초 | 원래 구도 | 같은 원래 구도 |
| 1.5초 | 카메라 이동 0 | 전진의 절반, 난간과 인물의 겹침을 유지 |
| 3.0초 | 카메라 이동 0 | 작은 전진 종료; 얼굴 정면 노출·신체 자르기 없음 |
| 판단 | 신체 자연스러움·호텔 인지·미감 점수 | 같은 기준과 프레임 간 관절·시설 흔들림을 비교 |

Higgsfield 공식 Camera Controls에 Dolly In과 Orbit 등이 있음을 확인했다. 여러 움직임을 동시에 섞는 대신 첫 테스트에서는 Dolly In만 사용한다. https://higgsfield.ai/camera-controls

### 프리미어·캡컷에서 재현 가능한 2D 검토 수치

아래 값은 실제 Dolly 촬영을 복원한 값이 아니라 정지 이미지를 이용한 저비용 구도 검토다. 2D 확대에는 진짜 원근·시차 변화가 없다. 소스를 먼저 1080×1920에 맞춰 새 중첩/컴파운드 클립으로 만들면 기준 크기 100%가 일정하다. 소스 비율 차이는 fit으로 확인한다.

| 시간 / 30fps 프레임 | A Scale / Position | B Scale / Position |
|---|---|---|
| 0.0초 / 0 | 100% / (540,960) | 100% / (540,960) |
| 1.5초 / 45 | 100% / (540,960) | 103% / (540,960) |
| 3.0초 / 90 경계 | 100% / (540,960) | 106% / (540,960) |

프리미어 Motion의 Scale·Position, 캡컷 Scale 키프레임에 적용한다. CapCut 위치가 화면 중앙 기준이면 (0,0)을 사용하고 앱에서 중심을 확인한다. 선형 보간으로 먼저 비교한다. 두 버전에 같은 음악이나 무음을 쓰고 새 효과음을 추가하지 않는다. 90은 클립 끝 경계이며 실제 마지막 표시 프레임은 89다. 필요하면 끝 키프레임을 89로 옮겨 두 버전에 동일 적용한다.

색보정의 시작 제안: 화이트밸런스부터 맞춘 뒤 Exposure +0.15EV, Highlights -15, Shadows +5, Saturation 105% 수준에서 피부와 수면을 육안 비교한다. 앱별 슬라이더 단위는 다르므로 숫자를 그대로 옮겨 동일색이라고 주장하지 않는다. 과한 샤픈·피부 블러·청록 피부는 제외한다. 원본에 없는 건물·시설을 색보정으로 추가하지 않는다.

Adobe 공식 키프레임 설명: https://helpx.adobe.com/premiere/desktop/add-video-effects/control-effects-and-transitions-using-keyframes/add-keyframes.html

### 제목·썸네일 제안 — 카메라 실험 이후 별도 시험

A ‘벳푸에서 물빛이 바뀌는 시간’ / B ‘사진보다 직접 들어가 보고 싶은 온천 풀’. 새 문구이며 흥행 보장은 없다. 썸네일은 동일 캐릭터의 자연스러운 옆뒷모습과 실제 풀의 물빛을 함께 보여 주고, 글자는 후처리한다. 현재는 썸네일과 비키니 수정 이미지를 생성하지 않았다. 원본 문장·캐릭터·시설을 복제하는 대신 색·빛·배치와 정보 공개 방식만 차용한다.
