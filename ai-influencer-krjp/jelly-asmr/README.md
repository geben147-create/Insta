# 호텔 ASMR 제작 규칙

이 규칙은 이 시리즈의 떡국, 젤리, 슬라임, 뷰티 ASMR 이미지와 영상에 공통 적용한다.

1. 제작 전에 Trip.com 숙소 상품 페이지를 확인한다. 해당 숙소에 실제로 등록된 자쿠지, 실내 수영장, 가족 물놀이장 중 하나를 골라 프레임 배경에 알아볼 수 있게 넣는다. 시설 근거 URL과 숙소 ID를 기록한다. 생성 이미지에 재구성한 공간은 콘셉트 이미지로 표시한다.
2. 전경에는 아이들이 한눈에 알아볼 만한 독특한 대형 소품이나 음식 하나를 배치한다. 명확한 동작으로 크기와 질감을 보여준다. 왕떡은 들어 올린 떡이 휘는 순간, 슬라임은 늘어나거나 눌리는 순간, 브러시는 모와 파우더가 움직이는 순간처럼 소재에 맞춘다.
3. 이미지는 한 장씩 독립 파일로 납품한다. 최종 이미지 파일의 바이트를 기준으로 SHA-256을 계산하고, 파일명·시설·Trip.com 숙소 ID·일반 상품 URL·제휴 URL을 [이미지 매핑](assets.json)에 한 행으로 연결한다. 제휴 URL은 계정에서 실제 발급한 뒤 같은 숙소 상품으로 이동하는지 확인한다. 아직 발급하지 않은 URL 필드는 `null`, 상태는 `pending`으로 둔다.
4. 이미지 후보 교체, 리사이즈 또는 재인코딩으로 바이트가 바뀌면 새 해시를 입력한다. 게시하기 전에 이미지에서 시설이 보이는지, 파일의 해시와 매핑의 해시가 같은지, 숙소와 제휴 링크가 같은 상품인지 확인한다.

```bash
sha256sum -- '최종이미지.png'
```

## 실제 시설 사진 직접 참조

신규 제작은 시설 설명과 함께 Trip.com 갤러리의 실제 해당 시설 사진을 눈으로 확인하고 이미지 생성의 입력 자료로 넣는다. `facility_photo_url`과 `facility_photo_sha256`을 최종 이미지 해시와 함께 기록한다. 일반 수영장이나 워터파크는 그 시설 이름으로 표시하고, 자쿠지는 원본에서 실제 자쿠지임이 확인될 때만 그렇게 표시한다. 생성 시안이 참고하는 시설과 촬영 장면을 구분한다.

왕팝콘 시안은 한화리조트 경주 Trip.com 갤러리에서 워터파크로 표시된 사진을 썼다. [숙소·시설](https://www.trip.com/hotels/gyeongju-hotel-detail-688858/hanwha-resort-gyeongju/) · [시설 원본 사진](https://ak-d.tripcdn.com/images/0220q12000pu5amfaCFEB_Z_1280_853_R50_Q90.jpg) · [청담언니 팝콘 참고](https://www.youtube.com/watch?v=A9h1jHGffVw)

## Flow 영상 인수인계

각 회차는 독립 PNG와 짝을 이루는 Flow I2V 프롬프트를 `flow-prompts/`에 둔다. `assets.json`에서 이미지와 프롬프트 해시, 실제 시설 사진, 숙소 링크를 같은 번호로 조회한다. 첫 1초에 놀라는 표정과 대형 소품의 변형을 보여주고, 식용 소재는 떼어낸 작은 조각을 실제로 먹는 장면과 질감에 맞는 소리로 끝맺는다. 화장품과 공예 슬라임은 손동작으로 질감을 표현한다. 영상 생성 상태는 이미지·프롬프트 완성과 별도로 기록한다.

신규 회차에서는 연속 두 편에 서로 다른 숙소를 쓰고, 이미 사용한 시설 사진 URL과 사진 해시는 다시 쓰지 않는다. 최근 다섯 편의 숙소는 다른 실제 후보를 먼저 찾는다. 물속, 튜브 위, 풀사이드, 키즈풀 옆, 실제 자쿠지 구도를 교대로 사용한다. 시설에 없는 구조물을 추가하면 안 된다. 이전 회차의 로컬 경로는 유지한다.
