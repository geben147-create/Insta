# 호텔 ASMR 제작 규칙

이 규칙은 이 시리즈의 떡국, 젤리, 슬라임, 뷰티 ASMR 이미지와 영상에 공통 적용한다.

1. 제작 전에 Trip.com 숙소 상품 페이지를 확인한다. 해당 숙소에 실제로 등록된 자쿠지, 실내 수영장, 가족 물놀이장 중 하나를 골라 프레임 배경에 알아볼 수 있게 넣는다. 시설 근거 URL과 숙소 ID를 기록한다. 생성 이미지에 재구성한 공간은 콘셉트 이미지로 표시한다.
2. 전경에는 아이들이 한눈에 알아볼 만한 독특한 대형 소품이나 음식 하나를 배치한다. 명확한 동작으로 크기와 질감을 보여준다. 왕떡은 들어 올린 떡이 휘는 순간, 슬라임은 늘어나거나 눌리는 순간, 브러시는 모와 파우더가 움직이는 순간처럼 소재에 맞춘다.
3. 이미지는 한 장씩 독립 파일로 납품한다. 최종 이미지 파일의 바이트를 기준으로 SHA-256을 계산하고, 파일명·시설·Trip.com 숙소 ID·일반 상품 URL·제휴 URL을 [이미지 매핑](assets.json)에 한 행으로 연결한다. 제휴 URL은 계정에서 실제 발급한 뒤 같은 숙소 상품으로 이동하는지 확인한다. 아직 발급하지 않은 URL 필드는 `null`, 상태는 `pending`으로 둔다.
4. 이미지 후보 교체, 리사이즈 또는 재인코딩으로 바이트가 바뀌면 새 해시를 입력한다. 게시하기 전에 이미지에서 시설이 보이는지, 파일의 해시와 매핑의 해시가 같은지, 숙소와 제휴 링크가 같은 상품인지 확인한다.

```bash
sha256sum -- '최종이미지.png'
```

현재 시안의 배경은 경주 온마루 한옥 키즈 풀빌라의 실내 수영장 시설을 바탕으로 생성했다. [Trip.com 숙소 및 시설](https://www.trip.com/hotels/gyeongju-hotel-detail-100691908/onmaru-hanok-kids-poolvilla-and-couple-spa/)
