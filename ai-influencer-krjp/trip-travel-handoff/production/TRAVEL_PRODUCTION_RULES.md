## 1. 컷 길이와 실제 재생 속도

| 소재 | 추천 속도 | 롱폼 | 쇼츠 |
|---|---:|---:|---:|
| 일몰 | 0.8–1배 | 4–6초 | 2–3초 |
| 드론 도시 | 1–1.3배 | 3–6초 | 1.5–3초 |
| 도보 | 1.1–1.5배 | 2–4초 | 1–2초 |
| 차량 | 1.5–2.5배 | 2–3초 | 0.8–1.5초 |
| 음식 상세 | 0.8–1배 | 3–4초 | 1.5–2초 |
| 인물 반응·대화 | 1배 | 3–6초 | 1–3초 |
| 물·파도·자연 | 0.5–1배 | 3–6초 | 1.5–3초 |
| 시장 | 1–1.3배 | 2–4초 | 1–2초 |
| 호텔 객실 공개 | 0.9–1.2배 | 3–5초 | 1–2초 |

속도는 소재별로 결정한다. 0–0.8초는 높은 시점과 낙차를 보여주고, 0.8–2.1초는 하강 또는 접근을 가속하고, 2.1–3초는 목적지를 드러내며 감속한다. 최고의 풍경은 1.5–3초 감상 시간을 확보한다. 실제 재생 배속과 생성 프롬프트의 카메라 가속은 따로 표시한다. 30fps 원본을 0.5배속하면 초당 15개의 고유 프레임만 쓰인다. 부드러운 느린 장면에는 60fps 이상의 원본이나 프레임 보간을 고려하고 손·얼굴의 왜곡을 검수한다.

## 2. 샷과 이미지 설계

- ① 전체 공간 → ② 공간 진입 → ③ 내부 공개 → ④ 디테일 → ⑤ 인물 경험 → ⑥ 감성 마무리. 짧은 편은 한 구간에 두 역할을 맡길 수 있다.
- 첫 3초는 하늘에서 내려오는 시점, 투명 난간이 있는 데크·높은 산책로·풀 출발대와 같은 낙차, 캐릭터의 뒷모습으로 엮는다. 하강 시작은 풍경 위주로 두고 인물 높이 목표는 처음 약 6–12%, 접근 후 14–20%로 잡는다. 방에서는 20–30%를 시작 기준으로 하고, 디테일은 필요한 손·컵·발만 사용한다.
- 메인 가족 편에는 아래 출연 기준을 쓴다. 기존 여성 여행자와 일본 여행 의상은 포즈·패션 참고다. 지정 여성의 머리는 허리 아래까지 풍성하게 내려오며 크게 한 번 흐르는 웨이브로 연출한다. 새 컷은 보폭과 무게중심, 손과 소품 접촉, 같은 장면의 의상 연속성을 확인한다.
- 생성 장면마다 피사체와 동작, 전경·중경·배경, 카메라 시작·이동·끝, 조명과 색, 렌즈 느낌, 다음 컷과 연결할 기준물을 지정한다. 3분할은 인물과 자막, 대칭은 건축, 리딩라인은 길과 접근, 전경·중경·배경은 공간 깊이에 쓴다.

| 장면 | 렌즈 느낌과 앵글 |
|---|---|
| 도시·큰 건축 | 16–24mm 와이드·로우 앵글 |
| 여행·거리 | 24–35mm 눈높이·트래킹 |
| 인터뷰 | 50–85mm 미디엄·클로즈업 |
| 인물 | 85mm와 부드러운 배경 흐림 |
| 음식·제품 | 85–105mm 매크로·측면광 |
| 웅장한 풍경 | 16–35mm, 풍부한 원근감과 전경 |

렌즈 수치는 생성 모델의 시각적 지시어다. L01 골든아워·역광은 여행과 감동, L02 하이키는 밝은 분위기와 음식, L03 로우키는 긴장, L04 자연광·창문광은 인물과 객실, L05 블루아워는 야경, L06 측면광은 음식·옷감·제품 질감에 사용한다.

## 3. 자막·오디오·다른 장르

- 여행은 통일감 80%와 편마다 달라지는 20%를 출발점으로 한다. 세로 9:16, 가로·세로 50% 지점에 연한 흰색 정자 세리프 소문자 한 줄과 마침표. 테두리 없이 2–4초간 읽히도록 중간 명도 배경에서 편집으로 얹는다. 감성 자막 페이드는 0.4–0.6초, 필요하면 미세 확대만 쓴다.
- 일반 자막은 발화에 맞춰 0–0.1초에 표시한다. 중요한 단어는 0.15–0.25초 등장, 1.5–3초 유지, 100→110→100% 확대. 충격 자막은 0.1–0.2초 등장, 0.8–1.5초 유지, 80→125→100%. 기사 강조는 0.4–0.8초 등장 및 3–6초 이상 유지, 메모는 0.2–0.4초 등장 및 2–4초 유지, 통계는 0.4–0.8초 등장 및 3–6초 이상 유지. 글꼴은 2–3계열 안에서 고른다. 고령층용 1920×1080은 일반 52–68px, 강조 85–125px부터 검수한다.
- 첫 훅은 원본 음성과 짧은 효과음, 설명은 낮은 BGM, 반전 직전은 0.2–0.5초 여백, 감동 구간은 현장음과 서서히 오르는 음악. 대사에 덕킹을 적용하고 끝나면 0.5–1초에 복구한다. 내레이션 약 -16 LUFS, 원본 음성 -18~-16 LUFS, BGM은 음성보다 16–22dB 낮게 시작하고 최종 약 -14~-16 LUFS 및 True Peak -1dBTP 이하부터 검수한다.
- 주식·교육·뉴스는 숫자 카운트업, 기업 VS, 공시 하이라이트, 추세선 순차 표시, 위험색, 단계 카드, 핵심에 슬로 줌을 제한적으로 쓰고 기준일·출처·축을 충분히 보여준다. 국뽕 자막 기준색은 흰색 #FFFFFF, 강조 #FFE500, 반전 #FF3838, 정보 #58DCEB, 감동 #FFB647, 배경 #151A26으로 별도 적용한다.

## 4. 자동화와 결과 관리

1. 원본 영상, 사진, 프롬프트, 캐릭터와 확인된 예약 링크부터 확인한다.
2. 장면별 장소, 동작, 인물, 감정, 소리, 정보, 재사용 가능 여부를 판단한다.
3. 장르별 프리셋에서 컷 전환, 줌, 자막, 효과음, 영화적 연출 강도를 고르고 소재에 맞게 조절한다.
4. 기존 컷을 우선 쓰고 부족한 장면만 만든다. 사진은 기본 이미지 도구, 영상은 지정된 MCP에서 실행한다. 승인된 유료 컷은 견적과 작업 ID를 기록하고 중복 제출을 피한다.
5. 세로 비율과 원본 프레임레이트, 화면 읽기, 과잉 효과, 음량, 동작 지속성, 반복, 소재와 실제 숙소 정보의 일치를 검수한다. 창작 장면을 표시하고, 사용자가 미리보기에서 승인하거나 수정할 수 있게 한다.
6. 신규 이미지 및 영상은 제작 보드의 파일 링크에 연결한다. 현재 세션에서 Pollo AI MCP가 확인됐으며, Google Flow용 프롬프트는 별도로 유지한다.

### 출연과 참고 사진

- 메인 가족 편은 사용자가 앞서 지정한 여성, 함께 출연시키기로 한 인물, 어린이로 구성한다. 첫 프레임에 확인 가능한 인물만 그대로 유지한다. 같은 컷 안에서 얼굴·머리·체형·의상이 바뀌거나 가족 구성원이 새로 생기지 않게 한다. 어린이는 자연스럽게 반응하는 가족 컷에 담는다.
- 사용자가 참고용으로 준 인물·패션 사진과 기존 시트는 뒷모습, 자세, 옷의 실루엣을 참고하는 자료다. 번호가 확정된 실제 원본을 시작 프레임에 연결하기 전에는 해당 인물이나 의상이 고정됐다고 표시하지 않는다.
- 가족 편의 성인은 마른 진입로에서 두 걸음을 가볍고 우아하게 내딛는다. 어린이는 평평한 마른 길에서 신나게 짧게 달려간 뒤 수영장 데크 전에 성인과 함께 속도를 늦춘다. 물과 시설을 주제로 하는 컷은 인물 없이도 제작한다.

### Pollo 영상 모션

[마데이라 벤치 13.47초 모션 분석과 구간별 프레임](https://geben147-create.github.io/Insta/insta-viewer/travel-motion/#DObZ7o3iOU8)의 핵심은 컷 없이 전경 뒤의 목적지를 드러내는 카메라 이동이다. 원본은 0–2.5초 전경만, 2.5–5.5초 전진·틸트업, 5.5–8.5초 와이드 공개, 8.5–11초 시차로 재구성, 11–13.47초 안정 구도다.

6초 풀 컷은 0–0.8초 데크 의자·난간·문틀 중 하나로 수면을 가린 하향 시점, 0.8–2.5초 실제 전진하면서 틸트업, 2.5–3.5초 풀과 원경을 와이드 공개, 3.5–4.8초 작은 측면 이동으로 시차, 4.8–6초 감속 후 수면과 빛만 움직이게 한다. 시작 프레임에서 구조물이 이미 다 보이면 가려진 시작 프레임을 새로 잡는다. 한 연속 샷으로 유지하며 디지털 줌, 갑작스러운 새 구조물, 난간 뒤틀림, 수평선 이동, 캐릭터 변형을 검수한다.


### 35장 기준 작업 구분과 애니메이션 검수

1. **메인 가족**은 지정 여성·지정 동행자·어린이의 원본 번호와 세 사람이 등장하는 뒷모습 시작 이미지를 기록한다. 한·일·중 편의 여성 원본은 [10-03 흰 드레스](https://geben147-create.github.io/Insta/ai-influencer-krjp/trip-travel-handoff/#ref-10-03)다. 해당 가족 컷의 동행자와 어린이 원본 매칭을 검증한 뒤 I2V를 요청한다. 남성 의상 시안이나 가족 배치 시안만으로 출연을 확정하지 않는다.
2. **사용자 사진 의상**은 사용자가 준 옷 사진을 컷마다 골라 원본 번호를 함께 기록한다. 목선·기장·색·소재·핏을 시작 이미지에 맞춘다. 생성 내내 그 컷의 뒷모습과 옷을 유지한다. 참고 사진의 역할은 의상 및 스타일이다.
3. **카메라 테스트**는 시설 창작 컷으로 한다. 02-33 가림, 02-28 공개, 02-34 물 반사를 시작·공개·홀드에 사용한다. Pollo·Flow 입력에 시작 프레임, 원본 번호, 5구간 타이밍, 전진 방향과 고정 렌즈 지시를 전달한다. 3초까지 수영장이 읽히게 한다.
4. **최종 프레임 검수**는 0초의 가림, 3초 풀과 원경의 공개, 6초 감속 및 안정 구도에서 한다. 프레임 사이에서 전경 모서리의 시차, 수평선과 조명의 일관성, 옷과 인물 연속성을 확인한다. 디지털 줌, 뿌연 베일, 수면 또는 난간 변형은 재검토한다. 기존 Pollo 결과의 도입부와 사진 모션은 신규 6초 연속 샷의 검수 증거로 사용하지 않는다.
