# 콘텐츠 제작 규칙 v1 (2026-11-09, 사용자 피드백 기반)

> 기존 `cardnews-top5/rules15.md`(15개 규칙)를 그대로 유지하고, 아래 규칙을 추가·우선 적용한다.
> 모든 대본은 이 체크리스트를 통과해야 시트에 "완료"로 올린다.

## A. 원본과 1:1 형식 맞추기
- [ ] A1. **형식 그대로**: 원본이 원페이지면 원페이지, 캐러셀이면 캐러셀, 릴스면 릴스. 임의로 형식을 바꾸지 않는다.
- [ ] A2. **분량은 원본보다 조금 더**: 원본 3장 → 4~5장, 원본 30개 → 35~40개, 원본 3총사 → 4총사, 원본 7가지 → 8~10가지. (숫자는 실제로 채울 수 있을 때만)
- [ ] A3. **글 구조·정보량은 원본 수준**: 칸 수, 칸 안 정보량(번호·도구명·제목·설명), 장 순서는 같은 분야 원본 수준으로 유지.
- [ ] A3-1. **사진·디자인은 똑같이 하지 않는다** (v1.1 추가): 같은 분야 원본의 이미지·구도·색을 그대로 따라 하지 않는다. **다른 분야(섹터)에서 잘된 게시물의 비주얼**(예: 뷰티의 전후 비교, 여행의 지도·랭킹, 음식의 클로즈업, 연애툰의 말풍선)을 벤치마킹해 섞는다.
- [ ] A3-2. 비주얼 벤치마크도 근거 표기: 어느 섹터의 어떤 게시물(링크·실측) 비주얼을 어떻게 가져왔는지 적는다. 같은 분야 원본과 다른 분야 비주얼 원본을 **최소 1개씩**.
- [ ] A4. 원본 이미지를 **참고 예시로 반드시 첨부**(원본 링크 + 캡처 미리보기). 캡처는 비공개 보관, 공개 업로드 금지.

## B. 훅·문구 조합 (출처를 문구 단위로)
- [ ] B1. 잘된 원본 **2~3개를 조합**해서 쓴다 (예: "자면서도 일하는 ○○" + "나만 몰랐던 ○○ 100개" + "완벽 정리본").
- [ ] B2. **문구 하나하나마다** 어떤 원본의 어떤 표현을 가져와 어떻게 바꿨는지 표기한다 (`[원본A: "…"] + [원본B: "…"] → 내 문구`).
- [ ] B3. **돈·혜택 숫자를 앞에**: "1억", "148만원 돌려받기"처럼 독자가 받는 돈이 핵심이면 표지에 크게. "모르면 못 받는", "나만 몰랐던", "받아가세요" 손실회피·획득형을 쓴다. (숫자는 공식 출처로 확인된 것만)
- [ ] B4. 저장 가치 장치: "완벽 정리본", "총정리", "100개", "전후 비교 + 프롬프트 공개" 등 저장할 이유를 표지에 넣는다.
- [ ] B5. 급등 이슈는 **날짜가 맞을 때만** 결합 (예: 11/9 가상자산 압류). 억지 결합 금지.

## C. 내용은 탄탄하게 (얇은 일반론 금지)
- [ ] C1. **유튜브 상위 3개의 자막/내용을 실제로 추출**해 핵심 팁을 뽑고, 장마다 구체 팁·숫자·도구명·절차를 넣는다. 출처 영상·타임코드 기록.
- [ ] C2. **뉴스 본문을 읽고** 사실(금액·조건·날짜·기관)을 뽑는다. 제목만 보고 쓰지 않는다.
- [ ] C3. 지원금·제도형은 **제도별로 쫙 분석**: 사업명 / 최대 금액 / 대상 / 조건 / 신청 시기 / 신청처를 표로.
- [ ] C4. 프롬프트형은 **실제 프롬프트 원문 + 전후(Before/After) 예시**를 같이 준다.
- [ ] C5. 장마다 "그래서 독자가 오늘 할 수 있는 행동 1개"가 있어야 한다.

## D. 레퍼런스 근거 표기
- [ ] D1. 각 콘텐츠에 원본 2~3개: 링크, 계정, 조회·좋아요·댓글(시트 실측), 형식, 장수.
- [ ] D2. 유튜브 TOP3: 링크, 조회수, 추출한 팁 요약(타임코드).
- [ ] D3. 구글 트렌드·자동완성·뉴스: 순위·날짜·링크.

## E. 결과물 전달
- [ ] E1. 결과는 **구글 시트 정본에 새 탭** + **GitHub Pages 링크**로 준다. CSV만 주지 않는다.
- [ ] E2. 시트 첫 탭에 이 규칙과 바로가기를 둔다.
- [ ] E3. 장별 탭: 문구 | 조합 근거 | 참고 이미지 | 이미지 프롬프트 | 결과 이미지 → **1:1 비교**가 한 줄에서 되게.
- [ ] E4. 캐릭터(Mr. Navy, 구석·새끼손가락) 지시를 프롬프트에 포함.

## F. 금지
- 실존 인물·로고 복제, 원본 이미지 공개 재업로드, 확인 안 된 숫자, 수익 보장, 투자·의료·법률 단정.
