# V4 디자인 기준 · 2026-11-12

## 범위
기존 V3_01~10의 문구·출처·설명글·사실 확인 목록을 그대로 보존한 V4_101~110 디자인 시안, 총 75장.
새 100편은 이 묶음에 포함하지 않는다. 사용자의 최종 손편집 및 게시 전 사실 검증은 별도다.

## 시각 기준
- 사용자 첨부 1·3·8: 크림 종이, 가는 이중 프레임, 명조 제목, 빨간 강조, 청록 보조색.
- 사용자 첨부 4: 통통한 얼굴, 짧은 검은 머리, 남색 정장, 파란 넥타이, 안경 없음.
- 사용자 첨부 5: 낙서풍 선과 과장된 리액션. 이번에는 기존 낙서 컷에서 배경을 제거한 투명 PNG 사용.
- 원본의 텍스트 묶음·정보 순서·같은 행의 비교 구조를 유지하고, 조판과 이미지 영역을 재배치.
- 기존 visual_bench와 metrics_note는 과거 자료로 보존. 이번 측정값은 redesign_metrics에 따로 기록하며 신규 외부 실측으로 주장하지 않음.

## 편집 및 검증
원본과 텍스트·출처·메타데이터를 비교하고, 편집기 checkRules / autoFix 결과를 spec에 반영한다.
PNG는 편집기와 같은 card.js로 렌더한다. PPTX는 사용자가 지정한 기존 card_build.py 방식(배경 PNG + 편집 가능한 글씨)을 사용한다.
AI 자동 맞춤만 기록하며 사람이 손편집한 증거 파일을 생성하지 않는다.

## 이미지 비교
