# 카드뉴스 제작 규칙 15개 (2026-11-08, 사용자 지시 기반)

## 글 작성 (1~6)
1. 훅은 잘된 원본 훅을 가져오되, 서로 다른 원본 훅 2개 이상을 섞어서 변형한다. 원문을 그대로 복사하지 않는다.
2. 게시물마다 "어떤 원본 훅을 어떻게 섞었는지"를 함께 적는다.
3. 숫자 훅(100개, 30명, 7개 등)은 채울 내용을 실제로 확보하고 팩트체크한 뒤에만 쓴다. 출처 링크를 남긴다.
4. 비공식 코드·사용자 제작 팁은 "비공식"이라고 표기한다. 금액·조건은 공식 공고 번호로 확인한다.
5. 글 구성은 훅 - 설명 - 첫 댓글 - CTA(댓글 단어 남기면 DM) - 해시태그. 유튜브 TOP10 영상과 구글 트렌드 급등 키워드의 소재를 반영하고 순위·링크를 기록한다.
6. 프롬프트·명령어 모음은 3개처럼 작게 말하지 않고 100개 규모로 구성한다.

## 이미지 생성 (7~14)
7. ChatGPT 웹(유료 계정, 새 탭)에서 생성한다. 레퍼런스 인스타 원본 이미지 파일을 실제로 첨부하고, 내 캐릭터 시트도 같이 첨부한다. 링크만 넘기지 않는다.
8. 레이아웃·여백·글자 위계·정보 밀도는 원본과 최대한 비슷하게. 좌우 반전, 색, 소재 정도만 변형한다.
9. 원페이지 카드는 정보를 간소화하지 않는다. 칸 수와 칸 안 정보량(번호, 도구, 제목, 설명)을 원본 수준으로 유지한다.
10. 내 캐릭터는 구석에 작게 또는 빼꼼 등장한다. 컵을 들 때 새끼손가락을 세우는 것이 트레이드마크. 짝꿍은 주제와 연결되는 캐릭터로 바꾼다.
11. 사람 사진은 극사실로, 완전 가상 인물(실존 인물과 닮지 않게). 비포/애프터는 같은 얼굴 크기·각도·표정. 원본 인물과 너무 닮지 않게 바꾼다.
12. 국기는 실제 대한민국 태극기를 쓴다. ChatGPT·Claude 등 실제 로고는 복제하지 않고, 원본(외국인 게시물)의 문구·구도를 똑같이 베끼지 않는다.
13. 색상 팔레트를 반드시 정하고, 원본과 다른 포인트 색(화살표, 띠 등)을 쓴다. 배경·소품(차, 장소)도 원본과 다르게 바꾼다.
14. 최종 크기는 인스타 캐러셀 4:5 (1080x1350). 생성 후 크롭한다.
15. 결과 보고는 레퍼런스 vs 결과 1:1 비교 HTML(한 줄 6개 그리드, 파일 하나만 열어도 보임)로 한다. 조회수·좋아요·댓글, 실제 링크, 유튜브·릴스·구글 트렌드 순위, 어떤 훅을 섞었는지를 넣고 GitHub Pages에도 올린다.
