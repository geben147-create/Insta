## 4. 감정선 비교
- V1: 억울함(창작 비하) → 위기 → 숫자 반전 → 이유 → 역사 → 약점 → 세계 전환 → 미래 → 회수(같은 원음 반복).
- V2: 억울함(실제 중국·미국 화자의 비하·비판) → 위기(중국 통계) → 1차 통쾌(판매 기록 + 미국 소비자 대기) → **놀람(톱기어가 부수다 지침)** → 역사적 굴욕(1960년대 비웃음·1980년대 재팬 배싱) → **감동(미국 최악 공장을 바꾼 "의무")** → 공정한 약점(같은 정비사의 상반 평가) → 2차 통쾌(포드·EU가 같은 길로) → 사람·가이젠 → 자긍심 결말(칭찬의 기준 = 일본차, 기념비가 된 하이럭스).
