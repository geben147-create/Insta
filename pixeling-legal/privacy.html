Pixeling 개인정보처리방침

시행일 2026-11-26 · 운영자: geben147-create (GitHub 프로필) · 문의: GitHub 프로필을 통해 연락

Pixeling은 운영자 한 명이 자신의 PC에서 YouTube 콘텐츠 기획에 쓰는 비공개 분석 도구입니다. 인터넷에 공개된 서비스가 아니며 회원가입·로그인이 없습니다.

1. YouTube API Services 사용

Pixeling은 공개 YouTube 영상·채널을 검색하고 보여 주기 위해 YouTube API Services(YouTube Data API v3의 search.list, videos.list, channels.list — 읽기 전용)를 사용합니다. Pixeling을 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다. Pixeling은 YouTube 로그인(OAuth)을 사용하지 않으며, 사용자의 YouTube 계정·비공개 데이터에 접근하지 않습니다.

2. 처리하는 정보

  • YouTube 공개 정보: 영상 제목, 썸네일, 채널명, 게시일, 공개 조회수, 공개 구독자 수, 카테고리, 채널 등록 국가
  • 사용자가 입력한 값: 검색어, 국가·기간·조회수 조건, 예상 수익 계산용 가정값(시청국가·형식·환율·단가)
  • 편집 도구에서 사용자가 직접 연 영상 파일과 마이크 음성: 이 PC 안의 로컬 프로그램으로만 처리합니다. 음성은 글자로 바꾸는 동안만 임시 파일로 두고 곧바로 삭제합니다.

3. 이용 목적

화면 표시, 콘텐츠 기획용 예상 수익 시나리오 계산, 사용자가 직접 저장한 목록 관리에만 씁니다. 제3자에게 판매하거나 제공하지 않으며 광고를 게재하지 않습니다. 여러 채널 소유자의 데이터를 합쳐 YouTube의 사업 현황을 추정하는 데 쓰지 않습니다.

4. 보관 기간

  • 최신 검색 결과는 브라우저 메모리에만 있으며, 페이지를 새로 고치면 사라집니다. 서버 DB에 저장하지 않습니다.
  • 서버 DB에 보관하는 YouTube 공개 통계(조회수·구독자 수 등)는 30일 안에 삭제하거나 새로 고칩니다.
  • 사용자가 직접 저장한 목록은 사용자가 삭제할 때까지 이 PC에 보관합니다.

5. 예상 수익 표시

예상 수익은 Pixeling이 공개 조회수와 가정 단가로 계산한 자체 추정치입니다. YouTube가 제공한 데이터나 실제 수익이 아니며, 화면에도 항상 그렇게 표시합니다.

6. 쿠키·기기 저장

Pixeling은 추적 쿠키를 쓰지 않습니다. 화면 테마, 저장한 필터 프리셋, 편집 중인 프로젝트를 이 브라우저의 로컬 저장소(localStorage·sessionStorage)에 저장합니다. 영상을 재생하면 YouTube 내장 플레이어가 YouTube의 정책에 따라 쿠키 등을 사용할 수 있습니다.

7. 삭제 요청·문의

Pixeling에 저장된 데이터 삭제를 요청하면 7일 안에 삭제합니다. Pixeling에서 삭제해도 YouTube에 있는 데이터에는 영향이 없습니다. Google 계정 권한은 Google 보안 설정에서 언제든 확인·철회할 수 있습니다(Pixeling은 Google 계정 권한을 요청하지 않습니다).

English summary. Pixeling is a private, single-user content-planning tool run on its operator's own computer (not a public service; no sign-up or login). It uses YouTube API Services (YouTube Data API v3, read-only; no OAuth). By using Pixeling you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms); see the Google Privacy Policy (http://www.google.com/policies/privacy). Data used: public YouTube video/channel information and values the user types in. Latest-search results stay in browser memory only; YouTube statistics kept in the local database are deleted or refreshed within 30 days. Estimated revenue is Pixeling's own estimate, not YouTube data and not actual earnings. No data is sold or shared; no ads. Pixeling stores UI preferences in the browser's local storage; the YouTube embedded player may set cookies under YouTube's policies. Deletion requests are handled within 7 days. Contact via the operator's GitHub profile.
