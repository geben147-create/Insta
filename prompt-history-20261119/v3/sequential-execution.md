# 순차 실행안 — 이번 제안, 원문 교정본과 별개

이번에는 새 스킬이나 에이전트를 만들지 말고, 아래 제작 순서를 하나씩 실행해 주세요. 한 번에 전부 집필하지 마세요.

1. 이번 영상의 작업 폴더와 run_id를 정하고 진행 상태를 기록하세요. 기존 파일은 덮어쓰지 마세요.
2. 공통기억과 참고 자막 7편 전문을 실제로 읽고, 읽은 파일·구간을 기록하세요. 자료를 읽지 않고 읽었다고 하지 마세요.
3. 아래 15단계를 순서대로 실행하세요. 각 단계가 끝나면 결과를 별도 파일에 저장하고 검수하세요. 검수가 통과된 결과만 다음 단계의 입력으로 쓰세요.
4. 훅·아웃라인 선택, 최종 대본 확정, 유료 생성, 공개 게시처럼 승인이 필요한 지점에서는 멈추세요. 내가 승인하지 않았는데 스스로 승인했다고 처리하지 마세요.
5. 단계별 집필은 승인된 아웃라인 구간 순서대로 하세요. 이번 구간에 해당하는 참고 예문, 앞 구간 마지막 문단, 이미 쓴 사실, 아직 풀지 않은 질문을 함께 읽고 이어 쓰세요.
6. 낭독 본문에는 실제 들려줄 이야기만 넣으세요. 제작·연출 설명과 출처·클립 ID는 별도 메모에 적으세요. 본문에서 ‘이 영상은’, ‘내레이션은’, ‘여기서 궁금증을 유발합니다’처럼 글 쓰는 방법을 설명하지 마세요.
7. 실제 외국인 발언·숫자·현재 사건을 만들지 마세요. 참고 자막은 말투와 전개의 예시이지 새 영상의 사실 근거가 아닙니다.
8. 자료 부족이나 검수 실패가 생기면 그 단계에서 멈추고 이유를 남기세요. 완료된 앞 단계나 실제 원문을 다시 만들지 마세요.
9. 새 대화나 예약 실행으로 이어가더라도 진행 상태와 직전 승인본을 읽고, 이번 run_id와 입력·출력 파일이 같은지 확인하세요.
10. 최종 보고에는 실제 파일·재생·게시 결과만 적으세요. 계획이나 성공한 도구 호출만으로 완성됐다고 하지 마세요.

아래 자막 7편 전문을 전부 읽어 주세요. 훅만 보지 말고 중간 문단의 말투, 연결 문장, 반전, 마지막 회수까지 봐 주세요. 각 편의 시작·끝과 실제 읽은 범위를 기록하고, 자료가 잘렸으면 분석을 시작하지 말고 알려 주세요. 자동자막의 오탈자나 참고영상 속 숫자를 검증된 사실로 취급하지 마세요.

## 3. 훅·전개·계속 보게 만드는 문장 분석

이 소스 내용을 제대로 분석해 주세요. 훅, 전개, 계속 보게 만드는 요인이 특히 중요합니다. 각 편에서 시작 훅, 배경, 의문, 갈등, 근거, 비교, 반전, 감동, 회수 역할의 실제 문장과 위치를 뽑아 주세요. ‘호기심을 만든다’ 같은 추상 설명으로 끝내지 말고 어떤 문장 뒤에 어떤 정보가 이어지는지 보여 주세요.

산출물: 역할별 실제 예문·문장 위치·전개 연결표
통과 기준: 요약만이 아니라 원문 예문이 실제 포함됨

## 4. 새 주제·실제 해외반응·날짜 확인

이미 한 주제는 빼 주세요. 폴란드는 이미 했다고 GitHub 사용 기록에도 남기되, 이번에는 게시 승인 전에 수정안을 먼저 보여 주세요. 실제 쓸 수 있는 영상·원음·기사로 새 주제를 고르세요. 과거 사건은 날짜를 확인하고 최근 사건과 자연스럽게 연결하되, ‘지금 과거 이야기를 합니다’ 같은 어색한 문장은 넣지 마세요. 젠슨 황·HBM처럼 최근 이슈로 연결할 내용은 현재 근거를 따로 확인하고, 미리 정한 결론에 맞춰 사실을 바꾸지 마세요.

산출물: 후보·제외 사유·출처·날짜·실제 클립 목록
통과 기준: 실제 사용 가능 여부와 해외 평가 주체 확인

## 5. 실제 외국인 호평으로 훅 후보 만들기

첫 훅이 진짜 중요합니다. 외국인이 한국을 칭찬하거나 놀라는 실제 영상으로 시작하고, 한국에 대한 호평과 궁금증을 연결해 주세요. 시작 클립은 약 1~4초씩 2~4개를 후보로 잡고 원문·번역·IN/OUT을 붙이세요. 훅 문장 다섯 개로 된 서로 다른 후보 세 개를 만들되, 실제 발언을 지어내지 마세요.

산출물: 훅 3후보·각 5문장·실제 클립 근거
통과 기준: 선택 전 다음 집필로 넘어가지 않음

## 6. 17분 아웃라인 후보와 승인

주전개 1종과 보조전개 1~2종을 골라 서로 다른 아웃라인 세 개를 보여 주세요. 기존 8구간 승인 구조가 있으면 유지하고, 7단계 집필로 바꾸려면 구간 대응을 먼저 보여 주세요. 각 구간에 실제 클립·질문·답·다음 궁금증·감정선을 연결하세요. 중반과 후반의 반전은 서로 다른 새 정보여야 합니다. 최종 대본은 아직 쓰지 말고 선택을 받으세요.

산출물: 아웃라인 3안·클립 연결·감정선

승인된 전체 아웃라인을 유지하면서 이번 구간만 써 주세요. 자막 7편 중 이번 역할에 해당하는 실제 문장 예시를 먼저 읽고, 그 말투·호흡·연결 방식만 참고하세요. 줄거리와 사실은 이번 영상 자료로 새로 구성하세요. 앞 구간 마지막 문단, 이미 말한 사실, 아직 풀지 않은 질문을 확인해 반복과 모순을 피하세요. 낭독 본문과 제작 메모를 별도 필드에 쓰세요. 검수 통과 뒤에만 다음 구간으로 넘어가세요.

## 8. 낭독 대본의 제작·연출 설명만 제거

낭독 대본에 섞여 있는 제작·연출 설명 문장만 제거하세요. 예: ‘내레이션은 반전을 보여줍니다’, ‘영상은 질문을 던집니다’, ‘여기서 시청자의 궁금증을 유발합니다’, ‘이야기를 이렇게 정리합니다.’ 실제 사건·인물·발언·숫자·질문·반전 정보는 삭제하거나 새로 만들지 마세요. 필요한 연출 정보는 비낭독 메모로 옮기세요. 판단이 애매한 문장은 삭제하지 말고 검토 목록으로 분리하세요. 변경 전후와 이유를 따로 적고, 교정 설명을 다시 낭독 본문에 넣지 마세요.

산출물: 정리된 낭독본·이동한 메모·변경 내역
통과 기준: 제작 설명 혼입 0건, 사실 정보 손실 검사

## 9. 참고 문장과 의미 기반 1:1 검수

왼쪽에는 참고 성공 자막의 원문·ID·위치, 오른쪽에는 이번 대본의 적용 문장을 놓고 의미 기반으로 1:1 매칭해 주세요. 훅·질문·배경·위기·검증·반전·감동·회수 역할을 붙이세요. 질문은 노랑, 갈등·반전은 빨강, 근거는 하늘색, 호평·감동은 연두색으로 표시하세요. 가짜 해외반응, 다른 인물의 발언 합치기, 국내 자화자찬을 해외 평가로 쓴 부분을 점검하세요.

산출물: 1:1 검수표·수정 대본·근거 상태
통과 기준: 최종 대본 승인 전 TTS·편집 시작하지 않음

## 10. 승인 대본 TTS·즉시 미리듣기

최종 승인된 한국어 낭독 본문만 TTS로 합성하세요. 연출 메모·태그·영상 ID·출처 코드는 읽지 마세요. 청크별로 생성하고 실패한 청크만 재시도하세요. WAV·MP3·SRT와 실제 길이·누락·발음·내레이션 비율 검수 결과를 남기세요. 웹에서 1배속·1.5배속·2배속으로 바로 듣게 하고, 외국인 원음과 합친 편집 길이도 따로 계산하세요. 실제 합성·편집 전 정확히 17분이라고 단정하지 마세요.

산출물: 음성·자막·QC·실제 재생 길이
통과 기준: 기존 도구 재사용, 비용·서비스 변경은 별도 승인

## 11. 영상 장면표·컷·자료화면 편집

15~30초 장면표에 실제 클립 IN/OUT, 자료화면, 그래프, 줌·패닝, 감정, 출처와 권리 상태를 붙여 주세요. 실제 칭찬 원음 앞뒤로 같은 내용을 다시 해설하지 마세요. 외국인 원음 컷은 4초 이내를 지향하고, 전체 한국어 해설 음성 비율은 별도로 60% 이상을 목표로 하세요. 허구 재현을 실제 사건 영상처럼 표시하지 마세요. 편집표만 만든 상태와 실제 MP4 렌더 완료를 구분하세요.

산출물: 장면표·편집 타임라인·실행용 편집 프롬프트·렌더 여부
통과 기준: 영상·자막 싱크, 실제 컷·권리 확인

## 12. 영상 폴더마다 썸네일 3안

영상마다 기존 썸네일 문구·제목·이미지를 먼저 보고 새 버전 폴더에 완성 PNG 세 장을 넣어 주세요. 하나는 짧고 큰 문구, 나머지 둘은 긴 문구로 하세요. A·B는 잘난체 고딕, C는 카페24 써라운드입니다. 기본색은 노랑·흰색, 핵심 단어만 형광 하늘색으로 강조하세요. 얼굴은 자르지 말고 모든 안에 넣으세요. 실제 강조 대상에 빨간 정원형 또는 타원형과 물음표를 붙이고, 따옴표는 확인된 실제 발언에만 쓰세요. 핵심 답을 문구에서 미리 알려주지 마세요. 개별 PNG·편집 SVG·모바일 비교표·출처와 검수 기록을 저장하세요.

산출물: 폴더별 3안 PNG·SVG·비교표·문구와 제목
통과 기준: 얼굴·글씨 잘림, 실제 폭·정렬·강조 대상 검사

## 13. 대본·근거·미리듣기를 HTML로 묶기

아웃라인·대본·감정곡선·근거·1:1 검수표·썸네일·미리듣기를 HTML에서 보게 해 주세요. 단계마다 짙은 와인색과 딥그린 계열로 구분하고, 필요한 자료는 펼쳐 볼 수 있게 하세요. 대본+편집 타임라인+편집 프롬프트를 복사할 때 설명·버튼명·메모가 섞이지 않게 하세요. 실제 파일이 없는 기능을 작동하는 것처럼 꾸미지 마세요.

산출물: 실제 파일이 연결된 HTML 작업판
