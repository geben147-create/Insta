# 전개 10개 선택지

기존 HOOK_ARC_TYPES.txt의 전개 8종+9종 중 성격이 겹치는 유형을 묶어 10개 선택지로 정리한 편집안. 원본 전체를 대체하거나 새로운 성능 검증 결과를 뜻하지 않음.

## D01 편견 검증·재평가
기존 S01 편견 반전
편견과 실제 경험이 다를 때. 사실과 다른 편견을 일부러 만들지 않음.
의외의 실제 반응 → 기존 편견·불편 → 그 말은 사실일까? → 그렇게 알려진 배경 → 직접 관찰·반례 → 편견을 바꾸는 새 사실 → 처음 평가를 다시 판단

## D02 질문–답 사다리
기존 S02 질문-답 사다리
원인 설명·도시·기술·생활. 작은 답이 실제로 다음 질문을 낳아야 함.
큰 질문을 여는 장면 → 첫 번째 작은 의문 → 첫 답과 새 단서 → 그 답에서 생긴 다음 질문 → 두 번째 답과 검증 → 예상을 바꾸는 마지막 답 → 큰 질문 회수

## D03 결과에서 원인 역추적
기존 원인 역추적
인물·산업·역사. 원인과 결과의 날짜·선후관계를 검증.
결정적 결과 먼저 → 왜 이 결과가 나왔을까? → 이전 상황으로 돌아가기 → 결과를 막던 장애물 → 실제 원인과 자료 → 가려져 있던 원인 발견 → 그 선택의 의미 → 첫 결과를 다른 의미로 회수

## D04 같은 기준 비교·판정
기존 S04 비교 실험/비교 판정
교통·음식·가격·제품. 같은 조건이 아니면 국가 우열 판정 금지.
차이가 보이는 현장 → 무엇이 다른가? → 비교 조건·기준 확정 → A 관찰 → 같은 조건으로 B 관찰 → 예상과 다른 차이 → 판정과 적용 범위

## D05 외국인 반응 모자이크
기존 S05 반응 모자이크
서로 다른 실제 인물이 동일 사건을 평가할 때. 여러 사람을 한 화자로 합치지 않음.
실제 외국인 반응 1 → 공통 사건 설명 → 반응 2와 근거 → 서로 다른 평가 → 평가 차이의 조건 대조 → 여러 반응이 만나는 발견 → 처음 반응의 이유를 회수

## D06 뉴스·주장 탐정
기존 S06 뉴스 탐정
시사·과학·경제. 기사의 주장과 검증된 사실을 구분.
실제 뉴스의 뜻밖의 주장 → 제목만 보면 맞을까? → 발표 날짜·범위 → 원문·숫자·조건 확인 → 반론·빠진 조건 → 제목과 다른 실제 의미 → 확인된 결론과 남은 한계

## D07 역순 단서 퍼즐
기존 S07 역순 퍼즐
실제 체험·사건. 장면 순서를 바꾸더라도 인물·발언의 맥락을 바꾸지 않음.
결말의 한 장면 → 아직 모르는 핵심 의문 → 후반 단서부터 확인 → 앞선 단서·상황 → 단서가 어긋나는 지점 → 단서를 연결하는 실제 정보 → 첫 장면 재해석

## D08 작은 반전→큰 반전
기존 S08 두 개의 파동
기술·휴먼·체험. 두 번째 반전이 첫 정보를 반복하면 안 됨.
의외의 실제 시작 → 목표·기대 → 첫 장애 → 첫 새 정보로 부분 해소 → 해소 뒤 더 큰 질문 → 독립된 근거·장면 → 다른 정보로 두 번째 반전 → 두 반전을 묶어 회수

## D09 체험–관찰–새 발견
기존 체험 발견
여행·생활·음식. 영상에 없는 감각·표정을 지어내지 않음.
실제 체험 첫 반응 → 장소·인물·기대 → 직접 확인할 질문 → 보고 만지고 써 보기 → 실제 불편·뜻밖의 차이 → 다시 본 장점·새 사실 → 인물의 생각 변화 → 체험 첫 반응으로 돌아가기

## D10 인물의 선택·대가·변화
기존 인물 감정
스포츠·전쟁·가족·산업 인물. 실제 행동이 없는 감동 사연은 만들지 않음.
결과 또는 감정 행동 → 인물의 목표·관계 → 위기·대가 → 어떤 선택을 했을까? → 실제 행동·인터뷰 → 선택 뒤 달라진 상황 → 행동에서 드러난 의미 → 처음 인물·목표 회수
