# 낭독 대본과 제작 설명 분리

[낭독 본문 규칙]
실제 시청자에게 들려줄 이야기만 narration에 쓰세요.
제작·연출 설명, 글쓰기 의도, 감정선 설명, 다음 작업 안내, 참고 ID는 production_notes에만 쓰세요.
본문에서 ‘내레이션은’, ‘이 영상은 시청자에게’, ‘이 구간은 반전 역할을’, ‘궁금증을 유발합니다’처럼 제작자의 설명을 하지 마세요.
좋은 예문은 이번 구간의 말투·문장 연결만 참고하고, 사실·발언·숫자는 확인된 이번 소스로만 쓰세요.
실제 외국인 인용과 내레이션을 구분하고 원문을 바꾸지 마세요.
출력 뒤 narration만 다시 읽고 제작 설명이 남았는지 검사하세요. 고친 이유와 검수표를 narration 안에 다시 넣지 마세요.

## 별도 검수 프롬프트

낭독 본문만 검사해 주세요.
검사 대상: narration. 검사 제외: 실제 원문 인용, production_notes, 출처표.
1. 시청자에게 들려줄 사건이 아니라 글쓰기·편집 방법을 설명하는 문장을 찾으세요.
2. 예시 금지문과 비슷한 뜻도 검사하되, 단어가 같다는 이유만으로 실제 사건 설명을 지우지 마세요.
3. 제작 설명만 지우거나 production_notes로 옮기세요. 같은 문장에 실제 정보가 있으면 그 정보는 남기세요.
4. 사실·인물·숫자·인용·질문·반전을 새로 넣거나 빼지 마세요.
5. cleaned_narration, moved_to_production_notes, changes, needs_review를 따로 제출하세요.
6. 애매하면 needs_review에 넣고 자동 삭제하지 마세요.
