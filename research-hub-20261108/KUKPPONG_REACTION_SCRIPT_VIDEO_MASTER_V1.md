## 3. 장면 속 '몰입 장치'를 단락마다 하나씩
A: 원본 외국인 반응(증거) → 한국어 해설(맥락) → 작은 질문 → 다른 장면(답).
B: 익숙한 기대 → 실제 화면 → 부분 설명 → 예상 못 한 디테일.
C: 부정적 시선 → 본인 검증 → 반례 또는 수정된 시선. 다만 실제 인물이 입장을 바꾼 경우만.
D: 한국 대 외국 직접 비교는 조건 통제·취향 차이를 보여주고 한 나라 전체의 능력·국민성을 단정하지 않음.
E: 인물이 겪은 소소한 당황·유머·따뜻함과 다음 질문. 긴 교훈 강의 금지.
F: 도입 때 한 말을 후반에서 다른 의미로 회수.

문단 끝에는 **이 장면에서 시청자가 답을 얻은 것 / 다음 장면을 궁금해할 이유** 한 줄을 붙인다.
질문 답 개수는 실제 경쟁 영상 자막으로 실측해 보고하고, 새 대본에서는 강제 숫자가 아니라 자연스러운 질문의 이동만 설계한다.
원음 대사·번역이 해설보다 재미있으면 해설은 오히려 줄인다.

## 4. 말투
- 한국의 생생정보 프로그램처럼 또렷하고 활기차되 광고 과장 금지.
- 전문 말보다 시청자가 바로 그려지는 말, 한 문장에 정보 한 개, 질문 다음에 짧은 답.
- 감탄사·가짜 극찬·'전 세계 발칵'·'외국인 충격' 반복 금지.
- 고조회 원고의 문장 그대로 복사 금지. Script B의 질문→즉답→다음 질문, Script D의 TTS 단문, Script A/C의 중간 전환과 이미지 회수 같은 상위 기법만 사용.
- 교육은 주연이 아니라 양념. 금융·주식·ETF/코인은 주제가 직접 관련될 때 10~30초 한두 번으로 끝내고, 관련 없으면 0초. 금융상품 매수 권유는 제외.

## 5. 영상 편집 '형식' 프롬프트
목표: 실제 인물의 영상이 우선, 자체 한국어 나레이션은 장면을 이해시키고 증거를 점검하는 역할.
- 16:9 롱폼(필요시 9:16 리프레임), 1080p 이상. 지나치게 복잡한 화면 효과보다 원본 인물의 눈·표정·거리·음식 같은 시각 정보에 초점.
- 0~5초 강한 실제 표정/발언 또는 설명 가능한 화면, 5~25초 첫 의문과 맥락.
- 비트별 시각 소스: source_video_id, source_start_s, source_end_s, rights_evidence, crop_allowed, voice_kind, translated_subtitle, planned_narration, music, next_question.
- 원본 화면·실제 원음·한국어 해설의 점유율을 **각각** 기록. 한 영상이 화면 70% 해외 브이로그여도 음성 70% 원어는 아닐 수 있음.
- 눈에 띄는 반응은 음악을 잠깐 낮추고 외국어 원음+정확한 번역을 읽게 한다. 번역은 원문 시각과 일치.
- 한국어 나레이션이 같은 말을 그대로 반복하면 줄인다. 추가 맥락·반론·비교를 얹는다.
- 5~20초 단위로 장면 목적 기록. 짧은 컷 자체가 저작권 안전 근거가 되지 않음.
- 꼭 필요한 보조장면: 자체 지도·정보 그래픽·권리 확인된 한국 풍경·전후 비교·가상 재연은 명시.
- 다양한 카메라 움직임: 빠른 진입·거리/역/골목의 FPV·드론 느낌은 **직접 제작하거나 사용 허락이 있는 컷에서만**. 재촬영·AI 창작 B-roll은 실제 장면처럼 속여 쓰지 않음.
- BGM은 어쿠스틱·희망·긴장 등 서사에 맞춰 낮게, 원어/내레이션을 가리지 않게. 곡·음원 라이선스 별개 확인.
- 인물·장소를 배경으로 합성할 경우 재연·AI 이미지 표시와 실존 인물 권리 확인.
- 편집 마지막 실제 외부 영상 초수와 원음 초수를 다시 산출하고 사용 허락·원본 중요 부분/음악/유튜브 수익화 검수.
