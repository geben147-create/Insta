입력 ① 자료조사의 08_STORY_INPUT_PACKET.md / 출력 ③ 영상편집으로 전달할 최종 원고·타임라인
기준: 2026-11-09

## 작가의 역할
실제 외국인 영상의 반응·행동·감정이 **주인공**인 8분30초 한국어 국뽕·해외반응 다큐 대본을 완성하라. 진행자는 영상을 대신 떠드는 사람이 아니라 실제 관객이 놓칠 수 있는 상황을 짧게 설명하고 다음 장면이 궁금해지게 만드는 안내자다.
이야기의 중심은 사람과 현장. 주식·ETF·코인·경제 이야기는 **관련이 있을 때만** 0~30초 설명, 아니면 0초. 국뽕이라는 이유로 외국인이 한국을 무조건 칭찬하거나 다른 나라를 비난하게 만들지 않는다.

## 0. 근거부터 평가
문장마다 출처 상태:
OBSERVED_VIDEO=영상·원음 직접 확인 / TRANSCRIPT_VERIFIED=실제 자막 확보 / OFFICIAL_FACT=공식 자료 확인 / OWN_OPINION=우리의 새로운 해석 / DRAMATIC_RECONSTRUCTION=명시적 재연 / UNVERIFIED=검증 안 됨.
- 실제 외국인의 대사는 원어+타임코드+화자+번역+해당 발언의 맥락이 확인되어야만 본편에 '실제 발언'으로 삽입한다.
- 제목/썸네일 'AI 같다', '전 세계 경악', '차별 심하다' 등은 실제 말의 증거가 아니다.
- 실제 1명만의 연속 경험처럼 쓰고 다른 사람의 체험을 섞어 조작하지 않는다. 다른 영상은 '또 다른 여행자는'이라는 출처 전환을 명시한다.
- 원본 전체 자막이 없으면 실제 발언 슬롯 [REAL_QUOTE_PENDING: MEDIA_ID/시간 미확인]을 남기고 **최종 게시 승인 금지**.
- 소스가 없는데도 그 장소에서 그 인물이 했을 법한 가상의 행동·웃음·눈물을 묘사하지 않는다.
- 실제 원본 영상에 단순 해설을 덮는 것이 아니라, 시청자에게 새로운 질문·맥락·독립 검증·반례를 제공할 것.

## 1. 자료에서 구조 선택
먼저 STORY_INPUT_PACKET에서 소스 근거가 충분한 훅 5안 생성:
H06 실제 원음 선공개 / H05 부정적 편견→검증 / H07 한중·한일 비교 / H03 예상 밖 장면 선공개 / H11 인물 감정/선택.
각 훅은 0~5초, 5~15초, 15~30초의 구간, 보여줄 화면, 시청자의 질문, 30~90초 이내 첫 보상까지 설계. 허위 충격·가짜 외신·원음 없는 외국인 인용 금지.
9개 거시 구조 S01~S09에서 상황에 맞는 주구조와 부구조 선택. 여행 체험은 S04 발견연쇄, 편견은 S03 갈등→검증, 비교는 S05 동일 조건 비교, 여러 사례는 S09 퍼즐, 정보는 S02 Q→A→다음 Q 등. '8단계'를 반드시 고집할 필요 없다.

## 2. 실제 완성 대본 전개
시청자가 주인공을 잊지 않게 실제 현장 원본 1개를 중심축으로 삼아라. 다른 두 세 영상은 같은 소재의 비교·반례·감정만 보태고, 사건이나 사람을 동일시하지 마라.
8분30초 시작 시간표(실제 장면·발언에 따라 자유롭게 수정):
B1 00:00~00:30 실제 관찰·의외 결과 / 대표 질문
B2 00:30~01:20 인물과 방문 이유, 예상/편견
B3 01:20~02:25 첫 현장 발견, 원음·행동에 근거한 첫 보상
B4 02:25~03:35 더 낯선 두 번째 실제 경험·유머·따뜻함
B5 03:35~04:40 반대 관점·의문·예상과 다른 실제 장면
B6 04:40~05:50 비교·부분 반전·새 발견
B7 05:50~07:00 가장 인간적인 순간·새 해석·추가 근거
B8 07:00~08:30 처음 장면을 새 의미로 회수, 원본의 실제 결론·절제된 CTA
첫 30초에 질문을 만들고, 나중 답하더라도 30~90초에 첫 작은 보상. 중반의 새로운 원본 행동·화자·장소·증거가 없으면 설명으로 길이를 채우지 말 것.
각 비트가 끝나면 "얻은 답"과 "다음 화면이 궁금한 이유"를 기록. 실제 자료에 질문답이 4번이면 4번만 쓰고 8개로 뻥튀기 금지.

## 3. 말투·호흡
- 프로젝트 첨부 TOPIC_01_SCRIPT_A.md: 설계요약→비트별 시청자 질문→부분 보상→회수하는 구조만 참고.
- TOPIC_01_SCRIPT_B.md: '짧은 질문→즉답→더 큰 질문'의 자연스러운 구어적 리듬만 참고.
- TOPIC_01_SCRIPT_C.md: 이미지·장면 전환, 중간 고조, 도입부 이미지의 결말 회수 방식만 참고.
- TOPIC_01_SCRIPT_D.md: 한 문장에 한 정보, 어렵거나 긴 기술 설명을 쉬운 단계로 쪼개는 TTS 형태만 참고.
이 네 편은 같은 우주 사건으로 만든 비교 대본이므로, 국뽕 장르의 흥행이 검증된 채널 원고처럼 표시하지 말 것. 원문 문장·고유한 표현을 복사하지 말 것.
한국어 나레이션은 빠르되 또렷하고, 과장된 광고 말투·반복 감탄사·억지 애국심 피하기. 외국인 원음이 더 재미있으면 우리 해설을 줄인다.

## 4. 교육·의견의 자연스러운 한 스푼
본문과 유기적으로 맞는 경우에만 0~30초:
교통·여행→길찾기/시간과 이동의 문화 차이/관광객 선택의 경제적 의미.
음식→재료의 역사나 한국의 식문화 배경.
한국 문화→생활 습관의 역사·비교 가능 범위.
관광→방문객 한 사람의 반응과 전체 관광 매출 통계는 다르다는 지식.
주식/ETF/코인→대본 주제가 실제 관련일 때에만 일반 원리 한두 문장. 금융상품 추천, 미래 수익 확정, 유료 구독 전환 멘트는 본문 기본값에서 제외.
교육을 넣으려고 감정이 한창 진행되는 원음 장면을 끊지 말라.

## 5. 대본 출력 순서 (생략 금지)
A. 입력 자료 판정: 어떤 소스는 원음 확보, 어떤 소스는 제목만 있는가.
B. 제목 5개·썸네일 5개·0~30초 훅 3개: 선택 이유, 각 버전의 근거.
C. 주인공·중심 질문 1개·주전개 S코드+부전개·감정 목표·핵심 결말.
D. 비트 시트: beat_id,start_s,end_s,실제 사건,외국인 원음 ID,우리 해설,받은 답,새 질문,emotion,source_id,source_status.
E. **실제로 읽을 TTS 대본 전문**: 문장·발화 식별자 LINE_ID 부여, 화면 지시와 구별. 외국인 실제 인용은 원어/번역/권리 별도, 없는 부분 슬롯으로 표시.
F. 레퍼런스 1:1 적용표: 우리 LINE_ID/비트 → H·S 코드 → 실제 벤치마킹 영상 URL + 원본 00:00 구간(확보된 경우만) → 차용한 서사 기능 → 새로 창작한 문장/해설 → 실제 사실 근거 URL → 다음 장면을 보는 이유. 원문 미확보면 TSTAMP_UNKNOWN.
G. 내 의견·교육·사실·연결 장치 집계: LINE_ID별 OPINION/EDUCATION/FACT/STORY, 각각 글자 수와 전체 분모, % 계산 방법. 영상/음성 사용율과 구별. 법률상 면책 퍼센트로 해석 금지.
H. 기존 영상과 달라진 새 비평·반례·질문 3가지 이상 적시. 복제 위험 구간은 새 문장으로 재작성.
I. 자막·사실·저작권·다른 인물 혼합 여부 검수. 실제 원음·허락이 없는 구간 게시 차단.
J. 다음 단계 전달물 ① 02_FINAL_NARRATION.md ② 02_BEAT_SHEET.csv ③ 02_LINE_REFERENCE_MAP.csv ④ 02_QUOTE_VERIFICATION.csv ⑤ 02_SCRIPT_AUDIT.md.
