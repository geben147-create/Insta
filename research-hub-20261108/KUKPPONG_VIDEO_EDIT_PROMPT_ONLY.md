# 🎬 국뽕 외국인 반응 중심 영상 편집 프롬프트
목표: 한국어 나레이션에 해외영상을 억지로 덧대는 영상이 아니라, **실제 외국인 표정·행동·발언이 이야기를 이끌고 한국어 해설이 질문과 맥락을 연결**하는 리듬의 영상.

완성 산출물: [편집 플랜만 / 렌더까지]
## 편집 지시
1. 실제 외국인 원음이 있는 구간은 원문+정확 번역 자막부터 표시한다. 원어가 들릴 때 한국어 나레이션이 덮어 말하지 않게 한다.
2. 영상이 주인공. 원본에서 가장 흥미로운 인물의 시선·표정·몸동작·현장성을 먼저 보여주고, 한국어 해설은 필요한 한두 문장만 끼운다. 해설이 방금 본 반응을 반복 설명하면 삭제한다.
3. 오프닝 0~5초: 강한 실제 현장 반응 또는 원본 미확보 시 자체 제작한 명확한 질문 그래픽. 5~30초는 상황과 앞으로 볼 이유. 30~90초까지 첫 진짜 보상.
4. 영상 전개: 평범한 여행 출발 → 낯선 경험 → 질문→답→새로운 놀라움 → 반대 관점 → 실제 검증 → 작고 따뜻한 감정 → 처음 질문 회수.
5. 중요한 반응 장면은 컷 전환을 줄이고 얼굴·눈·음성을 살리며, 이동·탐색 구간에서만 빠른 카메라 이동·지도 전환·짧은 드론/FPV 등 활기를 준다. 실존 해외 원본의 카메라 움직임 조작으로 속임수 금지.
6. 모든 장면에 video_id, original_start_s, original_end_s, speaker, exact_quote, translated_text, rights_status, own_narration, frame_type, music_cue, subtitle, transition, why_next_scene 컬럼 작성.
7. 외국인 원본 화면 초 비중과 외국인 음성 초 비중, 한국어 내레이션 초 비중을 각각 산출. 기존 채널 화면 구성비가 60~75%였다는 이유로 제3자 영상을 무허락 60~75% 채우지 않는다. 원본 사용 허락 없으면 자체 촬영·허가 스톡·자체 그래픽·명시된 AI 재연으로 대체한다.
8. 한국어 발음 쉬운 TTS, 핵심 단어 2~5자 자막, 원음 번역 두 줄 이내 가독성. 긴 자막 벽 금지. 숫자·기관 이름·국적 강조보다 실제 반응이 읽히게.
9. 음악은 말 아래서 작게; 외국인 원음이 나올 때 더 낮추고 감정 전환에만 음량을 움직인다. 원음 포함 음악·방송 영상/사진도 별도 허락 확인.
10. 장면 하나가 끝날 때마다 시청자의 질문이 무엇이었는지, 지금 답을 받았는지, 다음 장면이 새로운 정보를 주는지 QA한다. 답 없는 오픈 루프를 남발하지 않는다.
11. 화면 속 각 인물의 말이 서로 다른 영상이나 날짜에서 나온 경우 반드시 별도 자막·장면 구분. 가짜 표정 연결·원본 오역·AI 음성인 줄 모르게 조작 금지.
12. 경제·주식 설명은 시청자가 갑자기 강의 채널로 넘어온 듯 느껴지면 제거. 선택적인 생활경제 설명은 10~30초 이내만.
13. 렌더 전 법률·플랫폼 권리 확인: 원작자 허락의 범위(상업적 이용/편집/번역), 원음·음악, 초상·개인정보, 국내법/각국법, YouTube 재사용 콘텐츠. 클립이 몇 초인지가 자동 허용 기준은 아님.
14. 권리 미확인·자막 미확인 자산은 발행본에 넣지 않고 BLOCKED_FOR_RIGHTS 표시. 원본 영상 삭제·이동·재인코딩/기존 Docker·GPU 운영 변경 금지.
15. 최종 8분30초 재생시간은 실제 TTS wav와 삽입 가능한 원음 초수를 합산해 확정. 미확보 발화 슬롯을 임의로 대사 창작해서 채우지 말 것.
