# 🧬 전개 DNA · 고성과 대본 재현 마스터 프롬프트 V2.0
업데이트: 2026-11-09 | 연구 허브: https://geben147-create.github.io/Insta/research-hub-20261108/#storydna
분석 기준: 실제 영상 / 자막 / 장면 타임코드 / 업로드 시점 / 경쟁 채널 성과를 분리한다.

## 이 프롬프트의 목적
특정 영상의 문장이나 대본을 베끼는 것이 아니라, 영상이 시청자를 다음 장면으로 이동시키는 **질문, 약속, 갈등, 반전, 보상, 회수의 설계 방식**을 분류하고 주제에 맞춰 새로 조립한다. 참조 대본 A/B/C/D는 서로 다른 독립 영상이 아닌 **한 주제(Swift/LINK)로 만든 4개 버전**이므로 그 공통점을 일반적인 유튜브 성공 법칙으로 단정하지 않는다.

- 🔴 사용할 수 있는 영상 권리: [직접 촬영 / 라이선스 / 서면 허락 / 별도 법률 검토 필요]
- 🔴 금지 요소·민감한 주장: [ ]

### 입력 상태 판정
1. 링크/스크립트/장면을 실제 확보했는지 표시한다. 영상 접근 불가·자막 없음·장면 미검토라면 분석 가능 범위를 축소한다.
2. REAL_VIDEO(영상 직접 관찰) / CAPTION(자막 직접 확보) / TITLE_ONLY(제목·메타데이터만) / INFERRED(가설) / UNAVAILABLE(확인 불가)를 각 주요 판단에 표시한다.
3. 자료에 없는 첫 30초 대사, 실제 시청지속률, 원음 비율, 외국인 발언을 창작하지 않는다.
4. 구독자 대비 배수(조회수/구독자)와 VPH(조회수/업로드 경과시간)를 혼동하지 않는다.

## 1단계. 고성과를 재정렬하는 관측 표
영상마다 video_id, URL, 채널, 게시시각·수집시각, 총조회, 구독, 길이, 댓글, 좋아요, 같은 채널 최근 10편 중앙조회, 첫 24/48/72시간 조회(있을 경우), 노출·CTR·유지율(있을 경우), 자막·원본 권리 상태를 수집한다.
- 관측값: 모두 소스와 수집 시각을 붙인다.
- 조회/구독 배수 = 총조회 / 관측 시점의 구독자. 작은 구독자 분모는 과대평가 위험.
- 누적평균 VPH = 총조회 / 게시 후 경과시간(h). 최근 1시간 성장속도가 아니다.
- 구간성장 VPH = (최근 조회수 - 직전 조회수) / 스냅샷 간격(h). 두 시점 모두 있을 때만 계산.
- 채널초과성과 = 해당 영상조회수 / 같은 채널 최근 유사 길이·주제 10편의 중앙조회(비교 가능한 표본 부족 시 UNKNOWN).
- 영상 연령: 0~7일, 8~30일, 31~90일, 91~180일, 180일 초과로 구간화한다. 3개월 이내라는 이유만으로 동일 조건이라 가정하지 않는다.
- 동일 채널·동일 기획·비슷한 시기의 성공/실패 쌍을 선정해 제목, 주제, 내용, 자료의 신선함 차이를 비교한다.
- 제목 속 사실과 실제 원본 사실을 검증한다. 영화 같은 반응·유명인 발언·논문을 출처 없이 사실로 취급하지 않는다.

### 비교 지표와 판단
A. 실측 조회순, B. 같은 시기 누적평균 VPH순, C. 최근 구간성장 VPH순(자료 있는 경우), D. 구독 대비 배수순, E. 같은 채널 기준 초과성과순을 **별개**로 낸다.
주제 신선함과 인과관계는 가설로 분류한다. 수치만으로 CTR, 만족도, 영상 길이 효과, 추천 알고리즘의 원인을 단정하지 않는다.

## 2단계. 첫 30초 훅 분류: 복합 코딩 허용
각 훅은 1차 유형 1개, 보조 유형 0~2개, 실제 문장, 0:00~0:30 타임코드, 이후 본문 회수 위치를 기록한다.

| 코드 | 유형 | 질문·기대의 생성 원리 | 예시 문장 골격(창작용) |
|---|---|---|---|
| H01 | 단문 질문 | 답변을 미룬다 | “왜 이곳만 달랐을까요?” |
| H02 | 불가능 조건 질문 | 서로 충돌하는 조건 | “돈도 기술도 없는데 어떻게 가능했을까요?” |
| H03 | 이상 결과 선공개 | 결과는 보여주고 원인은 숨긴다 | “결과를 보고 모두 같은 질문을 했습니다.” |
| H04 | 역설·통념 전복 | 상식과 현실이 정면 충돌 | “망한 줄 알았는데 매출은 오히려 늘었습니다.” |
| H05 | 부정적 편견·검증 | 강한 주장 뒤 직접 확인 | “한국은 불친절하다? 실제로 확인한 사람이 있습니다.” |
| H06 | 외국인 WOW 원음 | 관찰자의 생생한 놀람 | “진짜 이런 곳이 있어요?” → 실제 발언 검증 필수 |
| H07 | 양국 비교·승부 | 동일 기준 두 사례의 차이 | “같은 열차를 탔는데 왜 결과가 달랐을까요?” |
| H08 | 대결·도발·반격 | 압박·역습이 있는 갈등 | 비판 제시 → 반격 조건 예고 |
| H09 | 은유·비유 | 익숙한 말로 낯선 구조 이해 | “도시 전체가 거대한 대기실이었습니다.” |
| H10 | 수치·데이터 이상치 | 숫자의 예상과 실제 차이 | “3년 전 0명이던 것이 지금은 10만 명입니다.” |
| H11 | 감정 인물·사연 | 개인의 선택과 상실·성취 | “그 사람이 마지막에 울었던 이유는…” |
| H12 | 새로운 논문·뉴스 | 최신 근거가 통념을 흔듦 | “새 연구가 기존 설명을 바꿨습니다.” |
| H13 | 시간 제한·카운트다운 | 늦으면 기회가 사라짐 | “시간이 사라지고 있었지만…” |
| H14 | 강렬한 영상 콜드오픈 | 장면이 먼저 증거 | 실제 화면 3~10초 + 맥락 질문 |

**훅의 형식과 실력은 별개.** 유형이 같아도 사실 근거, 말맛, 질문의 깊이, 화면 자체의 정보량이 다를 수 있다. 해설자가 만든 “외국인 반응”을 실제 원음처럼 꾸미지 않는다.

## 3단계. 중·장편 거시 전개 9개 공식
단일 영상에 1개 주구조+1개 부구조를 배합한다.

| 코드 | 공식 | 거시 전개 순서 | 특히 맞는 소재 |
|---|---|---|---|
| S01 | 결과 선공개·원인 역추적 | 이상 결과→과거→원인→증거→현재 회수 | 뉴스·기술·의문 |
| S02 | 질문-답변 사다리 | Q1→A1+Q2→A2+Q3→A3→큰 답 | 해설·비교·과학 |
| S03 | 갈등·역전 3막 | 편견/도발→위기 확대→역전→감정 회수 | 토론·해외 반응 |
| S04 | 체험·발견 연쇄 | 출발→첫 충격→두 번째 발견→반전→변화 | 여행·음식·브이로그 |
| S05 | 비교 실험·판정 | 공정한 기준→A→B→의외 차이→조건부 결론 | 한중·한일 비교 |
| S06 | 작은 인물이 큰 결과 | 인물→욕망/곤란→선택→대가→변화 | 감동·역사 |
| S07 | 연구·증거 계단 | 기존 통념→새 연구→반례→수정 설명→생활 영향 | 논문·신기술 |
| S08 | 시간 압박·작전 | 목표→제약→계획→중간 실패→부분 성공→결말 | 구조·사업·기술 |
| S09 | 다중 사례 퍼즐 | 이상 현상 A/B/C→공통점 찾기→가설→반례→새 해석 | 경제·문화·국가 현상 |

무조건 8단계로 쓰지 않는다. 길이가 짧거나 해외 원본의 실제 말과 화면이 이야기 대부분을 이끌면 장면형·Q&A형이 더 알맞다. 깊이를 늘리는 대신 새로운 질문 또는 보상 없이 설명을 길게 늘리지 않는다.

## 4단계. 대본을 5~20초 단위로 다시 라벨링
각 구간의 시작/끝/화자/실제 대사/화면/원자료 URL/감정과 기능을 표기한다.
기능 코드: HOOK, Q_MAIN, Q_SUB, A_PARTIAL, A_FINAL, EVIDENCE, SOURCE_QUOTE, METAPHOR, COMPARISON, SETUP, CONFLICT, REVERSAL, REVEAL, RELIEF, COUNTERARG, CALLBACK, CTA, FILLER.
질문/답변 묶음별로 Q-ID, 답변 종료 초, 답변까지의 지연 초, 다음 질문의 출발 초, 답변 유형(완결/부분/미회수)을 기록한다. 질문 부호 없는 은유적 의문도 “암묵 질문”으로 별도 표기한다.
- Q&A 반복 수, 분당 질문 수, 미해결→해결 비율, 최대 답변 지연시간을 실제 자막으로 계산한다.
- 8~10개 질문을 매번 강제하지 않는다. 원본 8분짜리 인터뷰가 자연스레 4개의 질문으로 이어지면 4개를 사용한다.
- 초반 훅은 정답을 모두 공개하지 않지만 45~90초 이내에 첫 실질 보상을 줄 수 있는지 확인한다(고정 규칙 아님).
- 중간 25~40%, 50~70%, 75~90% 구간에서 새 증거·역전·부분 답·감정 회수 중 무엇이 있었는지 표시한다.
- 자막 원문과 장면 확인 전에는 추정치를 사실처럼 퍼센트 막대에 채우지 않는다.

### 화면·오디오 출처 분류
원본 해외 영상 / 방송·뉴스 / 외국인 리액션 / 스포츠·음악 / 자체 촬영 / 자체 그래픽·AI / 스톡·라이선스 / 기사·사진 / 미상.
음성은 한국어 해설 / 실제 외국인 원음 / 더빙·TTS / BGM·침묵 / 미상.
각각 **영상 화면의 초 비율**과 **음성 초 비율**을 따로 계산한다. 화면을 70% 외부 영상으로 채웠어도 내레이션 100%일 수 있다. 반대로 공연 리액션 90%인 영상은 자체 나레이션이 거의 없을 수 있다.
컷 길이 중앙값, 소스별 점유율, 가장 긴 연속 클립, 최초 30초의 화면 출처, 다른 원본 소스 수, 출처 표기, 허락 상태를 기록한다.
모든 클립 길이 수치는 **관찰용 통계**일 뿐 법률상 허용 기준이 아니다.

## 5단계. 재미가 발생한 이유를 원인 후보로 분리
조회수의 원인 단정 금지. 최소 4가지 대안 가설을 비교한다.
- 소재 신선도: 최근 연구·뉴스·새로운 국가 비교인가? 이전 3~6개월 동일 제목·비교 조합의 선행 사례 수를 조사한다.
- 원본 영상의 힘: 표정·행동·공간·전후 변화가 자막 없이도 이해되는가? 실제 장면만의 WOW가 있는가?
- 전개 설계: 질문/답의 밀도, 부분 보상, 주제의 반전, 도입 콜백이 충분한가?
- 패키징: 제목의 약속과 본편 증거가 일치하는가? 썸네일과 초반 30초는 실제 확인 가능한가?
- 규모·시점·플랫폼: 구독자, 개설일, 업로드 나이, 관심 뉴스 주기, 채널 내 기준 성과 차이는 무엇인가?
- 반례 분석: 같은 채널의 유사한 제목·대상인데 성과가 낮은 영상은 무엇이 달랐나?

표시: OBSERVED(실측) / SUPPORTED(근거 보강) / HYPOTHESIS(가설) / UNKNOWN(확인 불가). 예: “한·중 고속철 비교가 드물어서 성공”은 검색량/선행 영상 수 검증 전 HYPOTHESIS다.

## 6단계. 새 영상용 구조를 선정하는 방법
1. 새 주제의 주인공(사람/문제/장소/현상), 신선한 증거, 시각적 장면, 갈등/반론을 정리한다.
2. H01~H14에서 4안(상반된 전략)을 만들고, 구체성·사실성·시각화·보상가능성을 0~5 평가한다.
3. S01~S09에서 상위 3안과 이유·약점을 제시한 뒤 최종 주구조를 선택한다.
4. 8분30초라면 아래 8비트를 **시작점**으로 활용하고, 소재가 요구하면 비트 수를 줄이거나 늘린다:
   B1 00:00~00:30 훅/질문, B2 00:30~01:30 첫 사례와 맥락, B3 01:30~02:35 통념 또는 난제, B4 02:35~03:40 새로운 근거, B5 03:40~04:50 반론/위기, B6 04:50~06:15 핵심 반전·증거, B7 06:15~07:45 두 번째 보상·진짜 이유, B8 07:45~08:30 회수·정직한 결론.
5. 각 비트 끝에 반드시 “시청자에게 지금 무엇을 알려줬고, 다음에 무엇을 궁금하게 만드는지”를 한 줄로 적는다.
6. 실측 시청지속률을 모르므로 “완주율 향상” 등 정량 효과를 예언하지 않는다.

### 제작용 체크리스트

## 7단계. 출력 규격(중간 산출물 생략 금지)
A. 입력 확인표(확보 자료 / 없는 자료 / 추정) + 소스 링크.
B. 실측 5개 순위표: 총조회 / 누적 VPH / 구간 VPH / 구독 배수 / 채널 초과 성과. 데이터 부족 시 결측 표시.
C. 같은 채널 성공-실패 쌍 3개 이상 비교표.
D. TOP5 영상별 훅 1차/2차 라벨, 원문 근거, 첫 30초 자막, 질문-답 수, 8비트 타임라인, 감정 그래프, 실제 화면/음성 비율, 권리 상태.
E. 14개 훅 중 4개 전략의 후보와 각 후킹 문장 0~5초 / 5~15초 / 15~30초.
F. 구조 3안 비교 → 선택 구조의 비트 시트(시간, 사실, 시청자 질문, 부분 답, 반전, 감정, 화면, 출처, 다음 연결).
G. **원본 표현을 재사용하지 않는** 독창적인 TTS용 전체 대본(타임코드, 한 문장 한 정보, 읽기 쉬운 한국어).
H. 영상 편집 인계: scene_id, start_s, end_s, narration, onscreen_keyword, visual_source, visual_rights, original_quote_verified, music_beat, sfx, subtitle, confidence.
I. 사실 검증표(주장, 근거 URL, 자료일, 사실/해석 구분, 반대 근거, 확인 필요).
J. 미해결·허락 대기 목록과 인간 승인 체크리스트.

## 8단계. 저작권·수익화의 독립 심사
벤치마킹과 원본 재사용을 분리한다. 기존 영상은 저작권 위험과 무관하게 **형식·전개 연구** 가능하나, 원본 영상을 실제 제작물에 붙일 권리는 별도로 검토한다.
- 몇 초 이하 안전, 화면을 좌우 반전하면 안전, 자막 넣으면 안전, 크레딧만 쓰면 안전 같은 기준을 만들지 않는다.
- 원본 3~6초 컷·해설 100%는 관찰된 편집 패턴이며 허락/공정이용 판정과 별개다.
- YouTube 재사용 콘텐츠의 수익화 기준과 각 원본의 저작권 법률 판정은 **서로 별개**다. 허락을 받아도 유튜브 재사용 콘텐츠 판단을 받을 수 있다.
- 국내외 최신 공식법률·플랫폼 정책을 확인하고, 외부 영상은 권리 증빙 상태를 라벨링한다.
- 공개 GitHub에 타인의 자막 전문, 원영상, 민감한 계정·연락처를 올리지 않는다. 공개 문서에는 요약·코드·통계·원문 링크만 남긴다.

## 기존 4개 테스트 대본에서 이식할 것
- A형: 전체 비트·구조와 검수표
- B형: 작은 질문 → 즉답 → 더 큰 질문으로 연결하는 **말맛**
- C형: 강렬한 장면, 반전 위치, 감정 회수
- D형: 한 문장 한 정보, TTS 발음, 쉬운 기술 설명
이 네 개는 **네 독립 채널의 조회 성과 근거가 아니라 동일 소재에 대한 편집 실험**이다. 새 연구가 모이기 전까지 범용 '성공 공식'으로 포장하지 않는다.
