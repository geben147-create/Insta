# 17분 국뽕 영상 방송형 자막·인포그래픽 디자인 시스템
사용자 업로드 방송 레퍼런스 15컷 + 확장 템플릿 3종. 흰색 HTML 작업판에 원본 이미지를 왼쪽, 유사 무료폰트·자간·크기·좌표·색상·그림자·애니메이션·복사 코드를 오른쪽에 배치했습니다.

- [HTML 작업판](./index.html)
- [18종 데이터](./designs.json)
- [17분 제작 큐시트](./17min_timeline_template.csv)
- 이미지: assets/D01.jpg ~ assets/D15.jpg (원본 스크린샷에서 영상 영역만 크롭, 3종 확장은 방송 원본 사진 없음)

## AI/Hermes 제작 규칙
1. 대본에 실제 TTS 시간, 문장의 역할, 출처 링크를 정리한 후 디자인 ID를 지정합니다.
2. 동일한 디자인 ID에 따라 designs.json의 x/y/w/h(%), font_size(px), letter_spacing(px), stroke_px(px), text_shadow 및 HEX를 1920x1080 영상 레이어에 적용합니다.
3. AI 이미지 생성으로 영상 텍스트를 재묘사하지 말고 실제 HTML/CSS 또는 자막 렌더 레이어로 적용합니다.
4. 출처 검증이 안 된 댓글(D16)·뉴스(D17)·통계 비교(D18)·문서(D11)는 공개 영상에 쓰지 않습니다. 가짜 해외 반응 생성 금지.
5. 15컷은 실제 방송 프로젝트 원본 파일이 아닌 이미지 화면 재현 기준이므로 글꼴 원본명·세부 픽셀은 추정입니다.
6. 방송 인물·장면·채널 로고는 저작권 및 초상권 검토가 별도 필요합니다. 이 레퍼런스는 스타일 연구용입니다.
7. 무료 유사 글꼴 확인: https://noonnu.cc/font_page/669 , https://noonnu.cc/font_page/374 , https://noonnu.cc/en/font_page/1254 .
