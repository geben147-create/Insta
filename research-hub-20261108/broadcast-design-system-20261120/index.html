① 사진 왼쪽 / 정확한 제작 규격 오른쪽

15개는 사용자 제공 스크린샷, 3개는 해외 댓글·언론·국가 비교를 위한 신규 확장 템플릿입니다. 오른쪽의 숫자는 1920×1080 영상 기준 시각적 추정치이며, 원본 방송 프로젝트 설정값은 아닙니다.

② 대본의 어떤 문장에 어떤 디자인을 쓸까?

기준은 단어 자체보다 문장의 역할입니다. 실제 인용·언론·댓글은 출처 확인 후에만 적용합니다. 같은 효과를 3번 연속 사용하는 것을 막도록 기본 교체 규칙을 둡니다.

내용 유형우선 적용예비 스타일판단 기준금지·주의
규칙 우선순위: 실제 댓글·뉴스·문서의 증거 표시 → 반전·큰 수치 → 감정·유머 → 일반 자막. 한 장면에서 메인 디자인은 1개, 보조 요소는 최대 1개가 기본입니다.

③ 17분 영상 기본 타임라인

실제 음성·컷의 타임코드가 생기기 전 단계의 권장 구조입니다. 훅 구간은 자극을 위해 가짜 반응을 만들지 않고 실제 외국인 영상과 검증된 발언을 우선합니다.

④ 17분 대본 붙여넣기 → 디자인 자동추천

아래는 서버 전송 없는 브라우저 내부 규칙 분류입니다. 원본 댓글·기사·수치를 자동 조사하지 않으며, TTS가 없으면 타임코드는 글자 수 비례 추정이므로 실제 영상 제작 전에 수정해야 합니다.

대본 입력

문단별 입력 또는 [00:24] 같은 시간을 붙여넣으세요. 한 줄이 길면 문장 단위로 분리됩니다.

아직 대본을 분석하지 않았습니다.

분류·컷 구성 규칙

훅 0:00~0:45

실제 발언/반응 → D07·D08 단어 팝업 → D09 핵심 질문. 감탄 도배 금지.

뉴스·댓글

원문 URL과 날짜 없으면 D16·D17 확정 불가. [근거 확인] 상태로 유지.

숫자·반전

동일 단위 비교는 D18, 충격 한 줄은 D12·D15, 일반 정보는 D01.

연속 효과 제한

2개 연속 같은 ID 금지 권장. 메인 문구 1~2줄, 장면당 1디자인.

중요: 실제 영상 TTS 타임코드를 가져오면 배정 결과의 추정 시작/끝 시간을 바꾸어 사용하세요. 이 앱은 영상 자체를 만들거나 MP3를 생성하지 않습니다.

⑤ 복사해서 Hermes·Codex 영상 제작에 사용하는 규칙

AI에게 “이 레퍼런스와 똑같이”라고만 전달하는 대신, 디자인 ID, 레퍼런스 경로, 폰트, 좌표, 색상, 효과, TTS 시간을 데이터로 주는 게 핵심입니다.

전체 시스템 프롬프트

제작 검수 체크
1 · 장면 구분
대본 문장·근거 출처·실제 TTS 구간·표시 디자인 ID를 먼저 확정합니다.
2 · CSS로 글자를 별도 합성
인물/배경은 영상 레이어, 글자/포스트잇/그라데이션은 HTML/CSS/캡션 레이어로 제작해 자간·크기·위치를 고정합니다.
3 · 샘플 프레임 확인
1920×1080 캡처와 원본 레퍼런스를 나란히 확인하고 글자 경계·시야 가림·안전 여백을 PASS/FAIL로 기록합니다.
4 · 최종 렌더 전 확인
실제 발언/출처, 폰트 사용조건, 자막 오탈자, 유튜브 정책·방송 영상 권리, 효과 과용을 점검합니다.

 
📌 원본은 사용자가 업로드한 방송 화면의 공부·스타일 참고용 이미지입니다. 레퍼런스 이미지의 방송사 로고·인물·장면을 본인 영상에 그대로 재게시하는 권리는 별도로 확인해야 합니다. 원본 방송의 실제 글꼴명은 검증되지 않았으므로 눈누에서 상업 사용 조건을 확인한 유사 무료 글꼴을 지정했습니다.
