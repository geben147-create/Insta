# 2026-11-22 썸네일·방송 자막 텍스트 공식 8종

기존 `thumbnail-analysis.html` 맨 위에 추가한 스타일 카드의 참고 이미지입니다.

- 8장: 영화 반응 2, 토크 자막 2, 금빛 1, 붓글씨 1, 번개 강조 1, 사선 경고 테두리 1
- 자막/제목의 유사 상업용 무료 글꼴 링크를 3개씩 제공
- 실제 방송 원본 폰트/편집값은 확인할 수 없어 유사 후보 및 캡처 기반 근사 색상/크기 표기
- 이미지·글씨 배경을 새로 생성하지 않고 텍스트/효과만 오버레이
- 대본 기반 문구로 바꿔 사용하는 한 줄 프롬프트 복사
- 각 참고 사진은 사용자가 제공한 화면을 비교 목적으로 크롭한 파일이며 저작권·사용권과 별개
- 검정·노랑 안전 경고 스트라이프는 CSS의 repeating-linear-gradient(135deg,#FFED00 0 24px,#080808 24px 48px)로 재현
