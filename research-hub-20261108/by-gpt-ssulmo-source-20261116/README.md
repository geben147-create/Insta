## 완료로 간주하지 않는 항목
- **각 편의 실제 최종 낭독 시간 17분은 검증 전입니다.** 지금은 최종 17분 완성 원고가 아니라 분량 확대와 자료 확인을 위한 8구간 대본 초안입니다.
- 10편 × 7개 실제 해외 긍정 **영상 원음**은 확보하지 못했습니다. 특히 ep04, ep05, ep07은 해외의 주관적 긍정 평가 음성이 아직 부족합니다.
- 일부 중국 SNS 자동 자막은 실제 음성을 재대조하지 않았습니다. 자동 번역 오류가 있을 수 있습니다.
- 각 컷의 정확한 원본 MP4 IN/OUT, 조회수·발행일, 원작자 사용 허락은 아직 확정하지 않았습니다.
- 영상 소스의 화면 40%/해설 60%와 **음성 나레이션 60%** 비율은 완성 영상에서만 실측 가능합니다.
- **Edge-TTS WAV·MP3·SRT 실제 생성·재생·검수는 미실시**. 그래서 완성 오디오 파일을 제공하거나 테스트 PASS로 표시하지 않습니다.
- GitHub Pages 배포 반영과 실제 브라우저 UI 렌더링은 별도 검증 필요. GitHub 저장소 파일 존재는 확인했습니다.

## 로컬에서 Edge-TTS 진행
Edge-TTS는 온라인 Microsoft 음성 서비스에 연결하므로 네트워크가 필요합니다. 먼저 이용 약관과 상업적 이용 가능 조건을 확인하세요.
1. `ep01.html`을 열고, **낭독 본문만 복사** 또는 **대본 TXT 저장**을 누릅니다.
2. 대본 내용을 사실 및 길이 검수한 뒤 승인된 최종 문장만 TXT로 보관합니다.
3. Ubuntu에 Python3, ffmpeg 설치:
   `sudo apt install ffmpeg python3-venv`
   `python3 -m venv .venv && source .venv/bin/activate && pip install edge-tts`
4. `tts_edge.py`와 TXT를 같은 폴더에 둡니다.
5. `python3 tts_edge.py ep01.txt --voice ko-KR-SunHiNeural --rate 1.2`
6. 생성 폴더의 `narration_master.wav`, `narration_final.mp3`, `narration_final.srt`, `QC_report.json`을 확인합니다.
7. 작업판의 **완성된 MP3 파일 선택**에 생성한 MP3를 연결하면 브라우저에서 실제 재생할 수 있습니다. 업로드나 GitHub에 자동 게시하지는 않습니다.

## 제작 책임과 정확성
- 한국어 대본은 원본 외국인 발언을 통째로 번역해 나열한 결과가 아니라, 출처 확인 사항을 토대로 만든 **독립 내레이션 초안**입니다.
- `ep08`, `ep09`, `ep10` 등 XHS ASR 원문에 시점이 있는 경우만 후보 위치를 기입했습니다. 타임코드는 자동 자막의 시작점이지 편집용 최종 IN/OUT이 아닙니다.
- 조회수 미확보 자료에 조회수를 창작하지 않았습니다. 30~60초 정보 전환은 완성 대본 단계의 필수 검수 항목입니다.
- 실제 인물의 고난·전쟁·가족 사건을 임의로 지어 실화로 제시하지 않습니다. 예시 영상은 화면에 'AI 재현' 표시 필요.
- 다른 사람 원음을 TTS로 재현하지 않습니다.
- 컷을 4초 이하로 나눈다고 자동으로 영상 저작권 사용 허락이 되는 것은 아닙니다.
- 기존 게시물을 삭제하거나 수정하지 않았으며 연구 허브에는 새 메뉴만 추가했습니다.
