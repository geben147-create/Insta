# STEP 2 · 훅·전개 설계
- 먼저 읽는다: 좋은 자막 예시 분석(fewshot/LEARNINGS.md), 훅 12종+14종·전개 8종+9종·실전 훅 22편(모음집 페이지), 대본 스타일 팩.
- 🌸 첫 0~30초: 외국인의 실제 호평 원음 2~3개 → 궁금증(질문 1개) → 통념 뒤집기 또는 결과 선공개. 훅 5문장을 쓴다.
- 🔵 초반에 "한국 너무 좋아요"류 호평, "속았어요" 같은 반전 한마디, 그리고 다른 나라(일본 등)와의 비교를 차례로 넣는다.
- 전개는 메인 1개 + 보조 1개만 고른다(예: 질문 사다리 + 체험 발견). 고른 이유를 한 줄로 적는다.
- 🔴 30~60초마다 새 정보·새 장면이 나오도록 질문→답→다음 궁금증을 잇는다. 판단이 뒤집히는 대목(Reframe)을 3~4번 둔다.
- 끝은 Triple Ending: 처음 질문에 답 → 정의를 한 번 더 바꿈 → 처음 장면·물건을 다시 불러 닫음. 마지막 문장은 답하고 싶은 질문.
- 문장을 베끼지 않는다. 예시에서는 기능(순서·호흡·말맛)만 가져온다.
