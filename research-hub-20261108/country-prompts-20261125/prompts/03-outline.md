# STEP 3 · 아웃라인·질문 회수

1. 확정 훅과 중심 질문, 검증된 근거표를 연결해 아웃라인을 쓴다. 외국인 실제 칭찬/비판 → 배경 → 오해·불편 → 새 근거·외국인 반응으로 반전 → {{TARGET_COUNTRY}} 사람들의 노력·저력·자긍심 → 최초 질문 회수가 이어지게 한다.
2. 구간마다 시작/끝 시각, 실제 사건, 내레이션 요지, 실제 원음의 소스 ID·원어·번역·IN/OUT, 화면 문구, 근거 URL, 감정, 열린 질문, 얻은 답, 다음 궁금증을 적는다.
3. 감정은 🟨 질문 / 🟥 갈등·반전 / 🟦 근거 / 🟩 호평·감동으로 표시한다. 감정 강도는 기획값이다. 측정된 시청자 반응으로 표시하지 않는다.
4. 숫자는 공식 자료를 우선하고 출처·날짜·역할(규모·비교·속도)을 적는다. ‘세계 최고’, ‘전 세계가’, 국가 전체의 우열은 해당 범위를 증명하지 못하면 쓰지 않는다.
5. 원음 한 인물의 체험과 다른 사람의 체험을 하나의 일처럼 섞지 않는다. 낯선 용어는 쉬운 말과 짧은 비유로 설명한다. 불리한 실제 평가도 반전의 근거와 함께 다룬다.
6. 약 1분마다 자료·영상·소재가 새롭게 바뀌도록 구성한다. 이것은 대본의 내용 배치다. 영상 편집·효과·렌더·TTS 제작 단계는 이번 결과물에 추가하지 않는다.
7. 내레이션 비율은 임의의 고정 목표로 강제하지 않는다. 현재 원고의 비율을 계산했다면 관찰값으로만 기록한다. 길이를 맞추려고 같은 칭찬·질문·해설을 반복하지 않는다.
