## STEP 4 · 대본 작성 — 국가·언어 적용 실행본

```
# STEP 4 · 대본
- 형식: episodes/<이름>/script_data.py 의 SEQ (예시는 episodes/ramen-20261115/script_data.py).
    ('S', 구간키, 화면 라벨)
    ('N', 내레이션 문장, 화면 문구 | 'chart:이름' | '"댓글 말풍선 문구"', 형광 태그 q|c|e|g|'')
    ('C', 소스키, IN초, OUT초, {{OUTPUT_LANGUAGE}} 자막, 형광 태그)
- 🔴🌸 외국인의 칭찬은 외국인의 실제 목소리로 증명한다. 내 해설은 배경·새 사실·의미를 잇고 
- 🔵 원음 앞에 소개 1~2문장, 원음 뒤에 의미 한 줄. 약 1분마다 무대(영상·소재)를 바꾼다.
- 🔵 {{OUTPUT_LANGUAGE}}는 말하듯 쓴다. 한 문장에 생각 하나. {{LANGUAGE_STYLE}}
- 🔵 불리한 평가(비싸다, 별로다)도 실제 발언이면 짧게 넣는다. 그 뒤의 호평이 더 믿음직해진다.
- 🔴 "영상으로 돌아갑니다", "댓글을 보겠습니다", "작은 질문을 드립니다" 같은 진행 설명 금지. ID·H/S 코드·제작 메모를 낭독하지 않는다.
- 클립은 자막 컷 경계에 맞춰 3~6초(평균 약 4초). 숫자는 READ 표에 {{OUTPUT_LANGUAGE}} 읽기를 적는다. {{NUMBER_READING}}
```

명령: `python3 -I bin/lint_script.py episodes/<이름>` (플랫폼 이름·헤지·메타·클립 길이·자막 일치 검사)  🔴🌸 첫 30초 {{TARGET_COUNTRY}} 호평, 외국인 원음 중심의 증거, 반복 질문·답, 반전, {{TARGET_COUNTRY}}의 자긍심이 실제로 전달되는지 본다. 🔵 첫 30초 안에 질문이 있는가 / 질문 사이 간격이 2분을 넘지 않는가 / 플랫폼 이름·헤지 문장이 0개인가.
- 🔵 원음 클립 프레임을 뽑아 남의 영상·광고가 섞이지 않았는지 눈으로 확인한다.   [https://geben147-create.github.io/Insta/research-hub-20261108/](https://geben147-create.github.io/Insta/research-hub-20261108/) 

### 실행본 추가 지시 — 보존 원문을 수정한 내용이 아님

- 대상 국가 {{TARGET_COUNTRY}}, 작성 언어 {{OUTPUT_LANGUAGE}}, 시청자 {{AUDIENCE}}, 주제 {{TOPIC}}, 목표 {{DURATION}}에 맞춘다. 이 문서는 실행용 파생본이며 사용자 STEP 4 보존 원문과 별도다.
- 오프닝 첫 1~2문장은 실제 외국인의 비판·부정 비교 또는 칭찬 원음으로 곧바로 시작한다. 위의 ‘원음 앞 소개 1~2문장’은 오프닝 이후 본문 클립에 적용한다. 첫 30초 안에는 {{TARGET_COUNTRY}}의 호평/긍정 반전 근거와 질문을 넣는다.
- 해설은 확인된 배경, 새로운 사실, 앞뒤 발언의 의미를 잇는다. 원문에서 ‘잇고’로 끝난 표현은 보존본에서 고치지 않았다. 원음의 칭찬을 같은 뜻으로 반복 낭독하지 않는다.
- 검증된 원음·화자·원문 자막·번역·타임코드가 있는 발언만 실제 인용으로 사용한다. 확보하지 못한 슬롯은 미확보라고 표시하고 별도 검수표에 남긴다.
- 실제 불만과 좋은 평가를 모두 문맥 그대로 사용한다. 서로 다른 사람의 말을 한 사람이 말한 듯 이어 붙이거나 반대 뜻으로 자르지 않는다.
- 질문→부분 답→새 궁금증→후반 회수의 연결과 선택한 감정선을 유지한다. 해설/원음 고정 비율을 맞추기 위해 근거 없는 문장을 늘리지 않는다.
- 원문·번역·창작 내레이션·화면 문구·실제 댓글을 구분하고, 검증 전 주장을 단정하기 위해 헤지를 삭제하지 않는다. 불확실한 주장은 검증하거나 본문에서 빼고 검수표에 남긴다.
- {{OUTPUT_LANGUAGE}} 출력에 맞게 C 자막과 READ를 작성한다. 한국어 어절 수와 종결어미 예시는 한국어에만 적용한다. 원본 .ko.srt 파일명·원어 발언·인용 출처는 국가/언어를 바꿔도 수정하지 않는다.
- 완성 후 제목·썸네일 문구는 STEP 5에서 대본과 한 쌍으로 작성한다. 이 단계에서 영상 편집·효과·TTS·렌더 제작은 하지 않는다.

출력: (1) 전체 SEQ 대본 (2) READ 숫자 읽기 표 (3) 실제 인용의 소스·화자·원문·번역·IN/OUT 대응표 (4) 질문·반전·감정 회수표 (5) 미확보·검수 결과.

명령 실행 상태: 위 lint 명령은 해당 파일이 있는 로컬 제작 작업실에서만 실행한다. 현재 확인한 GitHub 저장소에는 bin/lint_script.py와 예시 script_data.py가 없다. 파일 확인·실행 없이 검사 통과라고 보고하지 않는다. 실제 원음·프레임을 보지 않았다면 미확인이라고 적는다.
