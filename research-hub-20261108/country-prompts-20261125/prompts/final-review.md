# 최종 확인 · 대본과 제목 패키지

대상 국가 {{TARGET_COUNTRY}}, 작성 언어 {{OUTPUT_LANGUAGE}}, 주제 {{TOPIC}}의 결과를 아래 표로 확인한다. 아직 하지 않은 것을 완료로 표시하지 않는다.

- 국가와 언어: 호평·자긍심 대상은 {{TARGET_COUNTRY}}, 출력은 {{OUTPUT_LANGUAGE}}인가? 다른 나라의 고유 사실을 이름만 바꾸어 넣지 않았는가?
- 첫 1~2문장: 외국인의 실제 비판·부정 비교 또는 호평인가? 실제 원음·원문·화자·시간·URL을 대조했는가?
- 첫 30초: 질문과 {{TARGET_COUNTRY}} 긍정 평가/긍정 반전 근거가 있는가?
- 질문과 답: 질문 사이 2분 초과가 없는가? 질문·부분 보상·새 질문·마지막 회수가 이어지는가?
- 감정: 선택한 감정선과 실제 자료에 맞는 갈등·의심·호기심에서 증거와 반전을 거쳐 자긍심·감동까지 실제 사건으로 이어지는가?
- 해외 근거: 신규 출처 5개 이상·독립 해외 언론사 3곳 이상을 실제 확보했는가? 부족 수와 확인 수준을 적었는가?
- 역사·댓글: 최초 기원과 발전, 실제 댓글과 여론조사, 개인 후기와 국가 전체 판단을 구분했는가?
- 내레이션: 배경·새 사실·의미를 잇는가? 첫 1~2문장 실제 외국인 원음으로 시작하고, 이후 본문 원음 앞 1~2문장·뒤 의미 한 줄, 약 1분마다 새 소재가 있는가?
- 문장: {{OUTPUT_LANGUAGE}}의 자연스러운 구어체인가? 한국어일 때 한 문장 생각 하나·5~18어절·동일 종결어미 3연속 금지를 확인했는가?
- 진행 설명: ‘영상으로 돌아갑니다’, ‘댓글을 보겠습니다’, ‘작은 질문을 드립니다’, 낭독되는 ID·H/S 코드·제작 메모·플랫폼명이 0개인가?
- 불확실한 사실: 헤지를 지워 확실한 주장으로 만들지 않고, 근거를 보강하거나 해당 주장을 본문에서 뺐는가? 미확인은 검수표에 남겼는가?
- 형식: SEQ의 S/N/C, 원음의 자막 경계와 3~6초, READ 숫자 읽기, 원문/번역 대응을 확인했는가?
- 원음 프레임: 남의 영상·광고 혼입 여부를 직접 봤는가? 아직 보지 않았다면 미확인인가?
- STEP 4 원문: 사용자 원문 보존본은 그대로인가? 국가·언어 변환은 별도 실행본에만 들어갔는가?
- 제목·썸네일: 대본 뒤에 작성했고 제목·썸네일 문구가 한 쌍인가? 지정 규칙은 원본 링크를 참조했는가?
- 범위: 영상 편집·효과·TTS 제작·렌더 단계가 새로 추가되지 않았는가?

출력: 항목 / PASS·수정필요·미확인·해당없음 / 실제 확인 근거 / 남은 작업.
기존 명령 `python3 -I bin/lint_script.py episodes/<이름>`은 해당 파일이 있는 제작 작업실에서만 실행한다. 실행하지 않았다면 미실행이라고 적는다. 이 웹페이지는 프롬프트를 조립·복사할 뿐 영상·대본 제작이나 원음 검증을 자동 완료하지 않는다.
