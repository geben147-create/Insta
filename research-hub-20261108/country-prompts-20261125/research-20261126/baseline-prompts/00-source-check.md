# STEP 0 · 원본·자막·자료 확인

칭찬 대상 국가: {{TARGET_COUNTRY}}
작성 언어: {{OUTPUT_LANGUAGE}}
시청자: {{AUDIENCE}}
주제: {{TOPIC}}
목표 분량: {{DURATION}}

1. 기존 GitHub 자료와 이번 세션 자료집을 먼저 읽는다. 실제 영상, 원어 자막, 번역 SRT, 댓글, 기사, 논문, 전문잡지, 공식 통계, 과거 기획문을 서로 구분한다. 기존 자료는 지우거나 덮어쓰지 않는다.
2. reactions-downloads/subs의 한국어 자막(.ko.srt)이 있는 영상 수, 대상 국가, 분야, 조회수 기록 시점, 자막 큐 수, 마지막 OUT, 원본 URL, 파일 경로를 표로 만든다. 자료가 있는 것과 현재 제작 PC에 영상이 있는 것은 별도 상태다.
3. 영상 원본의 실제 파일 존재와 SHA-256을 대조한다. 송신측/수집표 해시와 현재 파일 해시가 일치한 것만 파일 검증 완료로 기록한다. 이 GitHub 웹페이지를 열었다는 이유로 제작 PC의 파일 검증이 끝났다고 하지 않는다.
4. {{TARGET_COUNTRY}}에 대한 외국인의 실제 호평, 비판·부정 비교, 감동, 판단 변화, 반전을 분류한다. 화자의 국적은 확인된 경우에만 적고, 언어·계정명만으로 국적을 확정하지 않는다. 촬영 장소와 평가 대상을 따로 적는다.
5. 원어 발언 / 저장된 번역 / 화면 글자 / 댓글 / 내레이션 창작문을 구분한다. 한국어 SRT만 있으면 ‘번역 자막 확인’이다. 원음 청취와 영상 프레임 대조까지 끝난 경우에만 ‘원음 대조 완료’로 올린다.
6. 원어 오인식이나 제품명 오역이 의심되면 원문을 남기고 별도 수정 제안 칸에 적는다. 없는 원음·시간·댓글·표정·장면은 만들지 않는다. 영상 제목을 실제 발언으로 사용하지 않는다.
7. 기존 회차 사용 기록을 영상 ID + 원본 URL + IN/OUT로 대조한다. 후보 / 구조 참고 / 대본 채택 / 미채택 / 확인 보류를 구분하고, 대본 채택을 완성 영상 사용으로 기록하지 않는다.
8. 원음 클립 프레임에서 원작자가 끼워 넣은 다른 사람의 영상·광고가 있는지 확인한다. 아직 눈으로 확인하지 않았다면 미확인으로 남긴다. 전체 ASR을 새로 돌리거나 원본을 수정하지 않는다.

출력:
- source_id, 국가, 실제 평가 대상, 확인된 화자, 원본 URL, 원문·번역, IN/OUT, 파일·해시, 확인 수준, 권리 상태, 기존 사용 여부, 보류 사유 표
- 사용 가능/번역만 확인/원음 미확인/미확보 건수
- 다음 단계에 넘길 근거 묶음과 누락 목록

기존 명령 참고: python3 -I bin/catalog.py
위 명령은 기존 제작 작업실의 실제 파일이 있을 때만 실행한다. 이 허브 저장소에서 명령 파일을 찾지 못했다면 ‘파일 미확인·미실행’으로 기록한다.
