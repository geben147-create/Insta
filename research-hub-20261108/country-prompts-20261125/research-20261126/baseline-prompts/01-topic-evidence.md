# STEP 1 · 주제 선정·해외 근거 보강

칭찬 대상 국가: {{TARGET_COUNTRY}}
작성 언어: {{OUTPUT_LANGUAGE}}
주제: {{TOPIC}}
목표 분량: {{DURATION}}

1. STEP 0에서 확인한 자료 안에서 주제를 고른다. 서로 묶이는 원영상 3~6개를 우선하고, 실제 호평·판단 변화·현장 경험이 중심인 주제를 선택한다. 이전 회차와 같은 주제·같은 장면만 반복하지 않는다.
2. 부정 평가가 전부인 소재는 긍정 결론을 억지로 붙이지 않는다. 실제 비판이 있는 경우 짧은 갈등과 반전의 출발점으로 쓴다. ‘{{TARGET_COUNTRY}}는 다른 나라에 비해 못한다’는 비교는 실제 누가 어떤 기준으로 말했는지 확인한다.
3. 해외 언론, 연구 논문, 전문잡지, 공식 통계, 전문가 발언, 현장 영상, 댓글을 보강한다. 목표는 회차별 신규 출처 5개 이상, 서로 다른 해외 언론사 3곳 이상이다. 실제 확보 숫자와 목표 숫자를 따로 적고, 부족하면 부족한 그대로 기록한다. 같은 통신사 기사의 전재는 독립 언론 근거로 중복 세지 않는다.
4. 모든 자료에 정확한 URL, 제목, 저자/발행기관, 게시일과 사건일, 확인일, 인용 구간·페이지·시각, 지지하는 주장, 반례·한계를 붙인다. 논문은 연관성과 인과를 구분하고, 통계는 기간·모수·비교 단위를 맞춘다. 현재 수치·순위는 최신 원문으로 다시 확인한다.
5. 역사 논쟁은 ‘최초 기원 → {{TARGET_COUNTRY}}에서 발전한 방식 → 현대 평가’를 분리한다. 문화의 기원과 이후의 기여를 모두 확인한다. 역사적 피해나 불리한 사실을 지워서 반전을 만들지 않는다.
6. 댓글 논쟁은 서로 다른 실제 의견과 앞뒤 문맥을 함께 확인한다. 댓글 원문·번역·작성일·링크·반응 수를 남긴다. 개인 후기를 전체 외국인의 판단으로 확대하지 않는다. 실제 댓글이 없으면 창작 댓글로 채우지 않는다.
7. ‘해외가 본 {{TARGET_COUNTRY}}’ 분석은 외신의 평가, 개인 체험, 여론조사, 산업 성과를 나눈다. 반대 근거도 기록하고, 긍정 결론은 자료가 지지하는 범위에 맞춘다.
8. Google Trends 24시간·7일 등 시의성 자료를 확인한 경우에만 기록한다. CTR·시청지속률·RPM·수익을 공개 조회수로 추정해 실제 측정값처럼 쓰지 않는다.

출력:
A. 주제 한 줄 + 고른 이유 + 제외한 후보와 이유
B. 실제 영상 3~6개 목록 + 훅으로 쓸 원음 후보
C. 회차별 근거표: 주장 / 원출처 URL / 출처 종류 / 원문 위치 / 최신 확인 / 반례 / 사용 위치
D. 역사·댓글·해외 평가 중 활용할 갈등과 근거 있는 반전
E. 신규 출처 수·독립 해외 언론사 수·미확보 항목

주의: 국가를 바꾸는 것은 조사 목표를 바꾸는 일이다. 다른 나라의 고유 지명·통계·인물·업적을 국가명만 바꿔 사실처럼 재사용하지 않는다.
