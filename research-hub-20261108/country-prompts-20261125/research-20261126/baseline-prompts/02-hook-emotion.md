# STEP 2 · 실제 원음 훅·질문·감정선

칭찬 대상 국가: {{TARGET_COUNTRY}}
작성 언어: {{OUTPUT_LANGUAGE}}

먼저 읽기: 보관된 GitHub STEP 2 원문, 참고 자막 R01~R07, 실전 훅 모음, 이번 세션 EP 기획 자료. 실제 확보된 문장과 미확보 원문을 구분한다. 참고문에서는 기능·순서·호흡·말맛을 분석하고 새 작품의 사실과 문장을 새 근거로 쓴다.

[첫 30초]
1. 첫 1~2문장은 반드시 외국인이 실제로 한 {{TARGET_COUNTRY}} 비판·부정 비교 또는 칭찬이다. 원어·번역·발언자·정확한 URL·IN/OUT·맥락·확인 수준을 붙인다. 실제 목소리가 핵심 증거다.
2. 비판으로 시작하면 첫 30초 안에 확인된 {{TARGET_COUNTRY}} 호평 또는 긍정 반전의 증거를 배치한다. 칭찬으로 시작해도 시청자가 궁금해할 질문과 이유를 곧바로 연다. 가짜 악평으로 분노를 만들지 않는다.
3. 훅은 5문장으로 쓴다. 실제 외국인 발언 1~2문장 → 그 판단을 흔드는 사실·차이 → 왜 그런 일이 생겼는지 궁금한 질문. 첫 30초 안에 질문을 넣는다.
4. 원음이 없으면 [실제 원음 미확보: 찾을 발언/맥락] 슬롯과 별도의 창작 내레이션 후보를 남긴다. 창작 후보를 외국인이 실제 말한 문장이나 원음 확보본으로 표시하지 않는다.
5. 훅 후보 3안을 비교하되, 가장 강한 말보다 본문에서 끝까지 증명할 수 있는 안을 고른다. 조회수 목표는 기획 목표이며 조회수 보장은 하지 않는다.

[전개·시청 지속]
- 메인 전개 1개 + 보조 전개 1개를 고르고 이유를 적는다.
- 30~60초마다 새 정보·새 장면·새 근거가 들어오게 질문 → 답 → 다음 궁금증을 잇는다.
- 질문 간격은 2분을 넘기지 않는다. 같은 질문을 말만 바꾸어 반복하지 않고, 답이 다음 더 깊은 질문으로 이어지게 한다.
- 30~90초 안에 첫 작은 보상, 중반 1차 반전, 후반 더 깊은 2차 반전을 둔다. 판단을 새로 해석하는 Reframe 3~4개는 자료가 뒷받침할 때만 쓴다.
- 반전 접속, 열린 질문의 회수, 숫자로 묻고 숫자의 의미로 답하기, 쉬운 비유, 감정 비트, 짧은 리캡을 각기 역할이 있을 때 사용한다.
- 끝은 처음 질문에 답하기 → 의미를 한 번 더 새롭게 보기 → 처음 장면·물건을 불러 닫기. 마지막 문장은 실제로 답하고 싶은 질문으로 쓴다.

[감정선 선택]
E01 억울함 역전형: 억울함 → 분노 → 의심 → 증거 → 통쾌함 → 더 큰 반전 → 자긍심
E02 역사 재발견형: 무시 → 역사 논쟁 → 과거의 시련 → 기술 발전 → 해외 인정 → 존경
E03 해외 댓글 논쟁형: 불쾌함 → 상반된 반응 → 직접 검증 → 예상 밖 결과 → 감탄
E04 불가능 극복형: 열세 → 절망 → 희망 → 다시 위기 → 기적 → 눈물
E05 장인 감동형: 무관심 → 호기심 → 수십 년 노력 → 위기 → 해외 인정 → 감동
E06 외국인 체험형: 편견 → 불편 → 놀라움 → 감탄 → 가치 발견 → 자긍심
E07 국제 평가 반전형: 비교 → 실망 → 숨은 통계 → 새로운 질문 → 두 번째 증거 → 통쾌함

자료에 맞는 주 감정선 1개와 보조 흐름을 고른다. 억울함·분노를 쓰는 경우 실제 사건과 발언에서 생기게 하며, 결말의 {{TARGET_COUNTRY}} 자긍심·애국심·뜨거운 감동은 사람들의 노력·시련·변화에서 나오게 한다. 모든 회차를 같은 감정선으로 억지 통일하지 않는다.
