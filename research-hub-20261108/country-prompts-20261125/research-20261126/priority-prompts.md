# 중요도순 보완 프롬프트 1~4

국가·언어 설정값은 화면에서 치환됩니다.

## 1. 수치·원출처·정책 기준부터 바로잡기

```text
[1순위 보완 — 수치·원출처·정책 기준]
대상 국가={{TARGET_COUNTRY}} / 출력 언어={{OUTPUT_LANGUAGE}} / 주제={{TOPIC}}

기존 STEP 0·1과 최종 확인에 다음을 추가하라.
1. 영상 URL/ID, 선정일·지표 수집일, 최근/전체기간 표본, 컷 로그·자막·분류 원자료를 연결하고, 직접 측정·제공 표 재계산·보고서 주장·미확인을 구분하라.
2. 비율의 분자·분모·단위와 단순평균/시간가중을 적어라. 화면 출처 비율, 실제 원음 시간 비율, 대본 발언 유형 비율을 섞지 마라.
3. 이번 20행 표시값의 전체10편 평균은 타인클립54.1%/71.6%, B-roll41.8%/24.1%, 자체의견22.6%/14.2%(쓸모왕/단골이슈)다. 첫60초 비율과 혼동하지 마라. 이 값은 표 재계산이며 영상 실측 검증이 아니다.
4. 저작권·사용 근거와 YPP 독창성 검토를 별도 표로 작성하라. 자체화면50%·원음10초·AI TTS·얼굴 비노출을 공식 통과/탈락 기준으로 사용하지 마라. 정책 주장에는 최신 공식 근거와 확인일을 붙여라.
출력: 근거 원장, 산식·분모 검산표, 정책과 내부 권고 구분표, 미확인 목록.
사용자 원문은 보존하고 정정은 별도 보완란에 기록하라.
```

## 2. 소스 역할·부족 자료 대안·회차의 새 기여

```text
[2순위 보완 — 소스 구성과 새 기여]
대상 국가={{TARGET_COUNTRY}} / 출력 언어={{OUTPUT_LANGUAGE}} / 목표 분량={{DURATION}}

기존 STEP 1·3에 다음을 추가하라.
1. 메인 증거 / 보조 비교 / 기사·이미지·댓글 배경 / 자체 설명의 역할표를 만들어라. 각 행에 고유 원본 ID·독립 원출처·확보 수·증명할 주장·사용 구간·권리 증빙·부족분을 적어라. 같은 영상의 여러 컷과 기사 전재를 새 독립 소스로 세지 마라.
2. 보고서의 메인3~4개·보조6~7개 등은 참고안이다. 필요한 근거와 실제 확보 수를 먼저 정하고 의무 수량으로 강제하지 마라.
3. 해외 비디오가5개 이하이면 분량 축소 / 자체 비교·배경 설명 보강 / 추가 조사 중 적합한 안을 선택해 이유를 써라. 원본 통재생이나 같은 칭찬 반복으로 분량을 채우지 마라.
4. 이번 회차에서 새로 검증·비교·설명한 기여를 한 문장으로 쓰고 해당 근거와 대본 위치를 연결하라. 권위 있는 매체의 이름만으로 사실 확인을 대신하지 마라.
출력: 역할별 소스표, 부족 자료 대응안, 회차별 고유 기여표.
```

## 3. 질문·판단 전환·국가 릴레이를 시간표로

```text
[3순위 보완 — 훅·질문·반전·시간표]
대상 국가={{TARGET_COUNTRY}} / 출력 언어={{OUTPUT_LANGUAGE}} / 목표 분량={{DURATION}}

기존 STEP 2·3에 다음을 추가하라.
1. 첫1~2문장은 실제 외국인 발언, 첫30초에는 대상 국가 호평의 근거와 답할 수 있는 질문을 둬라. 정체를 늦게 밝히는 콜드오픈은 자료에 맞을 때만 선택하고 숨길 정보·공개 시점·근거를 적어라.
2. 질문 간격은2분 이내로 유지하고, 별도로1~2분마다 기존 판단→새 증거→바뀐 판단을 점검하라. 접속어만 바꾼 가짜 반전은 만들지 마라.
3. 약1분마다 자료·인물·국가·매체가 바뀔 때 새 관점이나 독립 근거가 무엇인지 써라. 숫자는 규모→같은 조건의 비교→의미 순서로 설명하라.
4. 8~9분안과17분안의 훅·배경·본론·대비·결론을 대응시키고 선택 분량에 맞춰라. 첫 작은 보상은30~90초에 주고 마지막에는 처음 질문과 감정을 회수하라.
5. 화면 샷, 개별 원음 클립,10~40초 등 서사 증거 블록을 구분하라. 기존3~6초 클립 규칙은 보존하고 긴 연속 발언이 필요하면 문맥·필요성·권리·대안을 별도 검토하라.
출력: 질문/부분 답/새 증거/판단 전환/국가·매체 전환/마지막 회수/원음 길이 표.
화면 연출은 전달 메모로만 남기고 새 편집 실행 단계를 만들지 마라.
```

## 4. 대본 비중·해설 기여·제목 약속을 검수

```text
[4순위 보완 — 대본·제목·최종 대조]
대상 국가={{TARGET_COUNTRY}} / 출력 언어={{OUTPUT_LANGUAGE}}

기존 STEP 4·5와 최종 확인에 다음을 추가하라.
1. 사실 설명 / 번역·인용 / 자체 분석·의견 / 연결·기타를 문장 수 또는 발화시간 기준으로 분류하라. 분모를 밝히고 중복 계산 없이 합계를100%로 맞춰라. 보고서 비율을 의무 배분으로 강제하지 마라.
2. 내레이션 / 실제 외국인 원음 / 기타·무음의 음성표를 별도로 만들어라. 내레이터가 읽는 외국인 댓글은 ‘인용 대본+내레이션 음성’이다.
3. 해설마다 배경·새 사실·비교·전환·결론 중 역할과 새롭게 더한 의미를 적어라. 원음의 칭찬을 반복한 문장은 줄여라. 본문 원음 앞 소개1~2문장, 뒤 의미1줄과 오프닝 실제 원음 우선 예외를 유지하라.
4. 제목·썸네일 문구4쌍을 완성 대본 뒤에 만들고 각 약속을 첫30초와 본문 근거 위치에 연결하라. 썸네일 규칙은 기존 링크만 유지하라.
5. 대본 버전·자료 선정/번역/분석 과정·권리 증빙을 남겨라. 실제 Analytics가 제공되면30초 유지와 이탈 시점을 대본 가설에 대조하고, 없으면 측정 대기라고 써라.
출력: SEQ·READ, 대본/음성 비율표, 새 해설 기여표, 제목·썸네일 근거표, 미확인 목록.
영상 편집·TTS·렌더 완료를 대신 선언하지 마라.
```
