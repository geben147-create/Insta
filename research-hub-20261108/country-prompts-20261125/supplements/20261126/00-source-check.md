# 2026-11-26 연구 보완 · STEP 0 · 수치·출처·권리의 기준

1. 연구 자료마다 [영상 URL/ID·채널 ID·게시일·사건일·지표 수집일·표본 선정일·선정 기준·최근/전체기간 구분·원자료 위치]를 기록한다. 제목 요약만으로 특정 영상을 확정하지 않는다. 두 순위에 같은 영상이 있으면 고유 영상 수와 표의 행 수를 분리한다.
2. 수치는 [원자료로 직접 측정 / 제공 표를 재계산 / 보고서의 주장 / 미확인] 중 하나로 표시한다. 20편 원본·컷 로그·자막 타임코드·표본 라벨·Analytics가 없으면 실측 완료라고 쓰지 않는다.
3. 모든 비율에 분자·분모·단위·표본 수를 붙인다. 영상별 단순평균과 러닝타임 가중평균을 구분하고 최근 5편·전체기간 상위 5편·합계 10편을 섞지 않는다. 60장 표본의 이미지 분류 비율을 실제 재생시간 점유율로 바로 바꾸지 않는다.
4. 컷 분석은 원자료가 있을 때의 검산 참고로만 남긴다. N이 샷 수, L이 초 단위 길이라면 평균 샷 길이=L/N, 분당 샷=N×60/L, 내부 전환만 세면 분당 전환=(N−1)×60/L이다. 컷 정의·감지 방법/임계값·수동 확인·프레임 표본 추출 시각과 방법·로그 위치를 함께 적는다. 중앙값은 컷별 길이 목록으로 계산한다. 첫 60초는 개수와 전체 대비 비율의 분모를 별도로 쓴다.
5. 자산 원장에 [고유 원본 ID·재사용 횟수·권리자·이용 근거·허락/라이선스 증빙 URL/파일·허용 범위·표시 조건·확인일·미확인 사유]를 추가한다. 권리 상태와 외국어 청취/번역 확인 상태는 별도 열로 둔다.
