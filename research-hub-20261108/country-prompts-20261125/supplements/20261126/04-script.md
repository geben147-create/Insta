# 2026-11-26 연구 보완 · STEP 4 · 대본 분류와 새 해설 검수

기존 SEQ·READ 형식과 원문 보존은 유지하고 다음 검수표를 함께 만든다.

1. 대본 발언을 [확인된 사실 설명 / 외국 발언 번역·인용 / 자체 분석·의견 / 연결·기타]로 분류한다. 문장 수 또는 발화시간 중 무엇을 분모로 썼는지 먼저 쓰고 네 범주의 합이 100%가 되게 한다. 혼합 문장은 의미 단위로 나누거나 주된 기능 한 개만 부여해 이중 계산하지 않는다. 실제 발화시간이 없으면 예상 시간임을 표시한다.
2. 별도의 음성표에는 [내레이션 / 외국인 실제 원음 / 기타·무음]을 기록한다. 외국인 댓글을 내레이터가 읽으면 대본 분류는 ‘인용’, 음성 분류는 ‘내레이션’이다. 외부 화면 비율은 별도의 자산표에서 계산한다. 세 비율을 서로 대신하지 않는다.
3. 보고서의 인용 50~80%·사실 25~45%·의견 8~22%를 한 영상의 고정 배분표로 사용하지 않는다. 자체 의견 20%나 결론 1~2문장도 보편 상한으로 강제하지 않는다. 비율은 치우침을 발견하는 진단값이다.
4. 자체 분석·의견마다 [대본 위치·역할(배경/비교/전환/결론)·근거·새롭게 설명한 점]을 붙인다. 이미 원음으로 들려준 칭찬을 반복한 문장과 새 의미를 더한 문장을 구분한다. 의견을 사실이나 번역 자막으로 표시하지 않는다.
5. 실제 부정 평가도 문맥을 보존해 짧게 넣고, 이후 호평은 그 뒤에 실제로 이어지는 증거로 연결한다. 첫 30초의 {{TARGET_COUNTRY}} 호평·질문, 약 1분마다 새 자료, 질문 사이 최대 2분, 오프닝 원음 우선과 본문 소개/의미 연결을 시간표로 대조한다.
6. 원음의 원문·{{OUTPUT_LANGUAGE}} 번역·IN/OUT·연속 길이·증거 블록·권리 상태를 서로 연결한다. 의미 완결성이 3~6초와 충돌하면 예외 목록에 사유와 대안을 적는다. 원문 자체의 수치나 문장을 고치지 않는다.
7. SEQ의 N/C 구분과 q/c/e/g 태그는 역할 정보다. 화면 전달 메모에 내레이션 자막과 번역 자막의 구별 필요성, 인용 카드·댓글 원문·차트 수치의 연결을 적는다. 보고서의 하단15%·흰 자막바·브랜드 배지·색·폰트를 새로운 공통 디자인 의무로 덮어쓰지 않는다. 실제 디자인 작업은 기존 관련 규칙을 별도로 확인할 때 진행한다.
