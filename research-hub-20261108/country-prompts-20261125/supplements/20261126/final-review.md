# 2026-11-26 연구 보완 · 최종 확인 · 증거와 정책을 나누어 검토

[제작물 확인]
- 기존 검수표에 자료의 확인 수준, 비율의 분모, 소스 역할·부족분 처리, 첫 30초 약속, 질문/판단 전환 간격, 원음 블록과 클립 구분, 새 해설의 기여, 제목·썸네일 문구의 본문 근거를 추가한다. 통과/보완 필요/미확인/해당 없음과 근거 위치를 적는다.
- 대본 버전·원출처·번역 검토·자료 선정/분석 과정·권리 증빙을 제작 증거 목록으로 보관한다. 추후 실제 편집 프로젝트가 생기면 그 위치를 연결할 수 있지만, 이번에 실행하지 않은 편집·음성·렌더 파일을 완료 증거로 만들지 않는다.

[권리와 독창성 — 서로 다른 확인표]
① 권리표: 권리자·허락/라이선스 또는 적용을 검토한 이용 근거·사용 부분의 필요성·조건·증빙·미확인 항목.
② YPP 검토표: 이번 회차의 새 분석·유의미한 차이·원본 의존·여러 편 사이의 실질 차이·반복/양산 여부. 허락만으로 수익화 심사 통과가 보장되지 않으며, 외부 자료 비율만으로 특정 채널의 위반 여부를 판정하지 않는다.
- ‘자체 화면 50%’, ‘외부 화면 70%’, ‘원음 10초 미만’, ‘해설 오버랩’은 공식 안전선으로 쓰지 않는다. 내부 제작 권고와 정책 요건을 구분한다. AI TTS 사용이나 얼굴 비노출 자체를 일괄 수익화 불가 규칙으로 쓰지 않는다.
- 한국 저작권법의 현행 공정 이용 조문은 제35조의5다(2026-10-29 시행본 확인). 이용 목적·저작물 성격·사용 부분의 양과 중요성·시장 영향 등을 함께 검토한다. 제28조 인용도 목적·정당한 범위·공정한 관행을 확인한다.

[실제 통지가 있을 때만 확인할 대응 참고]
Content ID 주장, 저작권 경고, YPP 중지 예정/중지 통지를 구분한다. 유효한 삭제 요청과 경고, 단순 주장을 같은 것으로 취급하지 않는다. 90일 안에 저작권 경고 3회는 채널 해지 대상이다. YPP는 사전 항소 초대의 7일과 중지 후 경로의 21일을 구분하고 Studio의 실제 기한과 현행 공식 안내를 확인한다. 사전 항소 거절 후 같은 사안의 두 번째 항소가 가능하다고 쓰지 않는다. 한국어·일본어는 지원 항소 내레이션 언어이며 영어 자막·얼굴 출연을 일률 필수로 쓰지 않는다. 실제 제출이나 이의 제기를 이 프롬프트만으로 실행하지 않는다.

[발행 뒤 자료가 있을 때의 후속 검증란]
실제 Analytics가 제공되면 30초 시청 유지·주요 이탈/재시청 시점·평균 시청시간·동일 길이 비교군을 대본의 약속/새 증거 시점과 대조한다. 데이터 수집 기간과 변경 전후 조건을 기록한다. 공개 조회수나 컷 수만으로 인과 효과를 확정하지 않는다. 현재 자료가 없으면 ‘측정 대기’다. 이는 후속 기록란이며 새 편집 실행 단계가 아니다.
