## 3. 컷 배치
1. `ep0X-105cuts-audit.csv`를 읽는다. CSV 105행, 4초마다 정확히 1개의 영상/반응 편집 구간.
2. `GPT 나레이션`: `ep0X-narration-TTS.txt` 텍스트를 기존 로컬 TTS로 생성한다. 외부 API, 모델 설치, 전체 시스템 설정 변경 없음.
3. 강제 정렬로 문장 시작·끝 시간 확인. 4초보다 긴 나레이션은 의미를 유지하며 분절한다. 실제 길이를 420초로 조정할 때 인위적 단어 가속 금지.
4. `해외반응·원문`: 보유 영상과 SHA256 확인, 원본 ASR 중국어 직접 비교. 이용허락 전에는 외국인 자막 카드/허가 B롤. 사용권 확인된 영상만 4초 이내 사용.
5. 0–12초: **서로 다른 외국인** 한국 칭찬 실반응 3개를 연속 배치. 별도 영상 출처 ID를 항상 표시.
6. 12~20초: 진행자 해설로 **왜 서로 다른 의견이 나오는지** 중심 질문 제시.
7. 이후 매 20초마다 ‘왜? → 외국인 답/반대 → 부분 해소 → 다음 질문’을 이어 간다.
8. 80초마다 본문 화면 구성 스타일을 바꿔 지루함을 줄이되, 과도한 화면 흔들림은 피한다.
