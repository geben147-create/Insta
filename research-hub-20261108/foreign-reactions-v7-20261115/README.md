## 3. 재생 및 편집

1. 해당 회차 `ep01.html` 또는 `ep02.html`을 연다.
2. 첫 화면에서 **외국인의 실제 원어·한국어 초벌 번역·자막 시각**을 먼저 확인한다.
3. **TTS 전체 원고**에서 전체 복사 또는 TXT 받기. **음성으로 듣기**는 브라우저의 한국어 합성음이며 서버에서 생성한 MP3가 아니다.
4. **30컷 편집표**에서 완성 영상 시간·원본 장면 시작·자막·폰트·BGM·SFX·권리 상태를 확인한다. TSV 내려받기로 구글 시트에서 조정한다.
5. **SRT 가안**을 내려받는다. 20초 단락 내 약 42자 단위의 임시 자막이다. 최종 음성 싱크를 맞추려면 실제 TTS 길이 측정 후 수정해야 한다.
6. 실제 허락받은 원본만 편집기에 사용하고 검증·권리 모두 통과한 후에 공개한다.
