# 🎧 V8 EP01~03 · 합성 음성 공개 폴더

- **EP01.mp3 / EP02.mp3 / EP03.mp3:** Ubuntu의 Qwen3-TTS 로컬 합성 완료 후 생성·업로드하는 파일입니다.
- 현재 이 README와 manifest.json만으로는 MP3 재생이 되지 않습니다.
- 실행: \`bash research-hub-20261108/foreign-reactions-v8-20261115/tts/run_batch_mp3.sh --dry-run\`
- 합성+배포: \`bash research-hub-20261108/foreign-reactions-v8-20261115/tts/run_batch_mp3.sh --publish\`
- \`--publish\`가 성공하면 GitHub Pages에서 같은 경로의 MP3를 읽고 대시보드에 재생기가 표시됩니다.
- 내레이션은 대본의 한국어 해설만 합성합니다. 실제 외국인 원음은 인위적으로 재현하지 않습니다.
