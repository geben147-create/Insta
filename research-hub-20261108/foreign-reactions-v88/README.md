## 4. 영상·대본 공통 기준

- 한국 소개가 주인공이 아니라 **외국인이 실제로 한국을 어떻게 평가했는가**를 매번 출발점·감정 전환·결말에 배치.
- 사용자 내레이션 음성 **60% 이상**, 한 컷 최대 **4초**. 10분은 목표 러닝타임으로, 실제 TTS 강제정렬 후 컷 초수를 수정해야 합니다.
- 영상 사용 우선순위: **허가된 실제 원본 영상 > 실제 사진(줌 애니메이션) > 직접 그린 지도·표**.
- 영상 위 반투명 흰색 그래프/손글씨 오버레이 **1~2회**. 그 외는 실제 현장 영상 및 주제에 맞는 B-roll.
- V4 형식: 왼쪽 원고 강조 ↔ 오른쪽 원음·원본 위치·감정·사용권 등 **적용/보완/미적용** 항목. 브라우저 선택은 로컬 저장되며 원클릭 복사에 첨부.
- 예시 댓글은 언제나 **✍️ 재구성 질문 · 실제 댓글 아님**으로 표시.
- 원음과 ASR 번역·화자·원본 분초·사용 권리는 발행 전 대조. 4초 컷이어도 자동으로 저작권 허용이 되는 것은 아닙니다.
- 장면 편집 프리셋: 1920×1080, Pretendard/Noto Sans KR Bold 본문 56px / 외국인 번역 64px / 핵심 72px / 중국어 38px. BGM은 대본 음성보다 약 18~24dB 낮게.
