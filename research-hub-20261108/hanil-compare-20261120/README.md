# 한일 비교 · 신규 대본 / 신규 Qwen3-TTS 3종

생성일: 2026-11-20. 기존 MP3를 다시 모은 작업이 아니라 이번 요청에서 새로 집필하고 새로 합성했다.

- 결과 입구: https://geben147-create.github.io/Insta/research-hub-20261108/#workspace-new
- 구조: 문답디베이트 / 떡밥회수루프 / 하몬서클8(시청자 판단 여정)
- 각 MP3 약 10분20초. 17분 완성 MP4가 아니다.
- 실제 PCM 편집 구간 기준 나레이션 약59.982%, 원음 약40.018%. 자연스러운 해설 문단 사이0.18초 쉼을 해설 구간에 포함한다. VAD 발화활동 비율은 아니다.
- 설치된 로컬 Qwen3-TTS-Base + 기존 등록 voiceB. 최신 사용자 요청의 즉시 합성을 위해 선택한 실행 가정이며 별도 음색 선호 승인이 있었다고 기록하지 않는다.
- 새 TTS41개 발화. 공통 사실 문단은 이번에 한 번 합성하여 세 구조에서 공유했다. 도입·연결·회수와 원고/편집 순서는 세 안이 다르다. 비교 조건을 맞추기 위한 의도적인 공통 자료 사용이다.
- 실제 원본4개, 각 편111개 자막 행에 대응하는 원음 컷. 개인 발언을 국가기관의 입장이나 확인된 통계로 바꾸지 않았다.
- 새 문장 외국인 인용, 원음 TTS 위조, 일본인이라는 신원 설정, 발언자가 마음을 바꿨다는 설정은 만들지 않았다.

## 파일

`published/`: 실제 게시용 MP36개(혼합3+해설만3), 새 원고 TXT3, 타임라인 JSON3, comparison.json, comparison-data.js, qc.json, speech-qc.json.

`plan.json`: 최종 실제 사용 문장·출처·원본 시간코드. `tts/`: 이번 생성 WAV와 원시 WAV. `cuts/`: 원본을 수정하지 않고 뽑은 원음. `mix-qc.json`: ffprobe·디코딩·샘플 수·비율·해시 검증. `speech-qc.json`: 실제 합성 음성의 중요한 수치와 두 주요 원음의 독립 ASR 재확인 결과.

## 검수 범위

- 중요 낭독 수치(2025/139/한국4위/일본12위, 2024/1220/446/2.7배)와 주요 원음의 실제 단어를 새 ASR로 확인했다.
- 원본4개는 작업 시작 시 로컬SHA256을 남기고 작업 후 다시 대조하여 변경되지 않았음을 확인했다. 외부 전송 원장의 기대 해시와 대조했다고 주장하지 않는다.
- 원래 제공된 중국어 ASR·한국어 번역 초안은 독립적인 전 구간 감수 완료 자막이 아니다.
- 원본 촬영국가·화자 국적을 모두 독립적으로 확정하지 않았다. 중국어 화자를 일본인으로 소개하지 않는다.
- 전 구간 귀로 듣는 낭독 검수·원본 권리 확인·유튜브 공개 승인·완성 영상은 별도이다.

## 재사용 주의

최종 원고는 plan.json과 published/*.txt다. prepare.py는 최초 자료 준비 코드이며 최종 plan.json을 덮어쓰도록 무심코 재실행하지 않는다.

원래 TTS 도우미는 raw/<line_id>.wav가 있으면 문장이 바뀌어도 재사용한다. 문장을 바꾸면 해당 작업의 캐시만 별도 보관하고 재생성해야 한다. 이번 shared_factory 수정은 이전 WAV를 tts/first-pass-evidence/에 보관한 뒤 다시 합성했다.

기존 결과를 덮어쓰지 말고 다음 비교는 새 작업 폴더와 원장 항목으로 남긴다. 링크만으로 로컬 원본 영상이 다른 컴퓨터로 전송되지는 않는다.
