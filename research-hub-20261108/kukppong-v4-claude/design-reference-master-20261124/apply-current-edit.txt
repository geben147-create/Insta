- 언론 semantic_type과 댓글 semantic_type을 분리한다. 타이핑만 공유하고 출처 유형·카드형태는 섞지 않는다. 언론은 실제 기사 헤드라인·출처·참고 형광색, 댓글은 REF-23 악마 없는 흰 카드1개와 실제 원문·번역·확보된 좋아요가 중심이다. 캐릭터는 채널/영상별 선택이다.
- 기존 댓글 앱형/말풍선형/카드형 3종은 옵션으로 보존하고, 이번 선택 기준인 REF-23 악마 없는 흰 카드 형태를 기존 편집기에 연결한다. 기사 띠를 댓글 기본형으로 고정하지 않는다.
- 최신 V7 명세대로 해외 원문·중국어·일본어 글씨를 보존한다. 제거가 필요한 원본 하단 자막·로고만 정확한 영역에서 자연스러운 블러로 처리하고, 모든 글자를 OCR로 일괄 감지해 지우지 않는다. 이전 모자이크·전체글자 블러 지시로 되돌리지 않는다.
- 기존 보호 조건인 하단 자막 배치, 상단 임의 소제목·문장·로고 금지를 유지한다. 언론/댓글카드/VS/그래프는 기존 허용 영역을 사용한다. 이 조건은 제공된 Claude 요약에서 온 것으로 기록하고, 새로운 사용자 직접 인용으로 꾸미지 않는다.
- 글자·낱말 하나가 외롭게 떨어지지 않게 의미 단위로 줄바꿈하고 박스의 글씨 정렬을 확인한다. 기존 대본의 내용은 수정하지 않고 표시 방식만 교정한다.

[4. 배경·자료·그래프·불꽃]
- 뒤 영상은 계속 흐르게 한다. 글자와 전체 부모의 opacity를 함께 줄이지 말고 검정 반투명 배경 레이어와 글자 레이어를 분리한다. 흰 글씨에는 검정 반투명 배경, 검정 글씨에는 흰 배경이라는 후속 명세를 유지한다.
🌸기사·댓글의 가독성용 검정 배경은 불투명도40%를 시작값으로 하고35%/45%/55% 비교 시안을 만든다. 전체 영상을 상시 어둡게 하지 않고 해당 자료 장면에서만 필요한 범위에 적용한다. 이는 원본 캡처의 alpha를 측정한 확정값이 아니라 가독성 비교용 제안이다. 40% 불투명도는 뒤 영상 기여60%이고,55% 불투명도는45%다. 영상→영상용 색보정→검정dim→카드·형광→글자 순서로 합성한다.
- 대본/장면표의 통계·비교·증감·비율을 찾아 기존 그래프 후보 목록을 만든다. 실제 수치·기간·단위·출처를 연결한다. 후보마다 적용/미적용과 이유를 기록한다. 자료 부족을 숨기거나 그래프 수를 채우려고 숫자를 만들지 않는다.
- 기존 그래프의 막대/선/제목/큰 숫자/출처 디자인을 재사용한다. 기존 흰 선은 해당 legacy 그래프 스타일에서 유지한다. S의 새 통계 디자인은 별도 style_id·팔레트로 실제 장면에 연결하고, VS 빨강을 그래프 전역색으로 상속하지 않는다.
- 기존 효과 자산6장을 실제로 열어 투명도·파일상태·쓰임을 확인한다. 세로 불기둥=VS 분할선/옆, NO=부정/거절, 만화 테두리=놀람/감탄 가장자리, 아래 불벽=화남/샤우팅/좋다, 아우라=들어오는 사람 뒤, 번개=충격 보조. 사람 옆에 스티커처럼 붙이는 것으로 아우라를 대체하지 않는다.
🌸인물 마스크 뒤에 아우라를 합성하고 얼굴·자막을 가리지 않는지 검수한다. 사용처가 없으면 억지로6개를 모두 사용하지 않고 미사용 이유를 적는다.

[5. 초반 재미와 후반 연속성]
🌸예능감은 실제 발언→실제 반응→짧은 평가→근거 화면의 연결로 만든다. 다른 맥락의 놀란 표정을 해당 발언의 반응처럼 붙이지 않는다. 웃길 구간은 지정 평가/번개/라벨을, 근거를 보여줄 구간은 기사/댓글/그래프를 선택한다.
🌸초반0~12초는 컷0.8~1.8초, 필요한 강세 지점만115~122% 줌을0.18~0.28초에 적용하는 시작값으로 비교한다. 첫 질문이나 결과의 일부를 즉시 보여주고 설명을 연결한다. 회전·더치앵글·큰 효과를 모든 컷에 넣지 않는다.
🌸12~45초는 컷2~3.5초, 본문은2.5~4초를 시작값으로 한다. 반응 클로즈업은110~118%·0.18~0.3초부터 비교한다. 의미 있는 강조/카드/반응 이벤트6~10회/분, 큰 효과3~5회/분은 샘플 비교용 범위이지 의무 할당량이 아니다. 일상적인 컷 변경은 이 이벤트 수에 중복 집계하지 않는다.
🌸읽어야 하는 기사·그래프는5~8초 정도 유지하되 뒤 영상은4초 이하로 바꿀 수 있다. 자료 오버레이 유지시간과 배경 컷 길이를 구분하고, 실제 글자량에 맞춰 읽는 시간을 확보한다.
- 컷4초 이하라는 기존 조건은 유지한다. 이미 만들어진 대본·TTS 길이를 맞추려고 음성을 자르거나 다시 생성하지 않는다. 컷이 바뀐다는 이유만으로 매번 화면을 정지하지 않는다.
🌸후반은3~4초 단위의 자연스러운 컷을 우선하고 원본 기본속도1x, 동작 연결, 절제된 줌으로 안정시킨다. 일반 후반 컷에는 강제 프리즈·반복 프레임·불필요한 스피드램프를 넣지 않는다. 의도한 반전 효과만 별도 이벤트로 처리한다.
🌸필요한 디졸브는30fps 기준6~9프레임, 즉0.2~0.3초부터 비교한다. 실제 프로젝트FPS에 맞는 같은 시간 길이로 환산하며 모든 컷에 강제하지 않는다. 동작이 맞는 직접 컷이 더 자연스러우면 그것을 사용한다.
- 먼저 실제 소스·프로젝트·출력의 주FPS, time_base, PTS 연속성, 반복/누락 프레임, 컷 연결부를 확인한다. 무조건30 또는60fps CFR로 바꾸지 않는다. VFR/CFR 변환이 필요한지 증거를 보고 판단한다.
- xfade/디졸브가 클립 시간을 겹치므로 누적 겹침을 타임라인 계산에 반영한다. 음성·자막은 원래 절대 타임코드에 맞추고 후반으로 갈수록 TTS가 밀리지 않게 한다. 단순히 각 클립 길이를 더하여 전체 길이를 계산하지 않는다.
- 원음 전환·TTS 접합부도 듣고 확인한다. 영상 전환만 바꿨는데 소리가 잘리거나 반복되면 실패다.
💰🌸허가받은 자료는 원본 속도·대화 맥락을 보존하는 방향으로 편집한다. 좌우반전·크롭·배속을 권리 회피 목적으로 자동 강제하지 않는다. 허가 범위와 플랫폼 수익화 평가는 별개이며, 이런 변형만으로 안전이 보장된다고 보고하지 않는다.

[6. 검수와 결과]
- 먼저30초 샘플에서 문제 색/서체, 기사 연두·연노랑, 댓글 구분, 그래프, 기본/디자인 자막 교대, 자연스러운 전환을 확인한다. 원문이 요구한30초 샘플과 대표1편 검수는 둘 다 수행한다.
- 대표1편을 전체 렌더하고 마지막60초를 별도로 집중 확인한다. 기존 대본·TTS 해시 동일, 영상/음성 동기화, 프레임 정지·겹침·빈 화면, 자막 충돌·줄바꿈, 자료출처, 실제 사용 폰트·색을 검사한다.
- PNG 시안이 맞는 것으로 끝내지 말고 실제 인코딩MP4에서 같은 시점의 프레임을 뽑아 비교한다. 최종색이 달라지면 합성·색공간 변환·압축을 나누어 조사한다. 안티앨리어싱 경계 픽셀을 글자 원색이라고 측정하지 않는다.
🌸픽셀 검수는 오버레이 내부색과 최종 합성프레임을 별도 기록하고, 소스색/이미지실측/최종MP4측정을 구분한다. 비디오 압축 뒤 모든 픽셀이 HEX와 완전히 동일하다고 보증하지 않는다.
- 결과는 “직접 확인 / Claude 보고 / 추정 / 미구현”으로 분리한다. 실제 변경 파일, 원인, 변경 전후 프레임, 폰트 준비 상태, 그래프 후보·누락 이유, 대본/TTS 보존, 30초/대표1편/🌸후반60초 PASS·FAIL, 결과 경로를 제공한다. 실패한 항목을 성공으로 묶지 않는다.
- 수정 가능한 부분을 고친 뒤에도 남는 실패만 구체적으로 보고한다. 이미 정해진 색·기존 지시의 승인을 다시 묻고 작업을 멈추지 않는다. 새 제안은 모두🌸, 권리 관련 제안은💰🌸로 구분한다. 대표 검수 전50편 일괄 렌더는 실행하지 않는다.
[최신 실행 보완]
- P01~P04는 위 상태 기록에서 이미 처리된 웹 교정이다. 수신 환경의 코드가 같은 상태인지 확인하고 중복 패치를 피한다. 그 밖에도 실제 영상 결과와 사용자 규칙이 다르면 기존 렌더러·스타일 연결·폰트 로딩·자막 배타성·그래프·전환 코드를 필요한 범위에서 교정한다.
- 웹 P01이 색만 바꿨다는 사실을 T07의 폰트/외곽선/그림자 교정 금지로 해석하지 않는다. 실제 영상의 해당 스타일은 기존 지정 명세까지 맞추고 실제 렌더로 검증한다.
- 기존 T05 편집기 전체를 갈아엎지 않고 style_id/버전을 분리한다. 새 S/R을 기존 구조의 장면·스타일에 연결한다. 모든 참조를 매 영상에 강제 삽입하지 않는다.
- 경로·폰트·제작 자산·실제 통계가 없으면 해당 항목만 미확인/pending으로 기록하고, 확보된 입력으로 가능한 교정과 대표 검수를 진행한다. 없는 파일이나 실행하지 않은 렌더를 있다고 보고하지 않는다.
- 최초 사용자 승인과 프로젝트 규칙을 존중한다. 이미 정해진 색·캐릭터 선택·영상 교정에 대해 새 허락 절차를 만들어 작업을 멈추지 않는다.


===== S · 최신 수신 상태의 통계 실제 적용 =====

[통계·지도·숫자 디자인 추가 지시 — 기존 편집기에 붙이는 독립 모듈]

이 문서의 예시는 참고 이미지와 코드 모식도이며, 모식도의 수치는 demo로 표시한다. 최종 영상 적용 완료라는 뜻이 아니다.

이 지시는 기존 HumanTouch 편집기의 장면표·디자인 레지스트리에 추가한다. 새 편집기를 만들지 않는다. 기존 대본·TTS·발화 순서와 사용자가 지정한 자막 색/폰트를 변경하지 않는다. 기존 본문 지시 A/B/C를 대체하지 않고, 디자인 적용 단계 B의 통계 부록으로 적용한다.

1. 출처와 우선순위
- 최신 사용자 직접 지시 > 기존 사용자 직접 지시 > 확인한 참조 > 기존 디자인 > 🌸 제안 순서로 적용한다.
- 사용자 요구 정리, 실제 인용문, 레퍼런스에서 관찰한 사실, 새 제안, 미수신 자료를 별도 표기한다. 요약 문장을 사용자 원문이라고 부르지 않는다.
- 통계 REF-01~07의7장, 추가 REF-08~24의17장, GitHub 주소, REF-23 댓글 카드, REF-24 개구리167×116 시트를 받았다. 개구리 제작용 개별 고해상도/투명 이미지와 커피 남자 원본은 미확보/미수신이다. 없는 제작 자산을 생성한 대역으로 채우지 않는다.

2. 현재 7장 연결
REF-01: 흰 입체 지도+주황 핀+90%/15% 큰 숫자+장식 상승 블록.
REF-02: 호박색 유리 파이+큰 숫자+얇은 연결선.
REF-03: 흰 원형 분할+파란 발광 파이.
REF-04: 단계별 파란 유리 퍼널.
REF-05: 파란 유리 재질과 팔레트 견본.
REF-06: 유리 파이프와 리뷰/인용/사례의 과정 흐름.
REF-07: 여러 색의 유리 비교 막대.
각 장면의 의미에 맞는 모듈만 선택한다. 7개 스타일을 모두 매 영상에 넣거나 기계적으로 돌려 쓰지 않는다. 모든 원본과 필요한 디자인 영역 크롭을 문서에서 연결한다.

3. 디자인 구현에 필요한 데이터 조건
- 실제 장면의 값·단위·기간·분모·출처를 그대로 연결하고, 파이 각도·막대 높이·퍼널 전환율은 그 값으로 계산한다. 장식 블록은 장식 모드로 기록한다.
- 참고 이미지의 90%/1,100/30·70/퍼널·LOREM 수치는 영상 사실로 전용하지 않는다. 문서의 코드 모식도에 사용하면 demo로 표시하고, 자료 값이 없으면 숫자를 새로 만들어 채우지 않는다.

4. 팔레트와 재질
- 풀 파티 다홍·재능이 없는 그라데이션·VS 빨강·언론 연두/연노랑·기존 댓글색은 잠금 상태다. 통계의 파랑/주황으로 전역 덮어쓰기하지 않는다.
- REF-05의 인쇄 HEX는 #03195B / #0B2CB1 / #1951FC / #3781FC / #3781FC / #CBE9FD이다. 넷째·다섯째 중복과 보이는 색의 차이를 기록하고, 원본 제작값을 복원했다고 주장하지 않는다.
- 측정한 캡처 대표 RGB와 인쇄된 HEX를 별도 저장한다. 받은 GitHub 주소와 R 색상표 중 사용자 선택이 확인된 통계 역할을 연결한다. 썸네일/자막색을 통계 전체에 자동 치환하지 않는다.
- 🌸 유리 재질은 도형에 적용하고 숫자·단위·출처는 선명한 전면 레이어에 둔다. 광원 방향은 한 장면에서 통일한다.
- 🌸 기본은 투명 오버레이. 흰 유리 패널 78~90% 불투명도는 비교 시안일 뿐 자동 확정값이 아니다. 부분 감광이 필요하면 검정 20~35% 불투명도를 비교하고 글자와 형광 위에 덮지 않는다.

5. 가로·세로 별도 배치 — 이하 수치는 모두 🌸 시작 제안
- 가로 1920×1080: 통계 (x96,y64,w1728,h800), 출처 (96,876,1728,42), 주 자막 보호 영역 (96,940,1728,100). 차트 60%·옆 범례/큰 숫자 34%·간격 6%를 출발점으로 잡는다.
- 세로 1080×1920: 통계 (72,160,864,1320), 출처 (72,1496,864,76), 주 자막 보호 영역 (72,1596,864,164). 큰 숫자→주 도형→범례 순서로 재배치한다. 공식 플랫폼 안전영역이라고 부르지 말고 실제 게시 UI를 확인한다.
- 🌸 가로 큰 숫자 96~140px, 제목 48~60px, 항목 30~38px, 출처 26~30px.
- 🌸 세로 큰 숫자 120~176px, 제목 54~68px, 항목 40~48px, 출처 30~34px.
- 글자 크기 기준은 원본 해상도다. 가로 시안을 단순 축소/크롭해 세로에 맞추지 않는다. 넘치면 문구·항목 분리 또는 다음 카드로 해결하고 출처를 지나치게 작게 만들지 않는다.
- 숫자와 단위를 붙이고 의미 단위로 줄바꿈한다. 카드 안 제목은 가능하지만 상단 구석의 불필요한 로고·소제목은 추가하지 않는다.

6. 모듈별 실제 동작 — 수치와 동작은 🌸 제안
- 지도: 가로는 지도 왼쪽/숫자 오른쪽. 세로는 숫자 위/지도 중간/국가별 2열 항목 아래. 핀은 확인된 위치에 놓고 0.10~0.15초 간격으로 1회 등장한다.
- 큰 숫자: 0.5~0.8초 안에 최종 값으로 정착한다. 의미·분모·기간을 바로 옆에 둔다.
- 장식 상승 블록: 성장 이미지 보조용이라는 모드를 기록한다. 실제 시계열 모드는 축과 실제 높이로 분기한다.
- 유리 파이: 값에 맞는 중심각, 낮은 입체 깊이, 범례를 따로 배치한다. 0.75초 입장 후 정지한다. 비교 정확도가 중요하면 정면 또는 막대 비교안을 보여준다.
- 발광 파이: 발광은 흰 원반 위·숫자 아래. 조각 경계와 숫자는 선명히 남긴다. 무한 맥동은 OFF.
- 퍼널: 가로는 오른쪽 콜아웃, 세로는 각 단계 바로 아래로 메모를 이동한다. 폭이 실제 값 비례인지 장식인지 표시한다. 단계는 0.18~0.25초 간격으로 등장한다.
- 리뷰 과정: 가로는 좌→우, 세로는 위→아래. 글자를 회전하지 않는다. 수신한 REF-23 흰 댓글 카드와 별개인 과정 도식으로 사용한다.
- 컬러 막대: 공통 0 기준선·동일 깊이·동일 범주색. 가로 4~6개, 세로 3~4개를 출발점으로 하고 넘치면 나눈다. 0.65~0.9초에 실제 높이로 정착한다.

7. 자막·캐릭터·효과
- 통계 제목·큰 숫자는 통계 카드 내부 요소로 묶고 카드와 함께 입퇴장한다. 일반 상단 구석의 고정 소제목·로고는 추가하지 않는다.
- 기본 자막과 같은 발화를 전달하는 주 디자인 자막은 하나만 노출한다. 통계의 값/범례/출처는 정보 요소로 함께 보여도 된다. 평가 한마디를 또 겹치지 않는다.
- 최신 지시: 캐릭터는 채널별 기본 OFF. 사용자가 해당 영상/채널/구간에 요구할 때만 ON. 이전 카드 1개+캐릭터 1개 강제를 해제한다.
- 캐릭터 우선순위는 영상/구간 명시값 > 채널 저장값 > 기본 OFF이다. 요청된 캐릭터를 임의 생략하지 않고 통계 본체와 범례를 재배치해 공간을 만든다.
- 개구리 참고 시트는 수신했고 제작용 개별 자산은 미확보다. 커피 남자 원본은 미수신이다. 임의 대역을 생성하지 말고 그 슬롯만 pending으로 기록한다. 데이터·출처·자막을 가리지 않는다.
- 🌸 불꽃·번개·NO는 발화의 감정 조건이 맞을 때만 사용한다. 숫자 화면마다 강제하지 않는다. 자막 뒤/인물 뒤 배치와 필요한 인물 마스크 여부를 장면표에 기록한다.

8. 읽기 시간과 끊김
- 기존 컷 4초 이하 규칙을 임의로 삭제하지 않는다. 🌸 배경 컷과 정보 카드 지속시간을 분리해 단순 카드 4~6초, 여러 값 카드 6~8초를 출발점으로 삼는다. 기존 발화 길이가 짧으면 정보를 나누거나 항목을 줄이고 TTS를 바꾸지 않는다.
- 🌸 카드 입장 0.25~0.4초, 차트 정착 0.65~1초, 퇴장 0.2~0.3초. 읽는 구간은 도형/숫자를 안정적으로 유지한다.
- 특히 후반부에는 강제 프리즈·프레임 복제·속도 리셋·무한 회전으로 렉처럼 보이게 만들지 않는다. 자연 재생과 연속 타임스탬프를 확인한다.

9. 검수와 보고
- 장면별로 style_id/ref_id, 실제 데이터, 출처, 기간/단위/분모, 채널별 토큰, 캐릭터 ON/OFF, 기본/디자인 자막 모드, 가로·세로 배치, 시작/끝 시각을 기록한다.
- 🌸 먼저 가로·세로 대표 통계 장면을 기존 편집기에서 짧게 렌더하고, 실제 MP4의 시작/중간/끝 프레임과 연속 재생을 확인한다. 정지 이미지 검수만으로 모션 PASS라고 하지 않는다.

- 실제 편집기 접근 또는 렌더를 수행하지 않았다면 설계와 문서만 완료했다고 보고한다. 미확보 자산 때문에 받은 통계7장·추가17장·GitHub·댓글·캐릭터 시트의 정리나 가능한 장면 적용까지 멈추지는 않는다.

[🌸 모듈별 재질·빛·레이어 상세]

S01 입체 지도 + 위치 핀
🌸 흰 지도는 낮은 양각과 부드러운 접지 그림자로 입체감을 만든다. 숫자·핀만 주황 역할색. 나라 경계는 표면보다 조금 어둡고 얇게 유지한다. 핀과 지도 모두 같은 좌상단 광원을 받게 한다.
🌸 지도 접지 그림자→지도의 흰 표면→핀의 그림자→핀→지역 라벨 순으로 분리. 뒤 영상이 밝으면 부분 감광만 늘리고 지도를 검게 물들이지 않는다.
🌸 정적인 3/4 시점을 출발안으로 하되 읽는 구간에는 카메라 회전 없음. 입장 때만 100→102% 정도의 미세 접근을 비교한다.

S02 큰 핵심 숫자
🌸 핵심 숫자는 평평하고 선명한 전면 레이어로 둔다. 유리·금속 느낌은 뒤의 장식이나 옆 도형에 적용한다. 숫자 자체를 유리로 만들 경우에도 면 색을 충분히 채워 획이 사라지지 않게 한다.
🌸 큰 숫자와 단위를 같은 기준선에 두고 작은 단위는 숫자 높이의 40~50%로 비교한다. 기간/분모는 독립 소문구로 붙인다.
🌸 도형이 먼저 0.25초 입장하고 큰 숫자는 그 뒤 0.5~0.8초에 정착. 숫자가 떠 있는 동안 배경은 원속도로 자연 재생하고 숫자는 흔들지 않는다.

S03 상승형 장식 블록 / 실제 추세 분기
🌸 주황 전면, 조금 밝은 윗면, 얇은 측면을 공통 재질로 사용한다. 블록마다 광원을 바꾸지 않는다. 장식 모드의 낮은 블록은 겹쳐도 되지만 실제 추세 모드에서는 값의 높이 끝을 가리지 않는다.
🌸 주황 블록 투명도는 60~78% 불투명도의 비교안으로 시작한다. 수치 라벨은 불투명 전면 레이어에 둔다.
🌸 밑에서 한번 자라 0.65~0.9초에 멈춘다. 성장처럼 보이게 만들려고 영상 후반에 속도를 반복 변경하지 않는다.

S04 호박색 유리 파이
🌸 투명한 얕은 유리 접시의 테두리와 호박색 선택 조각을 분리한다. 테두리는 얇은 밝은 선, 측면은 약한 어두운 선, 바닥은 넓고 흐린 그림자로 깊이를 만든다.
🌸 유리 외곽/분할 조각/호박색 내용물/가장자리 하이라이트/전면 라벨을 각각 분리한다. 글자 위로 굴절·반사 합성을 하지 않는다.
🌸 조각을 들어 올리는 대신 선택 조각만 평면 안에서 짧게 분리하는 비교안을 우선한다. 뒤쪽 조각이 앞쪽보다 커 보일 만큼 깊은 원근은 피한다.

S05 파란 발광 파이
🌸 흰 무광 원반에 파란 빛이 스며드는 재질이다. 유리 파이와 달리 선명한 유리 테두리보다 넓고 부드러운 파란 확산광이 중심이다.
🌸 파란 빛은 흰 원반 위·숫자 아래. 1080 기준 blur 40~72px, 불투명도 22~35%로 비교한다. 영역 경계는 발광과 별개로 선명히 유지한다.
🌸 입장 0.65초 뒤 밝기만 0.3초에 부드럽게 정착한다. 읽는 동안 숨쉬기 같은 반복 발광은 넣지 않는다.

S06 단계별 유리 퍼널
🌸 단계마다 높이가 있는 유리 그릇 모양을 사용하되 측면 두께·모서리 곡률·빛 방향을 통일한다. 아래 단계로 갈수록 흰색/연파랑→진파랑이 되는 단계 구분을 제안한다.
🌸 각 단계 본체와 하이라이트/그림자를 묶고, 숫자는 별도 전면 레이어. 오른쪽 콜아웃은 가로에서만 옆에 두고 세로에서는 해당 단계 밑으로 이동한다.
🌸 네 단계가 순서대로 도착한 뒤 발화에 맞는 한 단계만 0.2~0.3초 밝기 변화. 단계 전체를 계속 위아래 떠다니게 하지 않는다.

S07 유리 리뷰/과정 타임라인
🌸 투명 관과 별/말풍선/문서의 유리 아이콘, 옅은 바닥 반사를 사용한다. 말풍선만 파랑을 주는 방식처럼 핵심 단계에 포인트색을 제한한다.
🌸 관/연결 고리/아이콘/아이콘 그림자/라벨을 분리한다. 반사는 아이콘의 일부이고 새로운 정보가 아니므로 텍스트보다 눈에 띄지 않게 약하게 둔다.
🌸 연결 방향만 가로→세로로 바꾸고 아이콘 면과 글자는 정면을 유지한다. 연결선 0.6~0.9초, 단계 아이콘 0.12초 간격의 한 번 등장.

S08 컬러 유리 비교 막대
🌸 반투명 유리 막대마다 전면·윗면·측면의 상대 밝기와 반사 위치를 통일한다. 오렌지/블루/민트/핑크는 범주색으로 사용하되 해당 채널 팔레트를 확정하면 그 토큰으로 치환한다.
🌸 데이터 높이를 먼저 계산하고 3D 측면/윗면을 붙인다. 바닥 반사는 차트 아래에만 두고 숫자나 축 위로 겹치지 않는다.
🌸 같은 기준선에서 0.65~0.9초에 정착한다. 과도한 바운스가 값의 최대 높이를 초과한 것처럼 보이지 않게 수치 도형의 오버슈트는 OFF.

[실제 영상 적용 범위]
- S는 기존 편집기의 통계 장면에 적용하는 실행 지시다. 확보된 실제 값·단위·기간·출처를 연결하고 지도/숫자/파이/퍼널/막대/과정 도식을 의미에 맞게 선택해 가로·세로 장면을 만든다.
- 🌸 대표 통계 장면을 기존 렌더러로 실제 렌더하고 색·글자·기간·출처·자막 충돌·모션을 확인한다. 정지 모식도 완료와 실제 MP4 적용 완료를 구분한다.

R04 채널별 선택 캐릭터 / REF-24
사용처: 사용자가 해당 채널·영상·구간에 캐릭터를 요청한 경우
가져올 요소: 사용자가 고른 캐릭터 정체성 · 확인된 표정/몸짓 · 채널별 독립 ON/OFF
가져오지 않을 요소: 전 채널 강제 등장 · 매 댓글마다 캐릭터 등장 · 미수신 커피 남자 대역 생성 · 저해상도 시트를 고해상도 완성본으로 표시
가로: 🌸 화면 폭 10~16%의 크기를 출발점으로 카드 옆/빈 하단 측면에 전용 공간을 만든다. 사용자가 ON이면 공간 부족을 이유로 임의 생략하지 않고 카드/도형을 재배치한다.
세로: 🌸 화면 폭 16~24%의 크기로 하단 자막 위의 빈 칸 또는 카드 옆 작은 전용 칸을 비교한다. 댓글·지도·출처와 겹치면 카드와 캐릭터를 순차 노출하는 안을 제안한다.
서체 근거: 캐릭터 자산과 자막 글꼴은 분리한다. 캐릭터 ON이 새 말풍선/평가 자막 자동 추가를 뜻하지 않는다.
색 역할: 원본 캐릭터의 색을 보존한다. 썸네일 배경광·네온 선택이 캐릭터 본체의 색을 바꾸지 않게 한다.
레이어: 배경/카드→필요한 캐릭터 뒤 효과→캐릭터→별도로 요청된 말풍선. 자막/통계 글자를 가리지 않는 예약 영역 사용.
동작: 🌸 0.15~0.25초 등장과 짧은 표정 반응만. 모든 문장마다 바운스/손짓을 반복하지 않는다.
적용 조건: 현재 개구리 시트는 167×116이며 제작용 큰 누끼 자산은 미확보. 표정 확인용으로만 사용하고 고해상도 원본 또는 저장소 자산 확인 후 제작에 연결한다. 커피 남자는 미수신이다.

R05 인물 뒤·자막 뒤 효과 배치 / REF-08, REF-11, REF-12, REF-13, REF-14
사용처: 충격·강조·감탄·경고 등 해당 효과의 의미와 발화가 맞는 순간
가져올 요소: 누끼 뒤 빨강 외곽광 · 충격 배경 조명 · 경고 띠 · 충격 박스 · 기존 불꽃/번개/NO 자산의 역할

서체 근거: 효과 추가가 기존 글꼴/자간/외곽선을 임의 변경하는 이유가 되지 않는다.
색 역할: 인물 누끼광 #C30E0C, 배경 충격 조명 #B71512, 충격 박스 #E21317, 경고 노랑 #FFED00를 각 역할에만 사용한다.
레이어: 인물 뒤: 배경→색광/아우라→인물 마스크→전면 글자. 자막 뒤: 영상→부분 효과/박스→형광(필요 시)→주 자막. 효과가 최종 글자색을 덮지 않게 한다.
동작: 🌸 0.12~0.20초 입장, 0.35~0.70초 감정 강조, 0.15~0.25초 퇴장을 비교한다. 필요 시 짧게 유지하되 후반부 정지/반복을 강제하지 않는다.
적용 조건: 기존 감정 효과 규칙을 유지한다. 해당 감정이 없으면 선택 목록에만 보관하고 자동 삽입하지 않는다.

R06 NO!!·충격 썸네일 역할 분리 / REF-14, REF-19

적용 조건: 참조의 인물·영화 문구는 현재 회차 대본/소재로 자동 복사하지 않는다. 기존 대본 안의 해당 표현에 디자인만 적용한다.

R07 T05 금빛 입체 자막 비교 / REF-20
사용처: 기록·특급·성과처럼 이 템플릿을 선택한 강조 구간
가져올 요소: 상단/밝은 띠/아랫면의 금빛 단계 · 진갈색 외곽선 · 청동빛 바깥 테두리 · 아래쪽 입체 그림자 · 선택 장식

서체 근거: 레코체 Bold/G마켓 산스 Bold/평창평화체는 REF-20 UI 비교 후보 L1. 사용자가 선택한 템플릿과 폰트 파일 확인 후 연결한다.

R08 풀 파티 실물 크롭의 적용 범위 / REF-16, REF-17
사용처: 기존 번개 2줄/풀 파티 계열 자막을 점검·적용하는 구간
가져올 요소: 작은 윗말과 큰 아랫말의 위계 · 핵심 명사만 다홍 강조 · 양끝 짧은 번개 · 기존 지정 글꼴/무외곽선 규칙
가져오지 않을 요소: 압축·배경 합성으로 변한 캡처색을 새 확정색으로 승격 · 캡처만 보고 원본 폰트를 확정 · 전 문장 전체를 빨강으로 변경
가로: 기존 하단 두 줄 구성을 유지한다. 🌸 긴 문구는 안전영역 안에서 박스 폭을 조정하며 핵심어와 조사를 따로 고립시키지 않는다.
세로: 🌸 두 줄 구조는 유지하면서 작은 윗말/큰 아랫말의 폭을 세로 화면에 맞춘다. 일반 자막을 아래에 다시 넣지 않는다.
서체 근거: 기존 티몬 몬소리 Black 지정을 유지. REF-17 원본 서체는 L0. 소문구 비율 등 기존 규칙을 신규 제안으로 덮어쓰지 않는다.
색 역할: 핵심어 #E03C3E 등 기존 고정 토큰 유지. REF-17 픽셀 실측은 참고색 항목으로만 별도 기록.
레이어: 필요한 번개 자산→기존 지정 본문/핵심어. 금지된 새 외곽선/그림자를 임의 추가하지 않는다.
동작: 🌸 기존 발화의 핵심 명사 시작에 0.10~0.18초 짧은 등장만 비교한다. 읽기 구간은 안정적으로 유지한다.
적용 조건: 새 실물 참조를 받았다는 사실만으로 기존 사용자가 지정한 수치를 미확인 값으로 바꾸지 않는다.

7. 충돌 방지 핵심
- 캐릭터: 영상/구간 명시값 > 채널 저장값 > OFF. 고해상도 미확보는 별도 상태.
- 빨강: VS 빨강은 유지하고 B71512는 배경 조명 역할에만 등록.
- 연두: 역할별 별도 보관. 사용자 선택을 저장할 수 있으나 자동 치환하지 않음.
- 풀 파티: 지정값 유지. 실측색/렌더색은 별도 비교 근거.
- 금빛: 별도 스타일로 등록하고 자동 병합하지 않음.
- 배경: 요소의 표면/가장자리만 불투명. 전체 배경을 전편 교체하지 않음.
- 상단 제목: 썸네일 문법은 썸네일에 한정. 카드 내부 정보는 카드와 함께 입퇴장. 일반 고정 상단 문구 추가 금지.
- 4초 컷: 🌸 배경 컷과 카드 지속 시간을 분리. TTS는 늘리지 않고 정보량/분할을 조정.
- 통계 S: S 통계 토큰도 일괄 치환하지 않는다. 해당 채널·스타일·역할에서만 선택값 연결.

8. 검수·보고
- 신규 17장 중 메뉴 캡처 REF-18까지 목록에는 포함하되 디자인/폰트 근거가 없는 이미지를 근거로 과장하지 않는다.
- 같은 색 계열을 전역 빨강·전역 노랑·전역 연두 하나로 묶지 않는다. style_id와 role을 함께 조회한다.
- 같은 이미지가 폰트 후보를 보여준다는 이유로 설치/실제 렌더 적용 완료라고 기록하지 않는다.
- 댓글 좋아요 null은 숨김. 캐릭터 요청 false는 숨김. 값이 없는 경우 임의 기본 숫자/악마/대역 캐릭터로 채우지 않는다.
- 개구리 시트는 수신 완료, 제작용 고해상도 원본은 미확보라는 두 상태를 동시에 보존한다.
- 종이틀은 선택 구간에서만 켜고 끝 시각에 종료한다. 검정/흰 배경을 전체 영상에 자동 확대하지 않는다.
- 후반부의 자연 재생을 유지한다. 그래픽 추가 때문에 원본 프레임을 반복하거나 TTS 끝 시각을 늘리지 않는다.
- 실제 영상 렌더 전에는 적용 규칙/정지 모식도 완료로 보고한다. 프레임 확인·연속 재생·폰트 적용이 검증되지 않으면 해당 항목을 PASS로 쓰지 않는다.
- 🌸 장면별 channel_id/output_type/style_id/color_role/hex/색근거/font_name/폰트근거/character_enabled/asset_id/시작·끝/기본·디자인 자막 모드를 기록한다.
- 🌸 가로·세로 정지 모식도는 모식도라고 표시하고, 실제 렌더는 대표 장면부터 확인한다. 색 일치·폰트 로드·글자 겹침·레이어·연속 재생을 실제 확인한 범위만 PASS로 쓴다.
- 🌸 미수신 항목 때문에 받은 17장의 정리까지 중단하지 않는다. 제작용 고해상도 자산이 필요한 부분만 pending으로 남긴다.

10. T05 참조 캡처와 현재 편집기 버전 구분 — 저장소 점검 연동
- REF-20은 guide.html의 정적 T05 원형이다. 레코체 Bold/G마켓 산스 Bold/평창평화체 3후보와 #F6CB52/#FCEC82/#F2CF5C 계열을 보여준다.
- P01~P04 이전의 저장소 점검 기준(6b91d1f)에서는 editor.js 72–74행이 T05를 별도 gold-editor로 교체한다. gold-renderer.js 24–29행의 현재 기본 팔레트는 #F9D56B/#FFF7B8/#F8DD78와 #3C280B/#D1A13B/#7B5019이고, 기본 글꼴은 검은고딕(ref106), 후보는 7종이다.
- 이것은 참조 캡처와 현재 편집기의 버전/진입 경로 차이다. 실제 영상 MP4의 색이 달라진 원인을 이 사실 하나로 확정하지 않는다. 현재 코드 기본값이 곧 사용자가 승인한 값이라는 뜻도 아니다.
- 🌸 t05_gold_reference20_guide / t05_gold_current_editor / caption_gold_11_locked를 각각 별도 style_id로 등록하고 source_version/template_entry_path/palette_set/font_id를 함께 기록한다.
- 🌸 참조 원형과 현재 기본값을 비교해 보여주되 기존 11번 금빛 칭찬과 기존 확정 폰트/색을 자동 변경하지 않는다. 참조의 3후보 중 아직 고르지 않은 글꼴을 임의 선택하지 않는다.
- 🌸 현재 T05 편집기를 대규모 교체하지 않는다. 기존 구조를 재사용해 선택한 R 스타일과 버전을 실제 영상의 해당 장면에 연결한다. 이 문서의 과거 작업 상태와 수신 환경에서 실행할 작업을 구분한다.

11. 실측/표기/현재 상태를 구분하는 메모
- REF-17 풀 파티 실물의 캡처 대표색 #DC3E3F는 참고 실측값이며 기존 고정 #E03C3E와 별도다.
- REF-20의 원본 배경 라벨은 #5A4636, 칩 실측은 #5A4839, 화면의 현재 배경 입력/미리보기는 #FFFFFF다. 서로 다른 상태를 하나의 원본 확정값으로 합치지 않는다.
- REF-23은 악마 없는 카드 부분 크롭과 뿔이 일부 가린 전체 카드 범위를 구분한다. 가려진 단어를 만들어 복원하지 말고, 확보된 실제 원문을 별도 흰 카드에 배치한다.

[현재 영상 교정과 연결]
- 이 R 모듈의 댓글·지도·종이틀·선택 캐릭터·뒤 효과·색 역할을 기존 장면표/렌더러에 연결하고, 실제 문맥이 맞는 장면에 적용한다. 미수신 제작 자산이 필요한 슬롯만 pending으로 남긴다.
- P01~P04의 웹 수정 완료는 R의 모든 영상 스타일이 이미 구현됐다는 뜻이 아니다. 실제 영상에서 남은 색·폰트·레이어·주 자막 중복·전환 문제는 B와 함께 필요한 최소 수정을 수행한다.
- 🌸 실제 렌더에서 확인한 장면만 적용 완료로 보고한다. 기본 자막과 평가 한마디가 겹치지 않고, 하단 배치와 후반 원속도 재생이 유지되는지 확인한다.
