[A · 최초 1회 / 사용자 원문과 실행 규칙 등록]

지금 작업은 기존 국뽕 영상 제작 체계에 내가 준 디자인·편집 요구를 정확히 등록하는 것이다. 원문을 요약한 문서만 읽고 임의 구현하지 말고, 내가 첨부한 실제 대화·디자인 명세·참고 이미지와 기존 프로젝트를 먼저 대조한다. 이 프롬프트는 새 프로젝트나 새 편집기를 만들라는 지시가 아니다.

1. 원문과 정규화 규칙을 분리한다.
- 내가 제공한 원문 파일은 토씨·색 코드·부호·개행을 수정하지 않고 그대로 보존한다. 사용자 발화, 내가 붙인 JSON/명세, Claude 자신의 실행 보고가 섞여 있으므로 각각 출처 유형을 붙인다.
- 원문을 지우거나 간추린 글로 바꾸지 않는다. 실행에 필요한 정규화 표는 별도 파일로 추가하고 원문 위치를 연결한다.
- 구분은 ①사용자 확정 ②참고 이미지 실측 ③Claude 보고 ④🌸추가 제안으로 고정한다. 직접 확인한 구현 사실은 별도 검증란에 쓴다. Claude가 “했다”고 쓴 내용은 실제 파일·코드·프레임을 확인하기 전까지 완료로 쓰지 않는다.
- 우선순위는 최신 사용자 직접 요청, 이전 사용자 직접 요청·제공 명세, Claude 요약 순이다. 이전 ChatGPT의 범용 팔레트·다큐 비율·추천 폰트가 사용자 지정값을 덮지 못한다. 최신 요청으로 해결되는 충돌을 다시 질문하며 기다리지 않는다. 확인 불가 항목만 미확인으로 남기고 가능한 교정은 진행한다.

2. 확정 디자인을 역할별로 기록한다.
- 기본 키워드: 레코체, 흰 글씨 #FFFFFF, 검정 외곽선 #111111, 핵심어 하나의 뒤쪽에 형광 표시. 오래된 keyword JSON의 acc=#e60f2f는 노랑/연두/하늘 형광 지시와 충돌하므로 범용 빨강으로 사용하지 않는다. “편당 형광1색”은 원문에 없는 단위다.
- 사용자가 제공한 기존 팔레트: 연연두 배경 #F5FFDC, 형광 연두 #D9FF65, 연분홍 #FEE9F2, 주의 박스 #FCF1ED. 각 용도를 유지한다.
- 최신 언론 참고 캡처의 대표 실측값: 왼쪽 연두 #C7F001, 오른쪽 연노랑 #F2F586. 축소·압축된 캡처에서 추출한 대표값이며 방송 원본의 제작 HEX를 확정한 것은 아니다. 이 값은 기존 #D9FF65와 별도로 기록한다. 이번 기사형 형광색 교정에서는 최신 참고 캡처 대표값을 사용한다.

3. 공통 표현과 보호 조건을 정리한다.
- 기본 자막과 디자인 자막은 동시 표시하지 않는다. 한마디 평가의 작은 머리말+큰 본문은 하나의 디자인이며 이 2줄 구조를 금지하지 않는다.
- 언론과 댓글은 별도 의미 유형이다. 타이핑 효과는 공유할 수 있지만 기사 헤드라인 띠를 댓글의 기본 레이아웃으로 사용하지 않는다.
- 배경 영상은 보이게 유지한다. 흰 글씨의 검정 반투명 배경과 검정 글씨의 흰 배경은 후속 사용자 명세에 있으므로 “통계에서만 어둡게”라는 Claude 요약으로 삭제하지 않는다.
- 자막 하단 배치, 상단 임의 소제목·로고 금지, 카드/VS/그래프의 위·가운데 허용은 현재 제공된 요약에서 확인된 기존 보호 조건으로 유지한다. 사용자 직접 원문 근거가 확인됐다고 표시하지는 않는다.
- 이후 지시대로 해외 원문·중국어·일본어 글씨를 보존하고, 제거가 필요한 하단 원본 자막·로고만 정확한 영역으로 처리한다. 자연스러운 블러 지시를 적용하고 모든 글자를 일괄 감지해 지우지 않는다.
- 이미 생성된 대본·TTS는 고정이다. 내레이션60% 규칙은 삭제됐고 약90%는 현황이지 새 목표가 아니다. 컷4초 이하 조건은 유지하면서 화면·음성의 연속성을 검사한다.
- 기존 HumanTouch와 디자인 코드를 재사용한다. 생성 자산6장은 실제 파일·투명도·미리보기를 확인하고 VS/NO/가장자리/아래 불벽/인물 뒤 아우라/번개에 각각 연결한다.

4. 🌸실행 구조 제안
🌸스타일별 색·폰트·효과·줄바꿈을 한 원천에 등록하고 시안과 렌더러가 같은 값을 읽게 한다. 스타일마다 임의 색을 다시 작성하는 중복 코드를 없앤다.
🌸각 장면에 semantic_type, style_id, primary_caption, 원문 근거, 자료 출처, 적용/미적용 이유를 기록한다. 필드 이름은 기존 구조와 맞춰도 되지만 역할을 합치지 않는다.
