R01 악마 없는 흰 댓글 카드 / REF-23
사용처: 실제 해외 댓글 또는 반응을 인용하는 구간
가져올 요소: 흰 직사각 카드 · 프로필/작성자/날짜 등 실제로 확보된 헤더 정보 · 원문과 핵심 구절 형광 · 읽을 수 있는 한국어 번역
가져오지 않을 요소: 악마 얼굴 · 원본 전체 검정 배경 · 카드 위의 별도 평가 한마디 · 좌상단 해시태그 · 플레이어/플러그인 아이콘
가로: 🌸 카드 폭은 화면의 64~76%, 중앙의 위·가운데 영역. 원문 위/번역 아래로 묶고 하단 기본 자막 보호영역과 분리한다. 캐릭터 ON이면 카드 폭을 줄여 옆에 전용 자리를 만든다.
세로: 🌸 카드 폭 80~86%, 세로 중앙의 위쪽. 원문→번역→확보된 출처/좋아요 순으로 쌓는다. 영문 긴 단어를 한 글자씩 줄바꿈하지 않고 문장 의미 단위로 나눈다.
서체 근거: 원본 댓글 서체 L0. 기존 지정된 댓글 글꼴/검정 본문색을 유지하고 번역 글꼴을 임의로 교체하지 않는다.
색 역할: 흰 카드와 진한 본문. 핵심어 형광은 기존 댓글 토큰 또는 사용자가 이 역할에 선택한 토큰을 사용한다. 새 #BCFF34가 언론·댓글 모두를 자동 교체하지 않는다.
레이어: 배경 영상→필요한 카드 그림자→흰 카드→헤더/형광→원문/번역→확보된 출처. 선택 캐릭터는 카드 텍스트와 겹치지 않는 별도 레이어.
동작: 🌸 입장 0.18~0.30초, 한 카드당 4~7초 읽기 시간을 비교한다. 타이핑을 쓰면 핵심 구절에만 짧게 적용하고 원문 전체가 오래 숨겨지지 않게 한다.
적용 조건: 원문·번역·좋아요는 실재하고 확보된 정보만 표시한다. 좋아요 미확보는 숨김(null)이며 0이나 임의 숫자로 채우지 않는다. 위 평가 문구와 아래 자막을 추가로 중복하지 않는다.

R02 선택 지역 강조 지도 + 하단 라벨 / REF-21
사용처: 지역·위치·이동을 간결하게 보여주는 구간
가져올 요소: 선택 지역의 선명한 채움 · 선택 영역의 형광 테두리/강조 · 인접 지역의 낮은 채도 · 지도에 붙은 하단 라벨
가져오지 않을 요소: 참조 방송 로고 · 불필요한 해설자 얼굴 · 고정 상단 소제목
가로: 🌸 지도는 화면 폭 58~72%의 중앙 영역, 선택 지역이 가려지지 않게 크롭한다. 이름/핵심 한 줄 라벨은 지도 하단에 붙이고 영상 주 자막과 분리한다.
세로: 🌸 지도 폭 82~88%, 위쪽~가운데에 배치한다. 지역을 읽을 수 있는 범위로 다시 잡고 하단 라벨을 지도 바로 밑 한두 줄로 정리한다. 가로 지도 전체를 축소해 작은 글씨를 유지하지 않는다.
서체 근거: 지도 원본 서체 L0. 라벨에는 기존 승인 글꼴을 사용하고 지역명/보조 문구의 크기 단계만 🌸 제안한다.
색 역할: 원본의 지역 채움·형광 경계·하단 라벨을 별도 역할로 보관한다. 🌸 #BCFF34 또는 선택한 노랑을 지역 강조 역할에 연결할 수 있으나 기존 언론 강조색을 바꾸지 않는다.
레이어: 배경 지도→선택 지역 채움→선택 경계/핀→지역명→지도 내부 하단 라벨. 발광은 지역명 아래에 둔다.
동작: 🌸 선택 지역으로 0.35~0.55초 접근 후 정지. 형광 경계는 0.25~0.40초에 한 번 나타난 뒤 유지하며 계속 반짝이지 않는다.
적용 조건: 표시할 지역과 라벨은 해당 장면의 자료에 맞춘다. 258×145 캡처는 디자인 참고이며 확대해 제작용 선명 지도로 쓰지 않는다.

R03 찢어진 종이 위아래 프레임 / REF-22
사용처: 영화/기록/회상 장면 등 종이 질감이 어울리는 선택 구간
가져올 요소: 영상 위·아래의 종이 면 · 영상 안쪽의 거친 찢김 경계 · 영상이 계속 움직이는 가운데 창
가져오지 않을 요소: 참조 영화 장면 자체 · 플레이어 UI · 전편 고정 프레임
가로: 🌸 위아래 띠를 각각 화면 높이의 5~9% 범위로 비교하고 가운데 영상의 주요 인물/자막을 가리지 않는다. 기존 하단 자막은 예약 영역에 둔다.
세로: 🌸 위아래 띠는 각각 화면 높이의 3~6%로 더 얇게 시작한다. 가로 프레임 이미지를 세로로 늘려 종이 결을 왜곡하지 않고 경계/질감을 분리해 재배치한다.
서체 근거: 프레임은 글꼴을 변경하지 않는다. 참조 캡처의 하단 자막 서체는 L0이므로 기존 자막 스타일을 유지한다.
색 역할: 원본은 회백색 종이 질감으로 관찰. 정확한 원본 HEX·불투명도는 미확정. 종이 테두리 안의 가운데 창은 투명으로 유지한다.
레이어: 배경 영상→종이 안쪽 가장자리의 선택 그림자→상하 종이 가장자리/찢김 알파→기존 하단 자막. 가운데 영상은 투명 창으로 유지한다.
동작: 🌸 입퇴장 0.15~0.25초의 짧은 페이드. 매 컷마다 책장 넘김을 강제하지 않는다. 해당 구간이 끝나면 프레임을 함께 종료한다.
적용 조건: 이 프레임은 미적 연출 옵션이다. 저작권 해결/탐지 회피 효과라고 설명하지 않는다.

적용 조건: 현재 개구리 시트는 167×116이며 제작용 큰 누끼 자산은 미확보. 표정 확인용으로만 사용하고 고해상도 원본 또는 저장소 자산 확인 후 제작에 연결한다. 커피 남자는 미수신이다.

R05 인물 뒤·자막 뒤 효과 배치 / REF-08, REF-11, REF-12, REF-13, REF-14

R08 풀 파티 실물 크롭의 적용 범위 / REF-16, REF-17

가져올 요소: 작은 윗말과 큰 아랫말의 위계 · 핵심 명사만 다홍 강조 · 양끝 짧은 번개 · 기존 지정 글꼴/무외곽선 규칙

적용 조건: 새 실물 참조를 받았다는 사실만으로 기존 사용자가 지정한 수치를 미확인 값으로 바꾸지 않는다.

7. 충돌 방지 핵심
- 캐릭터: 영상/구간 명시값 > 채널 저장값 > OFF. 고해상도 미확보는 별도 상태.
- 빨강: VS 빨강은 유지하고 B71512는 배경 조명 역할에만 등록.
- 연두: 역할별 별도 보관. 사용자 선택을 저장할 수 있으나 자동 치환하지 않음.
- 풀 파티: 지정값 유지. 실측색/렌더색은 별도 비교 근거.
- 금빛: 별도 스타일로 등록하고 자동 병합하지 않음.
- 배경: 요소의 표면/가장자리만 불투명. 전체 배경을 전편 교체하지 않음.
- 상단 제목: 썸네일 문법은 썸네일에 한정. 카드 내부 정보는 카드와 함께 입퇴장. 일반 고정 상단 문구 추가 금지.
- 4초 컷: 🌸 배경 컷과 카드 지속 시간을 분리. TTS는 늘리지 않고 정보량/분할을 조정.
- 통계 S: S 통계 토큰도 일괄 치환하지 않는다. 해당 채널·스타일·역할에서만 선택값 연결.

8. 검수·보고
- 신규 17장 중 메뉴 캡처 REF-18까지 목록에는 포함하되 디자인/폰트 근거가 없는 이미지를 근거로 과장하지 않는다.

- 개구리 시트는 수신 완료, 제작용 고해상도 원본은 미확보라는 두 상태를 동시에 보존한다.
- 종이틀은 선택 구간에서만 켜고 끝 시각에 종료한다. 검정/흰 배경을 전체 영상에 자동 확대하지 않는다.

- 실제 영상 렌더 전에는 적용 규칙/정지 모식도 완료로 보고한다. 프레임 확인·연속 재생·폰트 적용이 검증되지 않으면 해당 항목을 PASS로 쓰지 않는다.
- 🌸 장면별 channel_id/output_type/style_id/color_role/hex/색근거/font_name/폰트근거/character_enabled/asset_id/시작·끝/기본·디자인 자막 모드를 기록한다.
- 🌸 가로·세로 정지 모식도는 모식도라고 표시하고, 실제 렌더는 대표 장면부터 확인한다. 색 일치·폰트 로드·글자 겹침·레이어·연속 재생을 실제 확인한 범위만 PASS로 쓴다.
- 🌸 미수신 항목 때문에 받은 17장의 정리까지 중단하지 않는다. 제작용 고해상도 자산이 필요한 부분만 pending으로 남긴다.

10. T05 참조 캡처와 현재 편집기 버전 구분 — 저장소 점검 연동
- REF-20은 guide.html의 정적 T05 원형이다. 레코체 Bold/G마켓 산스 Bold/평창평화체 3후보와 #F6CB52/#FCEC82/#F2CF5C 계열을 보여준다.
