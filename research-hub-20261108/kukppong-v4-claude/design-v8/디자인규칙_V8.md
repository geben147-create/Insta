## 0. 제작 형식 (재확인)
- 컷은 **4초 이하**, 전체에서 **내레이션 60% 이상**.
- 원본 영상: 좌우반전·크롭·속도 변경. **빌리빌리·샤오홍슈 등 플랫폼 로고는 모자이크**.
- 효과음: 책장 넘기는 소리, 함성 소리 등 — **너무 많지 않게**.
- 댓글·언론 인용: **타이핑 효과**. 실제 댓글·기사가 없으면 지어내지 않는다.
- 화면 전환: **줌인 / 줌아웃 / 책장 넘김**.
- TTS·렌더·게시 절차는 STEP 6~8 그대로(Qwen3-TTS 3회 생성 → 받아쓰기로 선택, 제작 메모·ID 음성 혼입 검사, 완성 MP4는 권리 확인 전 GitHub 업로드 금지).

## 1. 공통
- **자막 폰트: 레코체(Recipekorea)** — `fonts/Recipekorea.woff`
  (CDN: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2001@1.1/Recipekorea.woff)
- **배경은 투명.** 단색 판(빨강·파랑 등)으로 화면을 덮지 않는다. 뒤의 영상이 그대로 흐른다.
  필요하면 뒤에 ① 그 내용에 맞는 한국 영상, ② 태극기 같은 관련 사진을 깔아 준다.
- **강조 빨강 = `#E21317`** (사용자가 준 색 견본 "충격 박스 빨강", ref4). VS 글자·충격 강조에 쓴다. `#B71512` 아님.
- 글자 내용은 **고정이 아니다.** 예시 문구는 자리 표시일 뿐, 편마다 대본 해당 구간의 내용으로 바꿔 넣는다.

## 2. ✨ 키워드 강조 자막 (기본 자막)
| 항목 | 값 |
|---|---|
| 폰트 | 레코체 |
| 글자 | 흰색 `#FFFFFF`, 외곽선 `#111111` |
| 배경 | 없음(투명) |
| 강조 | 핵심어 하나에 형광펜(marker), 왼→오로 칠함 |
| 동작 | 0.00 하단 자막 타이핑 → 0.40 강조어 형광펜 → 0.45 반짝 효과음 11(-20dB) |
| 금지 | 한 문장에 강조 하나만. 형광펜 색은 노랑/연두/하늘 중 한 편 안에서 하나로 통일 |

## 3. ⚔️ VS 비교
- **좌·우 카드: 흑백(무채색) + 반투명.** 빨강/파랑 판을 없앤다. 카드 뒤로 영상이 비친다.
  (검정 30~45% 반투명 + 얇은 흰 테두리, 국기·사진을 넣을 땐 흑백 처리)
- **가운데 `VS` 글자만 `#E21317`** (흰 외곽선 + 그림자). 폰트 Black Han Sans.
- 그 내용(두 대상을 비교하는 대목)에만 등장시킨다. 남발 금지.
- 동작: 0.00 좌우 카드 휙(21) → 0.25 충돌 금속음(23) → 0.30 VS 스탬프 → 0.80 비교 항목 등장.
- 비교 수치는 같은 연도·같은 단위. 국기는 Wikimedia Commons SVG.

## 4. 📈 통계 그래프 (ref3 스타일)
- **배경 투명** — 회색 판 없이 영상 위에 바로 그린다(가독성용으로 아주 옅은 어둠 막만 허용).
- 꺾은선 + 막대 혼합, 주요 지점에 숫자 라벨, 사건 표시는 손글씨/형광 주석.
- `[ 제목 ]` + 큰 숫자 + 출처 표기 필수. 선은 왼→오로 그려지는 애니메이션.

## 5. 📰 언론·댓글 인용 (ref1·ref2)
- 언론사 로고(작게) + **흰 띠 위 검정 굵은 헤드라인**(기사 원문 제목, 핵심어는 노랑 형광).
- 기자명·날짜 작은 회색 글씨. 뒤 영상은 그대로 보임.
- 헤드라인은 **타이핑 효과**. 실제 기사만.

## 6. 🔥 한국이 대단하다! (참고용)
- 외국인이 감탄하는 순간에만. 90→110→100% 팝, 강조어 하나에만 반짝이.
- 색은 V8 공통(흰 글자 + 강조 `#E21317` 또는 노랑 형광) 범위 안에서.
