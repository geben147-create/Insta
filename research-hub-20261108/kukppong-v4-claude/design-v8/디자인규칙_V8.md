## 1. 공통
- **🔴 화면 배치(2026-11-24 사용자 지시, 최우선):**
  - **자막은 항상 화면 아래에 붙인다.** (키워드 자막·2줄 문구·1줄 라벨·한마디 평가 모두 하단)
  - 언론·댓글 카드·VS·그래프만 위쪽/가운데 배치 가능.
  - **왼쪽 위·오른쪽 위에 소제목·특정 문장·로고를 절대 넣지 않는다.**
  - **배경은 항상 투명.** 어둡게 깔기(dim)는 **통계 그래프가 나올 때만**.
- **🔴 줄바꿈·정렬(2026-11-24 사용자 지시):**
  - **의미 단위로 줄을 나눈다.** 글자 하나·낱말 하나가 다음 줄에 혼자 떨어지면 안 됨 → 글자 크기를 줄이거나 박스를 넓혀 한 줄/균형 잡힌 2줄로. (CSS: `word-break:keep-all; text-wrap:balance`, 강조구는 `white-space:nowrap`)
  - **박스 안 글자는 항상 상하좌우 정중앙.** 위로 쏠리면 FAIL (CSS: flex 가운데 + `line-height:1` + `text-box:trim-both cap alphabetic`, 위·아래 여백 같게).
  - 글자와 박스 사이에 **아주 약간의 여백**을 둔다(딱 붙이지 않음).
  - 박스에 **흰 테두리(바깥 외곽선) 넣지 않는다.**
  - VS 글자는 좌우 카드 사이 **세로 정중앙**.
- **폰트 파일은 GitHub에 올리지 않는다**(정선아리랑체 등 재배포 금지). 페이지는 설치된 폰트(local)·공식 CDN으로 불러온다. 원본 폰트: `/home/yh/Pictures/폰트들/`.
- **자막 폰트: 레코체(Recipekorea)**
  (CDN: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2001@1.1/Recipekorea.woff)
- **배경은 투명.** 단색 판(빨강·파랑 등)으로 화면을 덮지 않는다. 뒤의 영상이 그대로 흐른다.
  필요하면 뒤에 ① 그 내용에 맞는 한국 영상, ② 태극기 같은 관련 사진을 깔아 준다.
- **강조 빨강 = `#E21317`** (사용자가 준 색 견본 "충격 박스 빨강", ref4). VS 글자·충격 강조에 쓴다. `#B71512` 아님.
- 글자 내용은 **고정이 아니다.** 예시 문구는 자리 표시일 뿐, 편마다 대본 해당 구간의 내용으로 바꿔 넣는다.

## 3. ⚔️ VS 비교
- **좌·우 카드: 흑백(무채색) + 반투명.** 빨강/파랑 판을 없앤다. 카드 뒤로 영상이 비친다.
  (검정 30~45% 반투명 + 얇은 흰 테두리, 국기·사진을 넣을 땐 흑백 처리)
- **가운데 `VS` 글자만 `#E21317`** (흰 외곽선 + 그림자). 폰트 Black Han Sans.
- 그 내용(두 대상을 비교하는 대목)에만 등장시킨다. 남발 금지.
- 동작: 0.00 좌우 카드 휙(21) → 0.25 충돌 금속음(23) → 0.30 VS 스탬프 → 0.80 비교 항목 등장.
- 비교 수치는 같은 연도·같은 단위. 국기는 Wikimedia Commons SVG.

## 4. 📈 통계 그래프 (ref3 스타일)
- **배경 투명** — 회색 판 없이 영상 위에 바로 그린다(가독성용으로 아주 옅은 어둠 막만 허용).
- 꺾은선 + 막대 혼합, 주요 지점에 숫자 라벨, 사건 표시는 손글씨/형광 주석.
- `[ 제목 ]` + 큰 숫자 + 출처 표기 필수. 선은 왼→오로 그려지는 애니메이션.
