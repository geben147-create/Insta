# V9 영상 편집 적용 가이드

## 같은 장면으로 비교

51편 「100위안으로 비교한 한중일 PC방」에서 왼쪽은 V8C, 오른쪽은 V9입니다. 30초 시범에서 강도와 가독성을 먼저 확인하고, 5분 비교에서 통계·댓글·반전의 흐름과 전환음을 봅니다. 비교 영상 재생 시 양쪽의 목소리가 겹치지 않도록 수정본을 기준으로 청취합니다.

## 장면별 적용

| 장면 | 화면과 자막 | 소리 |
|---|---|---|
| 훅·VS | 핵심어 스탬프, 짧은 줌 또는 움직임이 연결되는 컷 | 02, 06 |
| 한국 칭찬 | 스탬프 → 줌인 → 줌아웃 → 가벼운 바운스를 번갈아 적용. 줌은 핵심어만 | 07, 08 |
| 반전 | 짧은 검정 경유, 강조 박스와 줌아웃 | 02, 05 |
| 통계 | 기준선에서 막대를 0.65~0.9초 동안 올리고, 항목마다 약 0.1초 늦춤. 수치 카운트업과 출처·연도·단위 표시 | 06, 08 |
| 키워드·팩트 | 필요한 단어만 움직이고 배경은 가볍게 어둡게 | 10, 08 또는 06, 08 |
| 댓글 | 원문을 추적할 수 있는 실제 댓글에 타이핑 효과 적용 | 03, 10 |
| 기사 | 매체·날짜·제목을 표시하고 핵심 인용에 형광. 문맥에 맞으면 종이 펼침 | 03, 09 |
| 결론 | 가벼운 바운스와 필요할 때 검정 경유 | 08 |

기본 검정 경유는 총 0.6초입니다. 소리는 허브 라이브러리 안에서만 고르고 목소리보다 작게 섞습니다. 자료의 구조에 맞춰 통계 재질을 고릅니다. 막대는 크기 비교, 지도는 지리적 비교, 파이는 전체에 대한 비율, 퍼널은 실제 단계 데이터에 사용합니다.

## 사용자 지정 폰트 순환

레코체 → 검은고딕 → 도현 → 정선아리랑뿌리체 → 평창평화체 → 티몬 몬소리 Black → 여기어때 잘난체 → G마켓 산스 Bold → 주아 → 정선아리랑 혼. 페이지 기본 폰트와 독립된 사용자 지정 목록입니다. 로딩 증명과 실제 자막 등장 횟수를 따로 확인합니다.

타이밍과 소리 번호까지 가져가려면 [편집 프리셋 JSON](edit-spec-v9.json)을 사용하세요.
