공통 지시문 (최초 1회 입력)

# 🇰🇷 국뽕 해외반응 제작 공통 규칙 V4.3

- 🌸 주인공은 한국을 경험하고 평가하는 외국인이다. 실제 외국인의 호평·놀라움·감동을 먼저 보여주고 내 나레이션이 그 의미를 자연스럽게 연결한다.
- 🔴🌸 한국인이 한국을 칭찬하거나 국내 기관이 한국을 높이 평가한 자료는 해외 호평의 증거로 사용 금지. 국내 공식 숫자는 객관적 사실 확인용으로만 쓴다.
- 🌸 첫 30초 훅 5문장, 성공 영상의 훅·전개·감정선 참고, 질문→답→새 궁금증 반복. 한국의 자긍심·감동으로 회수한다.
- 🔴 실제 외국인 발언이 존재하면 해당 장면을 직접 배치한다. 내레이션이 똑같은 칭찬을 반복하거나 댓글·영상으로 이동한다고 설명하지 않는다.
- 🔵 자료는 "자막이 추출된 영상"만 쓴다. 먼저 자막이 몇 개인지 세고, 그 안에서 주제를 고른다. 원본 영상은 자막 타임라인으로 잘라 쓴다.
- 🔵 대본에 플랫폼 이름(샤오홍슈·빌리빌리·틱톡·깃허브)을 말하지 않는다. "중국인이", "조회수 몇백만 회를 기록한 중국 크리에이터는"처럼 말한다. 깃허브는 자료 창고일 뿐이다.
- 🔵 "이것만으로 한국이 최고라고 할 수 없습니다", "확인해 보셔야 합니다" 같은 말을 절대 넣지 않는다. 외국인이 스스로 한국을 대변하게 한다.
- 🔵 외국인이 하지 않은 칭찬은 만들지 않는다. 서로 다른 사람의 말을 한 사람의 말처럼 잇지 않는다.
- 🔵 영상 길이는 최소 10분. 내 한국어 해설 음성 약 60%, 외국인 원음 클립 약 40%(클립 1개 약 4초).
- 🔵 영상에서 중국어로 말하는 부분은 전부 한국어 자막으로 번역한다. 번역은 중국어 원문 자막에서 직접 한다(기계 번역본은 오역이 많다).
- 🔵 중간에 묻지 않는다. 단계마다 체크리스트를 스스로 확인하고 다음 단계로 간다. 단, 유튜브 등 외부 공개 업로드·유료 호출·원본 수정·삭제는 하지 않는다.
- 🔵 한 일은 페이지 맨 끝에 "by <작업한 도구 이름>"으로 항상 기록한다(예: by Claude Desktop, by Hermes).
- 모든 원문을 사실/번역/추정/창작으로 구분한다.

STEP 0 · 자막·원본 확인 (읽기 전용)

# STEP 0 · 읽기 전용 원본 조사
- GitHub 자막 폴더(reactions-downloads/subs)를 받아 한국어 자막(.ko.srt)이 있는 영상이 총 몇 개인지 센다. 나라·분야·조회수·자막 컷 수·길이를 표로 만든다.
- 원본 영상이 이 컴퓨터에 다 옮겨졌는지 확인한다. 수집표의 SHA-256과 파일 해시가 같은 것만 "사용 가능"으로 표시한다(옮기는 중인 파일은 해시가 다르다).
- 🔴🌸 한국을 긍정적으로 평가하는 외국인의 실제 발언·표정·장면을 우선 분류하고, 비판·비교·감동·반전 자료도 따로 표시한다.
- 🔴 영상에 등장하는 인물·계정명과 실제 대사, 화면 자막, 댓글을 구분한다. 원문이 없으면 발언을 추측하지 않는다.
- 🔵 원본 안에 끼워진 남의 영상(광고·다른 크리에이터의 소재)은 프레임을 뽑아 확인하고 사용 금지 구간으로 적는다.
- 전체 ASR과 원본 수정은 금지.

명령: python3 -I bin/catalog.py → catalog.json, 사용 가능 영상 수 출력

통과 기준: 자막 수·사용 가능 영상 수를 숫자로 적었다 / 이미 쓴 영상(episodes/*/script_data.py)을 표시했다

STEP 1 · 주제 선정

# STEP 1 · 주제 선정
- STEP 0의 "사용 가능" 영상 안에서만 고른다. 조회수가 높고, 호평 원음이 많고, 서로 묶이는 영상이 3개 이상인 주제를 우선한다.
- 평가가 주로 부정적인 영상은 주제에서 뺀다(갈등·반전 구간의 짧은 인용으로만 쓴다).
- 비교 축이 될 영상(일본·중국 편)이 있으면 함께 묶는다. 🔵 그 영상이 실제로 어디서 찍힌 것인지 확인한다(예: 중국 안의 일본 브랜드 매장인지, 일본 현지인지).
- 이전 에피소드와 겹치지 않게 한다.
- 🔴🌸 해외 언론·전문가의 실제 한국 평가가 있으면 붙인다. 없으면 "없음"으로 적고 지어내지 않는다.
- (시간이 있을 때) Google Trends 24시간·7일, 네이버 데이터랩으로 시의성을 확인한다. 확인하지 못했으면 "미측정"으로 적는다.
- 주제 1개와 고른 이유, 쓸 영상 목록을 적고 다음 단계로 간다.

통과 기준: 주제 한 줄 / 쓸 영상 3~6개 / 뺀 영상과 이유

STEP 2 · 훅·전개 설계 (Few-shot)

# STEP 2 · 훅·전개 설계
- 먼저 읽는다: 좋은 자막 예시 분석(fewshot/LEARNINGS.md), 훅 12종+14종·전개 8종+9종·실전 훅 22편(모음집 페이지), 대본 스타일 팩.
- 🌸 첫 0~30초: 외국인의 실제 호평 원음 2~3개 → 궁금증(질문 1개) → 통념 뒤집기 또는 결과 선공개. 훅 5문장을 쓴다.
- 🔵 초반에 "한국 너무 좋아요"류 호평, "속았어요" 같은 반전 한마디, 그리고 다른 나라(일본 등)와의 비교를 차례로 넣는다.
- 전개는 메인 1개 + 보조 1개만 고른다(예: 질문 사다리 + 체험 발견). 고른 이유를 한 줄로 적는다.
- 🔴 30~60초마다 새 정보·새 장면이 나오도록 질문→답→다음 궁금증을 잇는다. 판단이 뒤집히는 대목(Reframe)을 3~4번 둔다.
- 끝은 Triple Ending: 처음 질문에 답 → 정의를 한 번 더 바꿈 → 처음 장면·물건을 다시 불러 닫음. 마지막 문장은 답하고 싶은 질문.
- 문장을 베끼지 않는다. 예시에서는 기능(순서·호흡·말맛)만 가져온다.

통과 기준: 훅 5문장 / 메인·보조 전개 / 중심 질문 1개와 답이 나오는 시각 / Reframe 목록

STEP 3 · 아웃라인

# STEP 3 · 아웃라인 (10~12분, 장편은 17분)
- 🌸 외국인의 실제 칭찬 → 배경 → 오해·불편 → 외국인 반응으로 반전 → 한국의 저력·자긍심 → 최초 질문 회수.
- 구간마다: 시간, 내레이션 요지, 쓸 원음 클립(영상 ID·자막 IN/OUT·중국어 원문), 화면 문구, 감정(🟨 질문 🟥 갈등·반전 🟦 근거 🟩 호평·감동).
- 🔴 숫자는 공식 자료에서 가져오고 출처·날짜를 적는다. 숫자마다 역할(규모·비교·속도)이 있어야 한다.
- 아웃라인 아래에 "성공 요소 1:1 적용 근거 메모"를 적는다.

STEP 4 · 대본 작성

# STEP 4 · 대본
- 형식: episodes/<이름>/script_data.py 의 SEQ (예시는 episodes/ramen-20261115/script_data.py).
    ('S', 구간키, 화면 라벨)
    ('N', 내레이션 문장, 화면 문구 | 'chart:이름' | '"댓글 말풍선 문구"', 형광 태그 q|c|e|g|'')
    ('C', 소스키, IN초, OUT초, 한국어 자막, 형광 태그)
- 🔴🌸 외국인의 칭찬은 외국인의 실제 목소리로 증명한다. 내 해설은 배경·새 사실·의미를 잇고 같은 칭찬을 반복하지 않는다.
- 🔵 원음 앞에 소개 1~2문장, 원음 뒤에 의미 한 줄. 약 1분마다 무대(영상·소재)를 바꾼다.
- 🔵 한국어는 말하듯 쓴다. 한 문장에 생각 하나, 5~18어절. 종결어미(~습니다/~는데요/~거든요/~죠)를 섞고 같은 어미를 세 번 잇지 않는다.
- 🔵 불리한 평가(비싸다, 별로다)도 실제 발언이면 짧게 넣는다. 그 뒤의 호평이 더 믿음직해진다.
- 🔴 "영상으로 돌아갑니다", "댓글을 보겠습니다", "작은 질문을 드립니다" 같은 진행 설명 금지. ID·H/S 코드·제작 메모를 낭독하지 않는다.
- 클립은 자막 컷 경계에 맞춰 3~6초(평균 약 4초). 숫자는 READ 표에 한글 읽기를 적는다(예: '755만 회' → '칠백오십오만 회').

명령: python3 -I bin/lint_script.py episodes/<이름> (플랫폼 이름·헤지·메타·클립 길이·자막 일치 검사)

STEP 5 · SEMANTIC JUDGE 1:1 검수

# STEP 5 · 검수
- 🌸 성공 영상의 훅·전개·감정선 요소별로 새 대본의 문장과 타임코드를 의미 기반 1:1로 맞춘다.
- 🔴🌸 첫 30초 한국 호평, 외국인 원음 중심의 증거, 반복 질문·답, 반전, 한국의 자긍심이 실제로 전달되는지 본다.
- 🔴 국내 자화자찬·가짜 발언·다른 인물의 대사 합치기·과장된 해외 열광 표현을 찾아 고친다.
- 🔵 첫 30초 안에 질문이 있는가 / 질문 사이 간격이 2분을 넘지 않는가 / 플랫폼 이름·헤지 문장이 0개인가.
- 🔵 원음 클립 프레임을 뽑아 남의 영상·광고가 섞이지 않았는지 눈으로 확인한다.
- 🟨 질문, 🟥 갈등, 🟦 근거, 🟩 감동을 표시한 1:1 적용표(V4 검수판)를 만든다. 전개 순서를 기계적으로 복제하지 않는다.
