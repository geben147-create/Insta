# 통계·지도·종이 재질 스튜디오

2026-11-24 · 통계 참고 7장 + 영역 지도 + 종이 테두리, **9종 전용 페이지**입니다. 사용자 원본과 조절 가능한 시안을 비교하고, 선택한 색·빛·여백을 영상 제작 단계로 전달합니다.

## 사용하는 순서

1. 위쪽 원본 목록에서 유형을 선택합니다.
2. `원본 비율 / 가로 16:9 / 세로 9:16`과 `나란히 / 겹쳐 비교 / 시안 크게`를 고릅니다.
3. 색 역할을 먼저 선택한 뒤 HEX 칩·색상 선택기를 사용합니다. 원본 이미지를 클릭하면 해당 지점의 **5×5px 중앙값**을 읽어 선택 역할에 적용할 수 있습니다.
4. 그라데이션 각 지점의 색·위치·불투명도, 빛 중심·번짐, 두께·반사·그림자, 배치·여백을 조절합니다. 원본 비트맵이 유지되는 유형은 편집 가능한 항목만 적용됩니다.
5. `설정 JSON 저장` 또는 `현재 설정 프롬프트 복사`로 **실제 선택값**을 전달합니다. 정적인 TXT만 전달하면 브라우저에서 고른 현재 값이 포함되지 않습니다.
6. 필요한 결과를 PNG·SVG로 저장합니다. 다른 기기에서는 설정 JSON을 불러옵니다.

🌸 위 순서는 새 페이지의 사용 안내입니다. 기존 영상 편집 프로젝트를 대체하는 절차가 아닙니다.

## 색상과 재현값 구분

| 표시 | 의미 |
|---|---|
| 원본 명시 HEX | 이미지에 쓰인 코드를 그대로 옮긴 값 |
| 픽셀 실측 | 명시 ROI의 합성 화면색; 원래 재질의 기본색과 동일하다는 뜻이 아님 |
| 원본 관찰 | 모양·겹침·반사 위치·픽셀 경계의 관찰 |
| 🌸 재현 제안 | 시안을 만들기 위한 조절 가능한 초기 설정 |

REF-05의 표기 순서는 `#03195B / #0B2CB1 / #1951FC / #3781FC / #3781FC / #CBE9FD`입니다. **4·5행 중복을 보존**했습니다. 다섯 번째가 화면에서 더 밝아 보이더라도 원문 코드를 임의 수정하지 않습니다. 여섯 물체의 표기색과 한 물체 내부의 그라데이션 지점은 서로 다릅니다.

## 파일 안내

| 파일 | 내용 |
|---|---|
| `index.html`, `studio.css`, `studio.js` | 비교 화면·컨트롤·설정 저장·내보내기 |
| `material-renderer.js` | SVG 재현; `MaterialRenderer.render(id, config)` |
| `reference-spec.json` | 9개 원본의 좌표·여백·측정색·레이어·그라데이션 레시피 |
| `reference-analysis.md` | 상세 분석 설명 |
| `production-prompt.txt` | 기존 CURRENT와 함께 쓰는 통계 재질 적용 지시 |
| `assets/blue-glass-generated.png` | 🌸 새로 생성한 파란 유리 재질 시안 |
| `assets/white-relief-map-generated.png` | 🌸 새로 생성한 흰 양각 지도 재질 시안 |

두 생성 이미지는 사용자 원본 및 편집 가능한 SVG와 별개입니다. 실제 3D 프로젝트나 정확한 통계/지도 데이터의 대체물이 아닙니다. 실제 원본 3D·광원 정보가 없으므로 완전 동일한 복원이라고 주장하지 않습니다. 지도 경계·지명·통계 수치·비율은 실제 제작 데이터에 연결합니다.

## 실제 영상에 적용

[현재 통계 재질 적용 프롬프트](https://geben147-create.github.io/Insta/research-hub-20261108/kukppong-v4-claude/statistics-material-lab-20261124/production-prompt.txt)와 **사용자가 내보낸 설정 JSON**을 함께 전달합니다. 기존 [CURRENT 전체 지시](https://geben147-create.github.io/Insta/research-hub-20261108/kukppong-v4-claude/design-reference-master-20261124/apply-current-edit.txt)는 계속 유효합니다.

- 대본·TTS와 타임코드를 유지합니다.
- 기존 자막색·폰트를 통계 팔레트로 전역 변경하지 않습니다.
- 기존 HumanTouch와 실제 렌더러에서 선택값을 연결합니다.
- 🌸 원본 crop을 생성 결과로 표시하지 않습니다.
- 🌸 웹 시안과 실제 출력 MP4의 검증을 구분합니다.
- 🌸 가로·세로는 도형 비율을 유지하며 재배치합니다. 전체를 회전하거나 찌그러뜨리지 않습니다.

이 폴더를 배포한 것만으로 이미 만들어진 영상이나 기존 저장 설정이 자동 교정되지는 않습니다. 실제 영상 완료 여부는 실제 프로젝트와 출력 프레임 검수로 판단합니다.
