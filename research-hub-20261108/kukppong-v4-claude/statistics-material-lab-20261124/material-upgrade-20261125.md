# 🌸 통계·지도·종이 재질 개선 기록

2026-11-25 · 사용자 비교 캡처와 새 원본을 기준으로 한 구현 변경 기록

기존 **9종을 12종으로 확장**했습니다. 수정 전 렌더러는 [비교용 스냅샷](material-renderer-before-20261125.js)에 남겼고, 현재 렌더러 및 추가 3종과 구분합니다. 이번 문서는 구현한 내용과 측정 근거를 설명합니다. 최종 공개 배포와 브라우저 검수 완료를 뜻하지 않습니다.

## 1. 🌸 미리보기가 사라지는 문제를 막는 요청문

```text
🌸🌸🌸🌸🌸 미리보기는 화면에 고정하고, 설정·전환·효과음은 오른쪽 접이식 패널 안에서만 독립 스크롤되게 해주세요.
어떤 효과를 눌러도 같은 화면에서 즉시 재생 결과가 보여야 하며, 태블릿·모바일에서도 미리보기가 가려지지 않는지 확인해주세요.
```

설정을 누르는 동안 결과 화면을 찾아 다시 스크롤해야 하는 것은 **조작부와 결과의 공간적 분리** 문제입니다. 구현 요구를 구체화할 때는 **고정 미리보기(sticky preview), 접이식 인스펙터(collapsible inspector), 패널별 독립 스크롤, 즉시 피드백(live preview)**이라고 표현하면 됩니다.

## 2. 원본·수정 전·수정 후를 구분하는 방법

| 구분 | 무엇을 보여주는가 |
|---|---|
| 사용자 원본 | 제공된 참고 이미지. 원본 바이트를 보존 |
| 수정 전 | `material-renderer-before-20261125.js`에 저장한 기존 9종 시안 |
| 🌸 수정 후 | 현재 SVG 렌더러와 추가 유형. 색·빛·글자·여백을 조절 |
| 🌸 생성 재질 이미지 | 앞서 생성한 파란 유리·흰 지도 이미지. 편집 가능한 SVG와 별개 |

새 3종은 이전에 독립 렌더 유형이 없었습니다. 이 항목을 과거에 완성했던 것처럼 표시하지 않습니다. 특히 **15% 오렌지 영역은 이전에 지도 원본의 상세 크롭으로 볼 수 있었으나, 독립 편집 유형은 이번에 추가**했습니다.

## 4. 색을 고르는 기준

| 색의 근거 | 적용 방법 | 주의할 구분 |
|---|---|---|
| 원본에 적힌 HEX | 사용자 지정 기준색으로 사용 | 표면 전체가 이 색으로 보인다는 뜻은 아님 |
| 밝은 부분 실측 | 반사광·윗면·밝은 모서리에 사용 | 물체의 기본색을 대체하지 않음 |
| 중간 부분 실측 | 주요 면의 중간 톤에 사용 | 다른 면·다른 높이의 색과 구분 |
| 짙은 부분 실측 | 내부·겹침·측면·접점에 사용 | 큰 면 전체를 이 색으로 칠하지 않음 |
| 글자 코어색 실측 | 숫자·문구의 색을 별도로 맞춤 | JPEG 압축과 안티앨리어싱 영향은 남음 |
| 🌸 제안값 | 원본을 재현하기 위한 색 지점·위치·농도 | 원래 3D 재질 설정값의 복원이라고 표시하지 않음 |

## 5. 🌸 유리와 입체감의 6층 공식

전체 결과는 **면의 기준색 → 깊이의 암부 → 방향별 그라데이션 → 곡면 반사광 → 얇은 가장자리 → 투영/접촉 그림자**를 순서대로 쌓아 만듭니다. 이 순서는 재현을 위한 조형 규칙이며 물리 기반 3D 렌더러의 원본 설정을 의미하지 않습니다.

| 층 | 어떻게 만드는가 | 확인할 부분 |
|---|---|---|
| ① 면의 기준색 | 앞·옆·윗면을 별도 도형으로 나누고 사용자 선택색을 연결 | 모든 면이 같은 단색이 되지 않는가 |
| ② 깊이의 암부 | 내부, 겹치는 곳, 절단면, 두꺼운 유리벽에 짙은 색 적용 | 물체가 납작해 보이지 않는가 |
| ③ 방향별 그라데이션 | 세로·가로·대각선 그라데이션의 색 지점·위치·불투명도를 별도 관리 | 위아래와 좌우의 색 변화가 각각 있는가 |
| ④ 곡면의 흰 반사광 | 왼쪽 곡면광, 위쪽 반사띠, 모서리 반사점을 국소적으로 합성 | 전체를 뿌옇게 덮지 않고 빛의 위치가 보이는가 |
| ⑤ 얇은 가장자리 | 밝은 바깥 선, 어두운 경계, 안쪽 반사선을 구분 | 흰 테두리 하나로 끝나지 않는가 |
| ⑥ 투영·접촉 그림자 | 넓고 부드러운 그림자와 접점의 짧고 짙은 그림자를 별도 적용 | 바닥에 닿거나 떠 있는 거리가 읽히는가 |

🌸 반사광과 그림자에는 블러를 적용하되 숫자·글자·차트의 핵심 경계는 선명하게 유지합니다. 그림자는 기본으로 켜 두고, 효과의 차이를 비교할 때만 개별 표시를 바꿉니다.

## 6. 작은 여백과 크롭을 정확히 비교하기

원본 `crop.box`는 **캡처 픽셀 기준 `[x, y, 폭, 높이]`**입니다. 예를 들어 새 15% 계단의 `[348, 982, 585, 283]`은 1279×1536 원본에서 시작점 `(348, 982)`부터 `585×283` 영역을 뜻합니다. 이것을 1920×1080 결과의 좌표나 화면에 표시되는 CSS 픽셀로 그대로 해석하면 안 됩니다.

🌸 원본과 재현은 **같은 원본 좌표 구간**을 선택한 후 같은 화면 비율로 비교합니다. 가로·세로 변환에는 `min(출력 폭/크롭 폭, 출력 높이/크롭 높이)`의 균등 배율을 기준으로 여백을 계산합니다. 원본은 작은 구간을 확대하고 재현은 전체 구성을 축소해 보여주는 비교는 피합니다.

🌸 비교용 원본의 앱 버튼·상태바는 구성 영역에서 제외합니다. 원본 JPEG 자체를 덮어쓰지 않으며, 원작 지형이나 실사 장면을 사용한 경우 편집 가능한 벡터로 오인하게 표시하지 않습니다.

## 7. 화면에서 보이는 요소의 전문용어 5개

| 용어 | 뜻 | 이 자료의 예 |
|---|---|---|
| **콜아웃(Callout)** | 특정 항목을 설명하는 카드 | 퍼널 오른쪽 흰 설명 상자 |
| **리더 라인(Leader line)** | 대상과 설명을 이어주는 선 | 퍼널의 점과 가로 연결선 |
| **데이터 레이블(Data label)** | 차트의 값 또는 항목 이름 | 50%, 32%, Visits |
| **앰비언트 오클루전(Ambient occlusion)** | 모서리·접점의 좁은 음영 | 기둥 바닥과 접힌 경계 |
| **스페큘러 하이라이트(Specular highlight)** | 표면에 밝게 맺히는 반사광 | 유리 모서리의 흰색·청백색 빛 |

## 8. 원문 값과 적용 범위

- 접힘 막대의 첫 숫자는 사용자 발화의 27%와 달리 **원본에 21%**로 보입니다. 원본 예시는 21%를 보존했습니다.
- 흰 기둥 채움은 서로 다른 범주의 50/35/65/45/100%입니다. 합계 100% 구성비로 취급하지 않습니다.
- 접힘 막대는 원본 수치와 높이가 선형 비례하지 않는 인포그래픽입니다. 원본값 그대로면 원본 배치를 유지하고, 값을 변경하면 0–100% 공통 척도로 높이를 재계산합니다.
- 지도 시안의 실제 지형과 종이 시안의 실사 영상 창은 원본 이미지가 포함됩니다. 모든 픽셀이 독립적인 편집 개체는 아닙니다.
- 선택값을 실제 영상에 적용할 때는 현재 설정 JSON과 프롬프트를 함께 전달합니다. 페이지를 수정한 사실만으로 기존 MP4의 글자·효과가 자동 수정되지는 않습니다.

대본·TTS·기존 자막 고유색은 별도 사용자 지시가 없으면 그대로 유지합니다. 웹 구현, 공개 배포, 실제 영상 렌더 검수는 각각의 결과로 확인합니다.
