파란 유리: 겹침 순서 → 몸체의 깊은 색 → 내부 다중 stop → 왼쪽 넓은 반사 → 오른쪽 위의 작은 밝은 반사 → 윗면 얇은 밝은 선 → 가장자리 어두운 두께 → 안쪽 굴절띠 → 바깥 미세 번짐 → 접촉 그림자 순으로 분리한다. 두꺼운 흰 테두리 하나로 유리라고 표현하지 않는다.
🌸 방사형 블루: 중심 좌표·반경·안쪽 농도·중간 stop·외곽 alpha·블러를 별도 조절한다. 흰 원형 바탕, 분리된 조각, 깊이를 보이는 옆면, 파란 발광층, 얇은 표면 반사, 선명한 숫자가 각각 구분되어야 한다. 전체 원판이나 숫자를 함께 흐리게 만들지 않는다.
🌸 앰버 파이: 타원 원근, 접시 외벽과 안벽, 투명한 분할벽, 앰버 채움, 밝은 유리 가장자리, 짧은 접촉 그림자를 분리한다. 원근으로 왜곡된 픽셀 면적을 실제 구성비로 역산하지 않는다.
🌸 퍼널·막대: 면별 밝기·다른 깊이색·상단 림·바닥 반사를 구분한다. 막대는 동일 바닥선과 너비에서 값에 따라 높이가 정해지며, 유리 두께 때문에 값의 비교가 뒤틀리지 않게 한다. 퍼널은 단계별 수치와 전 단계 대비인지 전체 대비인지의 분모를 유지한다.
🌸 유리관: 관의 양쪽 가장자리, 중간 투명부, 링의 안/바깥 테두리, 아이콘별 유리면, 바닥 그림자와 반사를 따로 둔다. 파란 선 한 줄을 유리관의 완성본으로 내지 않는다.

🌸 영역 지도: 검증된 지리 데이터에 현재 소재의 영역·경계·핀·라벨을 연결한다. REF-21의 258×145 캡처를 확대해 새로운 정확한 경계를 복원한 것처럼 쓰지 않는다. 임의 생성 지형을 실제 지형 데이터 대신 사용하지 않는다.
🌸 종이: 상하 띠 높이·중앙 영상 창·불규칙한 찢김·밝은 섬유 끝·가는 접촉 음영·회색 미세 질감을 분리한다. 수평 흰 직선이나 반복 삼각형만으로 찢어진 종이를 대체하지 않는다. 영상은 비율을 유지하고 중요한 인물을 자르지 않는다.

[작은 여백과 가로·세로 배치]

[선택값을 실제 렌더에 연결]
🌸 PNG는 현재 시안의 평면 결과, SVG는 코드로 편집할 수 있는 결과, JSON은 선택한 설정의 전달 파일이다. 어느 파일을 받아 적용했는지 구분한다. PNG를 받았다는 이유로 그 안의 재질별 레이어나 원래 3D 광원까지 편집 가능하다고 간주하지 않는다.
🌸 지도/실사처럼 원본 비트맵이 포함된 시안은 이미지 내부의 각 부분을 색상 컨트롤로 독립 재채색할 수 없다. 실제 편집할 수 있는 항목과 원본 픽셀을 유지하는 항목을 구분한다. 전체 색조 필터를 부분 채색처럼 제시하지 않는다.
🌸 MaterialRenderer.render(유형, 설정)의 실제 코드와 JSON을 같이 확인한다. UI에서 고른 값이 렌더러에 연결되지 않는 경우 지시를 무시하지 말고 그 연결을 수정한다. 원본, 선택 설정, 렌더 직전 전달값, 출력 프레임을 나란히 비교한다.
🌸 렌더러 기본값을 바꿔도 기존 localStorage·기존 프로젝트·이미 출력된 PNG/MP4는 자동 갱신되지 않는다. 실제 사용 중인 저장 설정을 확인하고 해당 프로젝트에만 적용한다.
