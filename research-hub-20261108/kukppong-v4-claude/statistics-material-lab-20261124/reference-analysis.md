# 통계·지도·종이: 원본 재질 분석

원본 9장을 직접 확인하고, 기존 측정값과 추가 5×5 픽셀 표본을 연결했습니다. **명시 HEX / 화면 실측 / 관찰한 간격 / 🌸 재현 제안**을 구분합니다. 새 그라데이션·조명·투명도·블러는 원본 제작 파일에서 추출한 물성값이 아닙니다.

## 왜 이전 단순 시안이 달라 보였는가

유리의 색은 한 가지 HEX로 끝나지 않습니다. 파란 내부색, 표면의 청백색 반사, 두께에서 어두워지는 흡광, 가느다란 베벨 선, 바깥의 작은 빛 번짐이 겹칩니다. 원판의 푸른 원도 단색 원+그림자가 아니라 흰 판 위에서 중심부터 가장자리로 사라지는 넓은 방사광입니다. 지도에는 대륙 윤곽 외에 양각 옆면·국경 홈·접촉 그림자가 필요합니다.

🌸 재현 비교는 같은 crop·같은 표시 크기로 진행합니다. 가로/세로 출력에서는 도형을 찌그러뜨리지 않고 정보 영역을 재배치합니다. 원본 crop을 새 생성물이라고 표시하지 않습니다.

## 값의 출처

| 구분 | 의미 | 사용 방법 |
|---|---|---|
| 원문 HEX | 이미지에 글자로 써 있는 코드 | 그대로 보존·선택 |
| 화면 실측 | 특정 ROI의 합성 RGB 중앙값 | 결과 색 대조; 물성 원색으로 단정 금지 |
| 관찰 경계 | 화면에서 눈으로 읽은 픽셀 박스/간격 | 비교 기준점; 대체로 ±6px |
| 🌸 재현 제안 | 비슷하게 만들기 위한 초기 stop/빛/두께/블러 | 조절 후 사용자 설정으로 저장 |

## 공통 재현 규칙

1. 원본과 재현은 같은 관심영역을 같은 크기로 놓고 비교한다. 원본 전체 폰화면과 작게 잘린 재현을 비교하지 않는다.
2. 참조 이미지 crop/줌과 새로 만든 재현을 분명히 구분한다. 원본 crop을 생성 결과라고 표시하지 않는다.
3. 🌸 원본 보기 / 재현 보기 / 나란히 / 겹쳐보기에서 같은 기준점과 종횡비를 유지한다.
4. 명시 HEX는 편집 가능한 기본색으로 보존하되 반사·흡광·그림자는 별도 색상과 알파로 계산한다.
5. 🌸 HEX 선택과 그라데이션 stop 색/위치/알파 선택을 분리한다. 전체 배경의 opacity로 글자까지 흐리게 만들지 않는다.
6. 그라데이션은 내부색, 밝은 반사, 어두운 두께, 주변 번짐 네 부분을 독립 조절한다. 하나의 2색 linear-gradient만으로 대체하지 않는다.
7. 블러는 빛/그림자/재질층에만 적용한다. 선명해야 하는 숫자·지명·출처는 최종 별도 레이어다.
8. 가로와 세로는 재배치하며 도형의 가로세로 비율을 바꾸지 않는다.
9. 생성형 이미지는 재질/광학 시안으로 사용한다. 통계 숫자·도형 비율·지도 경계는 실제 데이터에 연결된 편집 가능한 요소로 합성한다.
10. 🌸 기본값 복원은 스타일별로 수행한다. 사용자의 기존 자막 컬러·폰트 설정을 전체 초기화하지 않는다.

[원본 이미지](../design-reference-master-20261124/references/REF-01.jpg) · 1279×1536px · 비교 crop `[300, 48, 685, 397]`

- 대륙 윤곽을 평면 아이콘으로 대체하면 원본의 면높이·세밀한 국경선·국경 주변 음영이 사라진다.
- 지도 윗면은 거의 흰색이며 측면과 바닥의 회색 대비로 양각이 보인다. 모든 면을 동일한 흰색으로 만들지 않는다.

- 🌸 **16:9**: 지도는 오른쪽 또는 화면 중앙 62~72% 폭. 큰 수치는 지도 위쪽에서 일부 겹침. 설명/출처는 지도 밖의 왼쪽 또는 하단에 배치.

## REF-03 · 분리 원판 · 코발트 확산광

[원본 이미지](../design-reference-master-20261124/references/REF-03.jpg) · 1279×1536px · 비교 crop `[160, 245, 1065, 825]`

- 재질은 무광에 가까운 흰 판이며 중앙의 넓은 푸른 확산광이 핵심이다. 원판 전체를 푸르게 칠하면 다르다.
- 밝은 푸른 중심에서 흰 원판까지 갑자기 끊기지 않고 넓게 사라진다. 원판 밖으로 번지는 정도는 작다.
- 절단면의 진한 푸른 L자 벽이 표면 발광과 구별된다.
- 숫자도 푸른 빛에 물들어 대비가 약하다. 원본 대조에서는 그대로 보여주고 실제 영상용은 별도 가독성 조절을 사용한다.
