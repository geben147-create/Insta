## 파일

- ep01-v42-tts.txt / ep02-v42-tts.txt: TTS에 넣을 순수 내레이션 본문
- ep01-v42-cuts.csv / ep02-v42-cuts.csv: 1:1 원문 SRT 확인 컷 후보(영상 ID, 시작·종료, 중국어/한국어, 로컬경로)
- dataset.json: 아웃라인·대본·영상편집 작업 데이터의 마스터

## 중요

- 본문/컷은 원본 자막을 근거로 제작했지만 자동 음성인식과 번역은 실제 음성 재청취 필요.
- 원본 MP4 로컬 전송·프레임 점검·TTS 음성 생성·완성 영상 편집은 수행하지 않음.
- 이용허락은 모든 영상에서 UNCONFIRMED: 3–6초로 자르거나 크롭·좌우반전한다고 자동으로 사용권이 생기지 않음.
- 대본과 컷의 시간은 분당 330자·원본 발언 4초를 가정한 *예상값*. 렌더 후 실제 싱크 재측정.
