한국이 일본을 앞섰다, 사람들은 그중 무엇을 좋아했나

추천: A안. “한국 서울이 일본 도쿄를 앞섰습니다. 2026년 미국 여행 잡지의 대도시 독자 투표에서 서울 1위, 도쿄 2위였습니다.” 제목·첫 화면에 ‘미국판 독자 투표 / 대도시’를 동시에 적는다. 같은 미국판의 국가 부문은 일본이 1위였다. 여기서 바뀐 것은 나라 전체의 서열이 아니라, 두 도시가 놓인 순위표다. [1–3]

첫 30초는 비교 → 서로 다른 화자의 원음 → 질문. 추천 A안은 0:00–0:05에 순위표, 0:05–0:08에 일본어 보쌈상 반응 [J1], 0:08–0:12에 중국어 브이로그의 ‘오늘 밤 최고’ [N1], 0:12–0:25에 ‘서울에서 뭘 그렇게 좋아했을까요?’와 낮·밤 대비 컷. 두 영상의 화자는 투표에 참여한 독자로 소개하지 않는다. 통계가 결과를 말하고, 사람들의 체험은 구체적 사례를 보여 준다. B·E는 한국이나 한일 비교가 들어간 실제 원음부터, C는 비교 질문 카드, D는 한국 칭찬 한 문장과 중국어 원음으로 연다.

안 줄거리 주전개 + 보조전개 감정의 변화 제작 판정
A 순위 역전 도쿄 1위였던 순위표가 바뀐다. 일본어 여행자의 낮 식탁과 중국어 채널의 서울 야식으로 구체적인 매력을 보여 준다. 결과 선공개 + 두 공간의 사례 릴레이 놀람 → 의심 → 배고픔 → 해소 → 발견 → 자부심 1순위. 도시 순위와 개인 체험을 분리할 때 가장 강하다.
B 일본인 여행자의 한 상 일본에서 먹던 김치와 다르다는 한마디를 먼저 듣고, 기다림·보쌈상·디저트·귀국길까지 따라간다. 1인 체험 여정 + 처음 말의 회수 호기심 → 동행 → 조급함 → 만족 → 재발견 → 여운 2순위. 원음 중심으로 탄탄하다. 한 채널 의존은 권리와 화면 다양성 확인이 필요하다.
C 가격표의 양면 일본에서 평범한 제품이 한국에선 비싸다. 반대쪽 가격표를 보자 같은 화자가 한국에선 쟁여 두겠다고 한다. 동일 조건 비교 + 방향을 뒤집는 반전 기대 → 불만 → 의심 → 확인 → 역전 → 납득 짧은 비교편 우선. 원비교 영상이 43초 안팎. 17분으로 늘리려면 검증된 별도 영수증·취재가 필요하다.
D 심야 배달의 양면 중국어 브이로거가 칭찬한 야식의 주문 화면을 따라가다, 배달을 해 본 사람의 하루 정산으로 시점이 바뀐다. 결과에서 역추적 + 손님·기사 교차 통쾌함 → 의심 → 놀람 → 고마움 → 존중 원본 길이는 충분한 후보. 일본보다 빠르다는 근거는 없다. 편의와 이를 만든 사람을 같이 보여 준다.
E 김치에서 김장으로 일본어 여행자가 느낀 맛의 차이가 한국 한 집의 배추·천일염·함께 만드는 손으로 이어진다. 사물 역추적 + 도쿄와 한국의 왕복 놀람 → 친숙함 → 의문 → 존중 → 여운 문화·감정선이 가장 뚜렷하다. 한 가정 영상이 짧아 17분형은 별도 촬영 또는 허가 자료가 필요하다.

아래 1:1 검수표 읽는 법. ‘적용’ 칸은 사용자 자료의 기법이 실제로 어느 장면에서 작동하는지 적은 것이다. ‘다음’ 칸의 따옴표는 새로 쓴 전환 내레이션 예시, 소스표의 따옴표는 자동 자막에서 읽고 직접 옮긴 발언 후보다. [원음]은 삽입 예정, 확정 음성 인증을 뜻하지 않는다. [화면]은 원음을 끄거나 자체 제작. 원음에 담긴 개인 선호를 통계나 조사 참여자 발언으로 바꾸지 않는다.
