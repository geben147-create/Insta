# 추가 프롬프트 · 영상 소스 사용 기록

- STEP 0~3: 기존 GitHub 소스 사용 장부와 Google Sheets에서 영상 ID 또는 원본 URL을 먼저 대조한다. 이전 회차·사용 장면이 있으면 후보 옆에 적고, 해시 불일치 또는 권리 불명은 분리한다.
- STEP 4: 회차 ID + 소스 ID + 구간(IN/OUT)을 키로 기록한다. 대본에서 원음·화면·자막으로 골라 넣은 것은 `대본 채택`, 확인만 한 것은 `후보/미채택`, 전개만 가져온 것은 `구조 참고`, 권리·화자·자막 미확인은 `보류`로 적는다. 쓰지 않은 이유도 적는다. 대본 채택을 실제 영상에 썼다고 기록하지 않는다.
- STEP 5~7: 청취와 구간·권리 검수 결과를 갱신한다. 완성 편집 타임라인에 남은 원본만 `편집 사용`; 빠진 컷은 `편집 미사용`과 사유를 적는다. 대체하면 새 ID와 컷을 별도로 남긴다.
- STEP 8: 공개 회차 링크, 편집본 버전, 최종 사용 구간과 시각을 기존 GitHub 장부와 Google Sheets에 같은 키로 업데이트한다. 원본 소스 목록은 덮어쓰지 않는다. GitHub와 Sheets 양쪽을 다시 읽어 일치할 때만 기록 완료. 접근 불가 시 TSV를 남기고 시트는 `미기록`으로 표기한다.
- 열: 회차 ID | 소스 ID | 분류 | 원본 URL | 쓰임 | 대본 시각 | 원본 IN–OUT | 대본 상태 | 편집 상태 | 권리·확인 | 미사용 사유 | 대본 링크
