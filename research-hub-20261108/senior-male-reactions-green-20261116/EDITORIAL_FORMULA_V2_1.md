# 🇰🇷 단골이슈 레퍼런스 기반 국뽕 대본 제작 공식 V2.1

2026-11-16 · 사용자 제공 자동 자막 4개 사례에서 **전개 구조만 참고**. 원문 문장과 확인되지 않은 사건을 그대로 복제하지 않는다.

## A. 최우선 편집 규칙
1. 첫 9초에 **외국인이 한국을 긍정적으로 바라본 실제 반응 3개**를 3초씩. 사람이 실제로 하지 않은 칭찬을 만들지 않는다. 긍정 발언이 3개 미만인 주제는 **외국 언론 제목, 공식 해외 전문가 평가**를 유형 표시하고 사용한다. 영상 제목과 사람의 발언을 섞지 않는다.
2. 9~30초에 긍정적인 결과를 한 번 보여주고, 핵심 의문 1개와 아직 말하지 않은 더 큰 사실 1개를 예고한다.
3. 30초 이후 전개를 8단계로 나눈다: 결과 선공개 → 역사·개인 배경 → 장애·억울함 → 외국인이 본 첫 발견 → 새로운 의문 → 외신·공식 통계로 관점 전환 → 기술·산업·문화의 더 큰 가치 → 처음의 감정 회수.
4. 외국인 SNS 반응은 **영상 초반 점화장치**이고 전체 10분을 그 사람의 발언만 반복 설명하지 않는다. 관련 해외 전문가, 해외 뉴스, 공식 수치와 실제 생활 장면을 교차하여 더 큰 이야기를 만든다.
5. 작가 나레이션/해설 음성 60% 이상. 컷 4초 이하. 실사 원본 영상 > 원본 사진 > 직접 제작 차트 순으로 비중을 배분한다. 차트는 영상 위 흰색 반투명 패널 1~2회.
6. 50~80대 남성의 경험과 연결되는 **산업화·노동·철도·군사·자동차·가족·스포츠의 실제 기억**을 사용하되 근거 없는 가짜 사연을 만들지 않는다.
7. 시청자에게 말하는 본문에서는 **클립, 자막, 소스, 재사용, 저작권, 원본, 검수, 편집 방법, 가짜 발언을 만들지 않겠습니다, 한국 칭찬만 하면 안 됩니다** 등의 제작자 메타 언급을 하지 않는다. 이런 내용은 오른쪽 검수표와 편집지시서에만 둔다.
8. 같은 문단이 반복해서 "좋은 점은 있습니다. 하지만 아닙니다"식 균형 강박으로 흐르지 않게 한다. 반론은 해외 공식 자료와 구체적인 숫자·현장 사실이 자연스럽게 말하게 한다.
9. 외국인이 지적한 불편이나 갈등은 허위로 꾸미지 않고 이야기의 긴장으로 사용한다. 다음 단락에서 한국이 가진 더 큰 증거나 성취로 시선을 옮긴다.
10. 실제 댓글/확인된 해외 발언과 구성용 가상 댓글은 반드시 구분한다. 가상 댓글을 실제 원문처럼 편집하지 않는다.

## B. 실제 사용자 참고 대본의 기능 분석
- **허미미 스타일**: 결과와 태극기를 앞에 놓음 → 가족의 약속 → 일본에서의 성장 → 선택과 장애 → 사실·기록으로 반전 → 감정 회수. 강점은 사건의 연결이지 과장된 일본인 악성댓글 재현이 아님.
- **한국 사격 스타일**: 특정 경기 결과 → 고도의 정밀성·멘탈 → 이전 선수 기록 → 국내 경쟁 → 국제대회 기록 → 한국 자긍심. 단, 특정 기록과 선수명은 제작 당시 공식 경기자료로 재확인.
- **외국 스타 한국 방문 스타일**: 화제 장면 선공개 → 평범한 거리로 이어지는 예상 밖 행동 → 작은 사건 여러 개 → 새로운 근거 → 한국의 특성으로 확장.
- **외국인의 경주 평가 스타일**: 외국인 실제 여행 영상 짧은 호평 → CNN/관광 전문자료 → 역사·유적·음식으로 넓히기 → 다른 외국인으로 시선 전환 → 감정 회수.

## C. 1회 전체 복붙에 포함할 필드
- 에피소드 ID/제목, 3초×3 오프닝 클립, 원본 영상 ID/URL/로컬 파일 기록/원본 타임코드/중국어/번역
- 대본 8구간 시간/전체 나레이션/각 문단의 목적
- 4초 이하 컷 1:1 편집표, 감정선 그래프/음악/글꼴/전환
- 다른 해외 자료 2~4개 링크, 수치 기준일·대상·범위
- 내레이션 실제 발화 비중/목표 10분 실측
- 권리, 초상권, 자막, 통계, 영상 ID의 미확인 표시
