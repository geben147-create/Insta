[국뽕 훅·전개 V2.1 공식 및 금지 문장](./EDITORIAL_FORMULA_V2_1.md)

대본은 회차당 공백 제외 약 **2,650~2,910자**로 확장된 신규 원고다. 영상 목표는 10분이나 실제 TTS 출력과 60% 해설 비율, 4초 이하 컷의 정확한 실측은 하지 않았다. 발행 전에 길이에 맞춰 조정해야 한다.

모든 원본은 **다운로드 기록과 자막 유무**를 근거로 연결했다. 우분투 HDD 현재 파일 실존 검사는 별도이며, **타인 영상의 로컬 보유가 재배포 허락을 의미하지 않는다.** 중국어 AI자막은 직접 원음 교차 검수 후 사용한다. 서류로 증명된 해외 자료·영상 제목과 실제 외국인의 발언을 혼동하지 않는다.

참고한 사용자 제공 자동 자막은 전개 구조 참고용. 그 안의 대회 성적·사람의 발언·통계 등은 사실 자료로 옮겨 적지 않고 각 회차에 별도 출처를 붙였다.
