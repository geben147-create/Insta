# STEP 6 · 음성
- 최종 대본의 내레이션만 합성한다. 외국인 실제 음성을 가짜 성우로 재현하지 않는다.
- python3 -I bin/tts_jsonl.py episodes/<이름>
- bash /home/yh/ai-work/tts_cosy_prod/qwen_tts.sh episodes/<이름>/build/narration.jsonl episodes/<이름>/build/tts -12
- 줄마다 3번 만들어 받아쓰기로 가장 정확한 것을 고른다. 받아쓰기 오류율이 높은 줄은 다시 받아써서 숫자 표기 차이인지 발음 문제인지 가른다.
- 🔴 제작용 메모·ID·H/S 코드가 음성에 들어가지 않았는지 검사한다.

# STEP 7 · 영상
- 원음 구간: 원본 클립(약 4초) + 한국어 자막 띠. 원본의 중국어 자막은 띠로 덮는다.
- 🔵 내레이션 구간: 가지고 있는 원본 영상을 소리 없이, 어둡게(반투명) 깔고 재생한다. 그 위에
    · 키워드 헤드라인: 흰 굵은 글씨 + 형광 강조(참고 사진 4·6번)
    · 댓글·인용: 흰 말풍선 + 이모지(참고 사진 5번). 실제 댓글이 없으면 지어내지 않는다.
    · 그래프: 회색 질감 배경 + [ 제목 ] + 큰 숫자 + 출처(참고 사진 3·7번)
    · 색: 첨부하신 사진에서 추출한 주요 색상은 다음과 같습니다.

- 배경 영상은 "다음 원음 클립 직전 구간"을 쓴다. 남의 영상·광고·큰 자막 카드 구간은 BROLL_FORBID에 적어 피한다.
- 좌우반전·속도 변경.
- /home/yh/ai-work/tts_eval/venvs/qwen/bin/python bin/render.py episodes/<이름>
- 결과: out/<이름>.mp4, subtitles-ko.srt, cut-list.csv(원음 IN/OUT), broll-list.csv(배경), timeline.json
- 표본 프레임을 뽑아 화면을 확인하고, 길이(≥10분)·내레이션 비율(약 60%)·음량을 잰다.

# STEP 8 · 게시
- python3 -I bin/make_checker_ep.py episodes/<이름> <자막 폴더>   → 검수판용 데이터, 대본 MD
- python3 -I bin/build_checker.py <Insta 저장소 폴더>              → V4 검수판(탭·형광펜·단계·체크리스트 1:1, 대본 접기/펼치기)
