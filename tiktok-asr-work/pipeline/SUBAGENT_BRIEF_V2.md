# Opus 자막 번역·평가추출 지침 v2 (영상 여러 개 순차 처리)

목적: 중국 SNS 영상(주로 중국인이 한국·일본을 다룸)의 음성인식 자막을 한국어로 **초벌 번역**하고, "한국(또는 일본)에 대한 평가"를 구조화해 뽑는다. 번역은 **자막 초안용(대충 OK)** — 단, 줄 단위 1:1은 엄격히 지킨다(타임라인 때문).

## 입력 (영상 1개)
- `/home/yh/ai-work/asr_20261115/out/{ID}.asr.json` → `lang`(원어), `sentences[{s,e,zh}]` (zh 필드 = **원어 텍스트**. 중국어일 수도, 러시아어/영어/한국어 등일 수도 있음)
- 과제 컨텍스트에 영상별 `제목원문 / 국가힌트 / 분야힌트` 가 주어진다.
- ASR 오인식은 문맥으로 바로잡아 번역(확신 없으면 "(?)" 또는 "(인식 불명)").

## 영상마다 해야 할 일
1. **ko**: sentences와 **같은 개수**의 한국어 번역 배열. 짧은 구어 자막체. 고유명사는 한국 표기. 외국어 글자(중국어 한자 등) 남기지 말 것. 원어가 한국어면 오탈자만 정리해 그대로. 소리 없음/노래뿐인 줄은 "(음악)" 등.
2. **줄 태그** (인덱스 = 0부터). 대상은 **영상이 다루는 나라**(country):
   - `good` 칭찬/감탄/장점, `bad` 불만/비판/단점, `eval` 비교·가격/품질 평가(단정 없음), `key` 핵심정보·반전·결론·명대사(전체 5~10%). 한 줄 한 태그. 확실한 것만.
   - `vs`: eval 줄에 비교 상대가 있으면 {"인덱스":"일본|중국|유럽|미국|한국|기타"}.
3. **메타**
   - `country`: 한국 / 일본 / 기타 (힌트가 "미분류"면 내용으로 판단)
   - `cat`: 여행·쇼핑·음식·게임·뷰티·의료·자동차·가전·경제·교육/유학·생활·문화·연예·스포츠·교통·기타 중 하나
   - `title_ko`: 한국어 제목(원문 제목 번역, 40자 이내)
   - `sum`: 3줄 요약(\n 구분), `verdict`: 해당 나라에 대한 전체 평가 한 줄(긍정/부정/혼합+근거)
   - `hooks`: 대본 훅으로 쓸 만한 번역 문장 3개
   - `chapters`: 4~12개 `{"at":"mm:ss"(1시간 넘으면 h:mm:ss),"h":"장면 제목"}` — at은 해당 장면 첫 줄 s값에서 계산
   - `praise`: 영상 속 "이 나라가 좋은 이유" 최대 10개 `{"i":줄인덱스,"note":"한 줄 요약"}`
   - `crit`: "나쁜 점/비판" 최대 10개 같은 형식
   - `compare`: 다른 나라와의 비교 최대 10개 `{"vs":"일본|중국|유럽|미국|한국|기타","i":줄인덱스,"note":"한 줄","result":"우세|열세|동등|중립"}` (result는 영상 나라 기준)
   - `use`: 국뽕 유튜브 영상 제작 시 이 영상을 어떻게 쓸지 1줄(어느 시각의 어떤 장면/주장을 소재로)
   - 평가가 거의 없는 영상이면 해당 배열은 [] 로 두고 verdict에 "평가 거의 없음(중립)".
