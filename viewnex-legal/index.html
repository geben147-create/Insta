ViewNex(뷰넥스) 서비스 안내

ViewNex는 운영자 한 명이 자신의 PC에서 YouTube 콘텐츠를 기획할 때 쓰는 비공개 분석 도구입니다. 인터넷에 공개된 앱이 아니며 회원가입·로그인이 없습니다. 이 페이지는 서비스 설명과 법률 문서만 제공하고 앱을 열지 않습니다.

무엇을 하나요

  • 사용자가 검색을 실행할 때만 YouTube API Services(YouTube Data API v3: search.list, videos.list, channels.list, 읽기 전용, OAuth 없음)로 공개 영상·채널 정보를 조회합니다.
  • 원본 제목·썸네일·채널명·공개 조회수·공개 구독자 수와 YouTube 출처를 표시하고, 영상은 YouTube 내장 플레이어로만 재생합니다.
  • YouTube에 업로드·댓글·평가 등 쓰기 작업을 하지 않으며, 데이터를 판매·공유하지 않고 광고가 없습니다.
  • 공개 통계는 30일 안에 갱신하거나 삭제하며, 앱 화면에 마지막 수집일과 다음 갱신 기한을 표시합니다.
  • 예상 수익 시나리오(가정 기반 자체 추정치)는 Google의 서면 승인 전까지 공개 API 데이터에 자동 적용하지 않습니다.

심사자 안내

앱은 운영자 PC의 로컬 주소(127.0.0.1:8931)에서만 실행되므로 외부 접속 주소·데모 계정이 없습니다. 실제 화면 캡처와 구조도는 신청서에 첨부했으며, 로컬 작업 화면 녹화는 요청 시 제공합니다.

English. ViewNex is a private, single-user YouTube content-planning tool that runs only on its operator's computer (no public app URL, no sign-in). On explicit user action it reads public data through YouTube API Services (YouTube Data API v3, read-only, no OAuth), shows YouTube attribution and plays videos only in the YouTube embedded player. Public statistics are refreshed or deleted within 30 days. Revenue scenarios are the tool's own assumptions and stay disabled for API data until written approval. Screenshots and diagrams are attached to the application; a screen recording is available on request.
