한 줄 결론
두 고양이를 ‘래퍼 듀오’로 브랜딩한 뮤직비디오. 비트에 맞춘 하드 컷, RGB 글리치, VHS 노이즈 전환, 크래시 줌, 립싱크로 30컷을 28초에 몰아넣었다. 스토리 대신 ‘캐릭터의 태도(스웩)’를 파는 영상.

1. 왜 떡상했나 — 4단 공식

① 훅 (0~1.1초)조용한 인트로 속 회색 고양이가 다이아 목걸이 차고 카메라를 노려봄.
② 드롭 (1.1~3.5초)비트가 터지는 순간 얼굴로 크래시 줌(160%). ‘등장’의 쾌감.
③ 핑퐁 (3.5~28초)두 고양이를 반 박자~한 박자마다 교차. RGB 글리치·VHS 노이즈로 전환에 타격감.
④ 루프 (28.6초)마지막 컷이 첫 컷과 같은 Tipsy 정면 → 처음으로 돌아가도 이어짐.
감독 노트

Oscar 계정 영상들이 ‘사건’을 판다면 이 영상은 ‘캐릭터’를 판다. 회색 태비(Tipsy)=다이아 목걸이·반쯤 감긴 눈의 여왕, 골든 롱헤어(Youmi)=금 체인·무표정 보스. 두 캐릭터가 핑퐁처럼 번갈아 나오며(교차 편집) 랩을 주고받는다. 배경을 컷마다 바꿔서(빨간 벨벳 커튼 → 빨간 네온 향수 진열장 → 금색 벽+샹들리에 → 카타나 책장 → 링라이트 → 아르데코 패턴) 저예산인데도 ‘여러 세트에서 찍은 뮤비’처럼 보인다. 비트가 약 0.56초 간격(107 BPM)이고 컷도 대부분 0.5~0.6초 → 박자에 붙은 편집이 중독성을 만든다.

제작 원칙 (똑같이 만들기 위한 핵심)
캐릭터 2마리의 ‘얼굴 일관성’이 성패를 가른다. 먼저 각 캐릭터의 기준 이미지(정면·측면·털 색·액세서리)를 만들고, 모든 샷을 참조 기반(ref2video)으로 생성한다. 입은 AI 영상 생성 단계에서 ‘입을 벌렸다 닫았다 랩하는 듯’ 움직이게 하고, 정확한 가사 싱크가 필요하면 h3-lipsync로 음원에 맞춘다. 컷은 전부 비트 위치(0.56초 격자)에 맞춰 편집에서 자른다 — 생성 영상은 샷당 3~5초 넉넉히 만들고 0.3~2초만 쓴다.

FFmpeg · 복붙 실행용 (파일명만 바꾸기)# shots/ 폴더에 샷별 클립(sNN.mp4)을 만들고, cuts.txt 에 비트 위치대로 사용할 구간 기록 # 비트 격자: 0.559초 (107.4 BPM) — 컷 위치는 가장 가까운 반 박자(0.28초)에 스냅 # 1) 샷 하나를 잘라 규격화 (예: s01을 0.0~3.5초 사용) ffmpeg -i s01.mp4 -vf "scale=1080:1920,fps=30,setsar=1,trim=0:3.5,setpts=PTS-STARTPTS" -an -c:v libx264 -crf 16 c01.mp4 # 2) 크래시 줌 (1.75~2.75초 동안 100%→160%, 3.0초에 원복) ffmpeg -i c01.mp4 -vf "scale=2160:3840,zoompan=z='if(between(it,1.75,2.75),1+0.6*(it-1.75),if(lt(it,1.75),1+0.02*it,1))':x='iw/2-(iw/zoom/2)':y='ih/2.6-(ih/zoom/2.6)':d=1:s=1080x1920:fps=30" -c:v libx264 -crf 16 c01z.mp4 # 3) 반 박자 RGB 글리치 스트로브 (S3: 0.3초~ 켜짐/꺼짐 반복) — 샷 내부 시간 기준 ffmpeg -i c03.mp4 -vf "rgbashift=rh=-14:bh=14:gv=4:enable='lt(mod(t+0.0,0.5),0.2)*lt(t,2.5)',noise=alls=18:allf=t:enable='lt(mod(t,0.5),0.2)*lt(t,2.5)'" -c:v libx264 -crf 16 c03g.mp4 # 4) VHS 글리치 전환 (샷 앞 0.25초에 가로 노이즈+색 번짐+흔들림) ffmpeg -i c05.mp4 -vf "rgbashift=rh=-24:bh=24:enable='lt(t,0.25)',noise=alls=40:allf=t+u:enable='lt(t,0.25)',crop=iw-60:ih:30+30*sin(120*t)*lt(t\,0.25):0,scale=1080:1920,eq=saturation=1.6:enable='lt(t,0.25)'" -c:v libx264 -crf 16 c05v.mp4 # 5) 전체 이어붙이기 (list.txt: file 'c01z.mp4' ... ) + 음악 + 루프 하드 엔드 ffmpeg -f concat -safe 0 -i list.txt -i song.wav -map 0:v -map 1:a -c:v libx264 -crf 17 -pix_fmt yuv420p -af "atrim=0:28.65,loudnorm=I=-14:TP=-1:LRA=11" -t 28.65 final.mp4 # 6) 전체 톤: 채도 약간↓, 대비↑, 블랙 살짝 들어올린 시네마틱 ffmpeg -i final.mp4 -vf "eq=contrast=1.08:saturation=0.9:gamma=0.97,curves=all='0/0.04 0.5/0.5 1/0.97'" -c:a copy final_grade.mp4
