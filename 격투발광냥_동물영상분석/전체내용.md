## 7편 공통 떡상 공식
- 첫 프레임 = 상황 전부. 7편 모두 0초에 ‘말이 안 되는 상황’이 이미 화면에 있다 (슬랩 테이블 위 고양이, 목 조르는 고양이, 방사능 페인트통 앞 고양이, 운전하는 고양이…). 설명·자막 없이 3초 안에 읽혀야 한다.
- 진짜처럼 찍은 척. Oscar 계정 4편(1·2·3·6위)은 전부 컷이 거의 없는 휴대폰 직캠 문법 + 현장음. ‘AI 티’를 지우는 게 조회수의 조건.
- 반전은 60~70% 지점. 10초 영상에서 핵심 사건은 6.3~7.4초에 터진다 (1위 6.5초, 2위 7.1초 탭아웃, 3위 7.35초 불 끄기, 6위 7.27초).
- 두 번 웃기기. 1차 사건(페인트에 빠짐) 뒤에 2차 반전(어둠 속에서 빛남)이 붙은 구조가 강하다.
- 동물은 끝까지 무표정. 고양이가 웃거나 과장된 표정을 짓지 않는다. ‘진지한 얼굴로 황당한 일’ = 데드팬 코미디.
- 소리로 반응 유도. 관중 함성·‘No way.’ 한 마디가 웃음 타이밍을 알려준다. 음악은 뮤직비디오형(4위·5위·7위)에만.
- 루프 설계. 마지막 프레임이 첫 프레임으로 자연스럽게 이어지거나(검은 화면, 정지 포즈) 끝이 ‘뚝’ 끊겨 다시 보게 만든다.

## 1. 왜 떡상했나 — 4단 공식
- ① 훅 (0초): 첫 프레임부터 고양이가 두 발로 서서 거구 앞에 가드 자세. 설명 없이 상황이 읽힌다.
- ② 긴장 (0~6.4초): 고양이 앞발이 천천히 올라가며 ‘준비 동작’. 남자는 무표정으로 내려다봄. 소리는 낮은 관중 웅성임뿐.
- ③ 폭발 (6.5초): 앞발 한 방 → 얼굴에서 하얀 분필 가루 폭발 → 거구가 테이블에 엎어져 기절. 관중 함성 폭발.
- ④ 루프 (9.4초): 검은 화면 0.63초 + 무음으로 뚝 끊기 → 처음 장면으로 돌아가며 반복 시청 유도.

### 감독 노트
실제 파워슬랩 중계를 휴대폰으로 테이블 높이에서 찍은 듯한 ‘현장 직캠’ 문법이다. 컷이 없어서 조작 의심이 줄고, 관객은 ‘언제 때리지?’를 기다리며 끝까지 본다. 기다림(0~6.4초) 64% : 폭발(6.5~9.4초) 29% : 검은 화면 7%. 마지막 0.63초 검은 화면은 릴스가 처음으로 되돌아갈 때 ‘다시 보기’를 자연스럽게 만드는 루프 장치다. 분필 가루 폭발은 실제 파워슬랩 선수들이 손에 바르는 초크를 재현한 디테일로, 타격 순간을 시각적 ‘느낌표’로 만든다.

### S1. 대치 — 가드 올린 고양이와 내려다보는 거구 (0.00s → 3.50s, 3.50초)

- 샷 크기: 미디엄 투샷 (고양이 전신 + 남자 가슴 위)

- 피사체 위치: 고양이 = 왼쪽 아래 1/3 (가로 0~45%, 세로 40~100%) / 남자 = 오른쪽 절반, 얼굴은 오른쪽 위 교차점
- 동물 자세·연기: 고양이 뒷발로 서서 앞발 두 개를 가슴 앞에 모은 복서 가드. 귀 앞으로, 눈은 남자 얼굴을 올려다봄. 남자는 턱수염, 뒤로 묶은 머리, 상의 탈의, 무표정으로 고양이를 내려다봄.
- 배경·소품: 검은 원형 패드 슬랩 테이블(로고 인쇄), 뒤쪽 흰 심판석 배너, 파란 조명 관중석, 천장 조명 4개
- 조명·색감: 경기장 천장 스포트라이트(위 왼쪽), 파랑-남색 배경 + 따뜻한 피부톤, 대비 강함
- 들어올 때 전환: 영상 시작 (프리롤 없음)
- 나갈 때 전환: 끊김 없이 이어짐 (원테이크)
- 소리: 경기장 웅성임만. 평균 -33dB 수준으로 조용함 → 뒤의 타격음이 더 크게 느껴지게 하는 ‘빈 공간’

  - 0.0–1.5s: 고양이 가드 유지, 앞발 끝이 살짝 까딱임 (살아있는 느낌의 미세 동작)

## 5. FFmpeg 레시피
```
# 0) 폴더: clipA.mp4(0~6.4초) clipB.mp4(타격~KO) 또는 full.mp4(10초 한 번 생성)
#    sfx_crowd.wav sfx_slap.wav sfx_puff.wav sfx_gasp.wav sfx_cheer.wav

# 1) (분할 생성했을 때) 두 클립 이어붙이기 → 9.40초로 자르기, 60fps·1080x1920 통일
ffmpeg -i clipA.mp4 -i clipB.mp4 -filter_complex "[0:v]scale=1080:1920,fps=60,setsar=1[a];[1:v]scale=1080:1920,fps=60,setsar=1[b];[a][b]concat=n=2:v=1:a=0,trim=0:9.40,setpts=PTS-STARTPTS[v]" -map "[v]" -an -c:v libx264 -crf 16 -preset slow body.mp4

# 1-b) (10초 한 번에 만들었을 때) 소리 제거 + 9.40초로 자르기

# 2) 끝에 검은 화면 0.63초 붙이기 (하드 컷)

# 3) 효과음 배치 (adelay = 밀리초) + 9.40초 이후 무음 + 유튜브/릴스 기준 -14 LUFS
```

## 7. 떡상 편집 기법

‘고양이가 사람처럼 가족 여행’ 콘셉트를 시트콤식 리액션 컷으로 엮은 20초. 캐릭터 4마리 각자 개그(가발 넘기기·립스틱 번짐·통화·만세)가 있지만, 하나의 큰 사건/반전이 없어 7편 중 반응이 가장 낮다 — 상위 영상들과 비교하면 ‘반전 한 방’의 중요성이 보인다.

## 1. 왜 떡상했나 — 4단 공식
- ① 훅 (0초): 검은 가발 쓴 주황 고양이가 운전대를 잡고, 옆에서 흰 고양이가 립스틱을 바름. 뒷좌석에도 고양이.
- ② 캐릭터 소개 (2~11초): 엄마(립스틱) → 아빠(기어·가발) → 엄마(번짐 심화, 푸시인) → 뒷좌석(통화·만세) 순서로 한 명씩.
- ③ 리액션 몽타주 (11.7~16초): 0.3~0.9초짜리 짧은 컷으로 네 캐릭터 표정을 빠르게 돌림.
