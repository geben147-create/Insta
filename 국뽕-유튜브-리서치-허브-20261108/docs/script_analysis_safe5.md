### 6-7. 메가 프롬프트용 규칙 초안(10개)
1. 첫 문장 = 제목 문장(큰따옴표 인용) 또는 숫자 충격 또는 외국인 육성 1줄. 인사는 30초 이후 또는 생략.
2. 45초 안에 "그런데/더 ~한 건 따로 있습니다" 1회, 중심 질문 1개, 약속 1개, 숫자 2개, 보류 1개("조금 뒤에 밝혀 드릴게요").
3. 본론은 번호 매긴 블록 3~8개. 블록 = 전환 라벨 → 사실·숫자 → 외국인 인용(매체·국적·직함·이름) → 핵심 한 줄 한다체 반복 → 1줄 해석(~인 거예요/~셈이죠) → 다음 블록 예고.
4. 제목 문장은 전체 55~77% 지점에서 육성/인용으로 회수하고, 회수 직후 1인칭 감정 1문장.
5. "여기서 끝이 아닙니다" 레이어 1~3개 뒤에 반드시 솔직한 한계/온도차 1단락.
6. 숫자는 생활 단위로 환산 1회("하루 한 명씩 58년", "열 대 중 세 대", "기와집 열 채").
7. 사실=합니다체, 해석·감상=해요체(~거예요/~거죠/~거든요), 인용=한다체. 문장 중앙값 25자, 장문 뒤 5~12자 펀치.
8. 질문 0.6~1.6/분, 숫자 1~9/분(장르별), 한국어 310~330자/분.
9. 칭찬의 주어는 항상 외국인/외국 매체("우리가 쓴 문장이 아닙니다"). 내레이터는 전달·해석만.
10. 결말: 첫 장면/첫 문장 콜백 → "우리"를 주어로 한 감정 문장 1개 → 질문형 CTA(경험 공유/선택/추천). 구독 요청은 넣지 않는다.
