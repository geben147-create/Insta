# SFX30 — 편집용 효과음 & 크레딧

`01.mp3`–`30.mp3`는 `../media.js`의 `SFX30` ID와 1:1로 대응하는 자체 합성 효과음입니다. 미리듣기와 실제 편집에 사용할 수 있습니다. 외부 샘플이나 음성 녹음, 유료 모델은 사용하지 않았습니다. `media.js`의 원본 링크는 용도와 음색의 참고용이며, 번호 파일에 해당 원음이 들어 있지 않습니다.

## 포맷 / 재생성

- 번호 파일: MP3, 48 kHz, 스테레오, 192 kbps, 디코딩 기준 0.17–1.12초. 내레이션과 함께 믹싱할 때는 `SFX30`의 장면별 gain을 출발점으로 삼고 귀로 조정하세요. 그 gain은 파일에 적용하지 않았습니다.
- Python 3 + NumPy, FFmpeg의 `libmp3lame` 필요. 같은 환경에서는 ID별 고정 시드로 재현됩니다. 스크립트는 지정한 번호의 파일만 씁니다. `voice-*.mp3`, `source-*.mp3`는 건드리지 않습니다.

```sh
python3 generate_sfx.py                  # 01–30 MP3
python3 generate_sfx.py 04 15 30         # 지정 ID만 다시 생성
python3 generate_sfx.py --wav 07 23      # MP3와 48 kHz/24-bit PCM WAV 함께 출력
```

## 별도 출처 프리뷰 (CC0)

## 검증

`ffprobe`로 33개 MP3의 코덱 및 스트림을 확인하고 `ffmpeg -xerror`로 전부 디코딩했습니다. 번호 파일은 `SFX30`의 30개 ID와 정확히 일치하며, 디코딩한 PCM 해시도 전부 다르고 샘플 피크는 −6.4 ~ −4.0 dBFS입니다. ID 19로 동일 MP3 재생성과 24-bit WAV 출력을 추가 확인했습니다.
