## 이용과 가공

모든 선택 음원의 원 제작자 페이지에 CC0가 명시되어 있습니다. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)에 따라 사용·수정·재배포할 수 있습니다. 원 제작자와 재배포 경로를 자발적으로 기록합니다.

MP3 파일은 공개 저장소의 출처 표시된 OGG 편집본을 변환한 것입니다. 새로운 소리 합성·배경음악 분리·음정 변경은 하지 않았습니다. 재배포처의 선행 편집과 이번 감쇠량, 필터, 커밋·blob SHA, 파일 SHA-256은 manifest.json에 기록합니다.

이번 편집: 피크가 각각 -10 / -11 / -12 / -15 / -12 / -15dBFS 이하가 되도록 감쇠하고 시작 3ms·끝 최대60ms 페이드를 적용했습니다. MP3 192kbps·48kHz이며 플레이어 기본 음량은 50%입니다. 음량 보정은 이미 적용되었으므로 내보내기 설정의 gain을 다시 적용하지 않습니다.
