## 1. 썸네일 문구 = 잘 만든 제목을 그대로 문구로
1. 답을 바로 말하지 않는다. "한국인이 좋아한 건 라면이었다" ✗ → "한국 라면에 외국인들 난리난 상황.." ✓
2. 끝은 **이유 / 상황 / ? / .. / ...** 로 끊어 궁금하게: ~난리난 이유, ~심각한 상황, ~부르는 이유, 왜 한국처럼 못하나?, "맵다! 근데..."
3. 필수 단어: **한국** + 반응 주체. **반응 주체는 하나만 쓴다** — 중국 사람이면 **중국인(들)**, 일본 사람이면 **일본인**, 러시아면 **러시아인**, 국적이 여럿이거나 불분명하면 **외국인(들)**.
   - ✗ "중국 외국인들" ✗ "중국인 외국인" ✗ "외국인들 해외 반응" (겹쳐 쓰기 금지)
   - ✓ "중국인 넋 나간 이유.." ✓ "외국인 넋 나간 이유.." ✓ "중국 블로거 한마디에 외국인들 반응.."
   - 빨간 태그는 **"해외 반응"** 네 글자만 ("외국인 해외 반응" ✗).
4. 강조어(근거에 맞는 것 하나): 대박·경악·충격·놀람·논란·오열·난리·대폭발·대반전·발칵·망연자실·백기·뒤집힌.
5. 비교·현장형: 비교 대상과 장면을 앞에 — 한국처럼 못하나 / 삼성으로 몰려가는 외국인 / 유럽인들 발칵 / 경악한 미국 / 무섭다 / 싹 다 쓸어갔다·망쳐놨다·무너졌다.
6. 국가 반응형: 실제 반응 주체를 적는다 — 중국인 반응 / 일본은 경악 / 일본이 망연자실한 이유 / 중일 크게 당황. 참교육형: 한국 깎아내리던 외국인 / 한국보다 일본이 좋다던 외국인.
7. “큰따옴표”는 영상 속 실제 발언만. 인용·인원·수치·반응 강도는 영상에서 확인한 범위만, 지어내지 않는다.
8. 숫자는 한글 단위: 4000 → 4천, 450000 → 45만, 1600 → 1천6백. 반올림해서 바꾸지 않는다.
9. 제목(4개)도 같은 규칙 + 이모지 1개 이상 + 반응 주체(중국인/일본인/외국인 중 하나) + 해외 반응. "중국 외국인"처럼 나라+외국인을 붙여 쓰지 않는다.

## 2. 화면 구성 — 꽉 차게 (듬성듬성 금지)
1. 배경은 화면 끝까지 확장. 사진이 짧으면 같은 사진을 흐리게(블러 18)·어둡게 키워 뒤를 채운다.
2. 글자 뒤가 복잡하면 그 띠만 블러+어둡게(글자 가독성).
3. **얼굴은 글자와 절대 겹치지 않는다.** 얼굴은 위·아래 글자 사이 가운데 띠 안에 통째로. 너무 큰 클로즈업(눈만 보임)도, 너무 작은 얼굴도 금지 — 띠 높이의 40~80%.
4. 레이어 4~6개: 배경 사진 + 인셋 2장(하늘색/흰색/빨강 테두리) + 국기·VS + 말풍선 (?!!)·(헐...)·(....)·똑똑히 보세요 + 빨간 화살표·노란 동그라미 + 빨간 태그 "해외 반응".
5. **인셋 얼굴은 칸 정중앙.** 한쪽으로 쏠리면 안 된다. 얼굴이 원본 가장자리에 있으면 더 클로즈업(fh 키움)해서라도 가운데로. 사람 한 명을 쓸 때는 그 사람 **얼굴만**(어깨 위) 보이게.
6. **국기는 동그란 배지**(흰 테+검정 외곽선). 인셋 테두리와 최소 30px 띄운다. 흰 사각형이 보이면 원본에 박힌 스티커·자막인지 먼저 확인해 잘라낸다(`clip`).
7. 원형 인셋 OK(네모만 고집하지 않는다). 원형 + 뒤에 불꽃 아치 = "사람 뒤에서 불 나오는" 효과.
8. 디자인 요소(`디자인요소썸네일자막_로고` 폴더 맨 위 파일만, `xxxx` 하위 폴더는 쓰지 않음): 황금 불꽃 아치(원 뒤), 사실적 불꽃 띠(아래 글자 뒤), 번개(VS 분할선), 불꽃 줄기(VS 분할선), NO!!·노우(거절·반대 문맥일 때만), ㅋㅋ(웃음 문맥).
9. 놀란 표정을 새로 만들어 넣지 않는다(실존 인물 표정 조작 금지). 영상 속 실제 놀람·소리침 프레임을 찾아 쓴다.
10. 로고(K PRIDE 등)·원본 스티커·박힌 자막·모자이크·화면 맨 위 색 줄(초록·하늘색 오버레이)이 보이면 `clip`/`cb`로 잘라낸다. 잘린 스티커 조각이 남으면 안 된다.
12. **흰 동그라미 테두리 금지** — 원형 인셋 테두리는 빨강 또는 노랑만.
13. **불꽃은 끊기지 않게**: 원 뒤 불꽃 아치는 화면 맨 아래까지 늘려 아래 불꽃 띠와 이어지게. 사람 몸이 아래까지 보이는 사진이면 몸까지 보이게 당기고 양옆에서 솟는 불꽃(만화 불꽃 프레임)을 쓴다.
14. VS 나라 라벨은 상자·테두리 없이: 동그란 국기 + NO!! 스티커 색 그라데이션(노랑 #F9DF00 → 주황 #FC8701 → 빨강 #FD0C01) 글자 + 검정 외곽선.
15. 군중 사진에는 빨간 동그라미 + 노랑 ? 로 궁금증. 놀란 얼굴 옆에는 ?! .
16. 저해상도 원본은 확대 시 자동 선명화(compose4 sharp). 원본 자체가 480p 이하면 AI 업스케일(Real-ESRGAN, 미설치) 필요.
11. 사진 우선순위: 놀람 2 > 소리침·충격·눈물·경악·공포 > 깔깔 웃음 / 인파(우르르 군중) / 서양인·흑인·아나운서·기자·뉴스 화면. 영상 박힌 자막은 잘라낸다(배경 아래 13%, 인셋 20%).

## 3. 스타일 (한 영상당 3장: A 또는 기존 + B 번개 VS 분할 + C 불꽃 원형 충격)
- **A 뉴스 3줄형**(조회수 상위 다수, 79만~162만): 위 2~3줄(첫 줄 흰 “인용”, 나머지 노랑) + 가운데 사진 띠(인셋 2·국기·화살표) + 아래 1줄 하늘색(질문·이유). 글자가 화면 55%.
- **B 리액션 인셋형**: 위 2줄 + 큰 현장 사진(군중·제품) 위에 반응 얼굴 인셋 2장, 아래 “인용…” 하늘색.
- **C 임팩트 2줄형**: 사진 한 장 크게 + 아래 2줄 아주 크게(흰 “인용” + 노랑 이유..), 원형 인셋 1개, 왼쪽 위 빨간 태그.
- **B′ 번개 VS 세로 분할형(신규)**: 화면 반반. 왼쪽 🇰🇷 한국 / 오른쪽 상대국(중국·일본·미국·러시아·튀르키예…) 얼굴. 가운데 노란 번개 또는 불꽃 줄기 + 큰 노랑 VS(빨강·검정 외곽). 위 양끝에 국기+나라 이름 라벨(한국 파랑, 상대 빨강). 아래 2줄 흰 “인용” + 노랑 이유... 얼굴은 각 반쪽 가운데, 아래 글자 위.
- **C′ 불꽃 원형 충격형(신규)**: 큰 장면 사진 전체 + 오른쪽 위 원형 얼굴(지름 330, 놀람·소리침) 뒤에 황금 불꽃 아치 + 옆에 노랑 ?! + 왼쪽 위 빨간 "해외 반응" + 아래 불꽃 띠 위 2줄(흰 “인용” + 하늘색 이유..). 거절·반대 문맥이면 NO!! 스티커.

## 4. 글씨
- 폰트: 여기어때 잘난체 2만. 검정 외곽선 = 글자 크기의 1/8 + 오른쪽 아래 그림자.
- 색: 노랑 #FFE51F · 흰 #FFFFFF · 하늘 #3DE6FF · 분홍 #FF6FB0 · 빨강 태그 #E8132B · 노란 동그라미 #FFE51F · 빨간 화살표 #FF2020.
- 크기: 위 줄 84~104px(3줄이면 84), 아래 줄 86px, C형 아래 118~150px. 한 줄 최대 폭 = 화면 − 36px(넘으면 자동 축소).

## 5. 만드는 법
`python3 compose4.py spec.json 출력.jpg` (spec 예: `시범10_V3.1/05_b.json`). 얼굴은 `face:[가로,세로,얼굴높이]`(원본 기준 0~1)로 주면 칸 정중앙에 자동 배치(`fh` 칸 대비 얼굴 크기, `tx`/`fy` 위치). 원본 일부만 쓰려면 `clip:[x0,y0,x1,y1]`. 만든 뒤 반드시 직접 열어 얼굴·글자 겹침, 뒤집힌 글씨, 옛 자막·로고 노출을 확인하고 고친다.
