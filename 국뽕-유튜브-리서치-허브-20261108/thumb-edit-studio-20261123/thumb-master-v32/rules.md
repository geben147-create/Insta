## 2. 국가·출력 언어 및 자료 통합
TARGET_COUNTRY=KR 또는 JP, OUTPUT_LANGUAGE=ko 또는 ja. 두 변수는 독립: 한국어로 일본 칭찬 등도 명시 요청 시 지원.
KR/ko: 한국 + 실제 반응 주체(중국인/일본인/외국인 등) + 제목에 해외 반응, 이미지 태그는 해외 반응만.
JP/ja: 日本 + 실제 반응 주체(外国人/韓国人/中国人 등) + 제목/태그 海外の反応. 일본어로 자연스럽게 현지화하고 숫자 단위도 일본어(4千、45万 등). 일본 칭찬이 목표여도 실제 비교와 반응의 범위는 그대로 유지한다. 발언자의 국적을 외모로 추정하지 않는다.
일본 자료는 기존 jp 갤러리, japan-reactions(중국 반응/글로벌 반응/스포츠), japan-social, korea-japan, 한일 비교 기존 제작본을 링크로 연결한다. 중복 수집은 플랫폼·영상 ID·원본 URL·타임코드·언어로 식별하여 하나의 출처 카드로 연결. 서로 다른 발언·판본·번역을 덮어쓰지 않는다. 일본 자료 전체 내용/중복 전수 검증 및 통합은 이 커밋 범위 밖.

## 3. 제목과 썸네일 문구 (필수)
1. 제목 4개, 썸네일 문구 4개를 1:1로 A/B/C/D 매핑. 제목과 썸네일 안 문구는 별도 필드다. 좋은 제목의 핵심 훅을 짧게 썸네일로 가져오되 그대로 반복할 필요는 없다.
2. 사용자 말투 우선: 이유 / 상황 / ? / .. / ... / 결국.. / 왜 ~처럼 못하나 / 넋 나간 이유 / 발칵 / 대반전 상황. 답을 바로 말하지 않고 핵심 질문을 남긴다.
3. 국가·반응 주체는 정확히 표기. 중국 외국인들/중국인 외국인/외국인 해외 반응 같은 중복 조합 금지. 한국/日本은 제목과 썸네일의 본문 또는 실제 국가 라벨에서 명시. 제목에는 정확한 반응 주체, 해외 반응(ja=海外の反応), 이모지 1개 이상. 리액션은 선택. 이미지의 빨간 태그는 해외 반응/海外の反応만. 텍스트 본문에 태그 표현 중복 금지.
4. 대박·경악·충격·놀람·논란·오열·난리·대폭발·대반전·발칵·망연자실·백기·뒤집힌 등은 원본에 근거한 강도로 1개 선택. "싹 다 쓸어갔다", "망쳐놨다", "무너졌다", "참교육"은 실제 범위가 뒷받침될 때만. 몇 명의 반응을 전 국민/전 세계의 반응으로 확대하지 않는다. 사실이 부족하면 강도를 낮추고 사용자 문체를 유지한다. 국가/국민 일반화·비하 금지.
5. 실제 발언만 큰따옴표: 원문·화자·번역·출처·타임코드 기록. 확인 전 인용은 따옴표 없이 임시 요약 또는 검수 보류. 특히 07 페이커·12 커제는 기존 패키지에서 원음 대조 전으로 기록됨.
6. 숫자는 정확한 한글 단위(4000→4천, 450000→45만, 1600→1천6백, 4323→4천3백23), 원수치 보존·반올림 금지. 19점, 2점 등 작은 수치는 숫자 가능. 금액·날짜·순위·비교 기준 검증.
7. 네 가지 훅 방향(신규 제안): A 실제 한마디·뉴스형 / B 편견·비교·반전형 / C 현장·반응·숫자형 / D 이유·궁금증·감정형. 네 안은 어순만 바꾸지 말고 내용상 다른 각도. 동일 의미 반복 제거.
8. 레퍼런스는 아래 원문 TOP20·31행과 이전 패키지를 사용한다. 예시 문장을 사실로 간주하지 않으며 해당 영상과 일치하는 것만 채택. 일본 예시는 문형만 현지화.
9. 예시 문형(실제 주장 아님): KR 한국 [대상]에 [반응 주체] 놀란 이유.. / [기존 평가] 뒤 [현장]에서 벌어진 상황? / JP 日本の[対象]に[反応主体]が驚いた理由… / [当初の評価]から一転、[現場]で何が？. 과장·인용은 증거 있을 때만.

## 5. 네 가지 시안 (최종 스타일 구성은 개선안, 아직 렌더 미실행)
A 뉴스 3줄형: 위 흰 실제 인용/노랑 이슈, 중앙 현장·반응, 아래 하늘 이유. 기존 A(또는 적절한 B/C)를 개선.
B 불꽃/번개 VS형: 실제 비교일 때만 반반 분할, 서로 보는 인물·원형 국기·노랑 VS. 비교가 없으면 현장+반응 2인셋형으로 대체.
C 불꽃 원형 충격형: 큰 현장+중앙 정렬 원형 반응 얼굴(빨강/노랑)+위 아치·별도 하단 불꽃 띠+?!. 태그와 글자 겹침 없음.
D 신규 품질형: 기존 임팩트 2줄/리액션 인셋형을 활용하여 가장 강한 실제 고화질 장면을 크게, 흰+노랑 또는 하늘 2줄, 효과 최소화. A/B/C와 다른 주피사체·훅을 선택해 모바일 가독성을 확보. V3.1 "새 디자인 없음" 제한은 재현 패키지에만 적용, V3.2 품질 개선을 막지 않는다.
4안은 실제 영상에 맞춰 재구성 가능하나 네 가지 시안이 의미상 달라야 한다.
