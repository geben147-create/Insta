✍ 썸네일 문구 규칙

  1. 🏆 잘 만든 제목을 그대로 썸네일 문구로 쓴다.
  2. ❓ 답을 바로 말하지 않는다 — ✗ 한국인이 좋아한 건 라면이었다 → ✓ 한국 라면에 외국인들 난리난 상황..
  3. 🔚 끝은 이유 · 상황 · ? · .. · ... 로 끊어 궁금하게.
  4. 🇰🇷 필수 단어: 한국 + 외국인(들), 해외 반응은 문구나 빨간 태그에.
  5. 💥 강조어(근거에 맞는 것 하나): 대박·경악·충격·놀람·논란·오열·난리·대폭발·대반전·발칵·망연자실.
  6. 🔢 숫자는 한글 단위: 4000 → 4천, 450000 → 45만. 반올림 금지.
  7. 🗨 “큰따옴표”는 영상 속 실제 발언만. 인용·인원·수치·반응 강도는 영상에서 확인한 범위만.
📋 규칙 원문 (복사용)
제목·썸네일 문구에 ‘외국인’ 또는 ‘외국인들’과 ‘해외 반응’을 넣는다. ‘리액션’은 선택. 대박·경악·충격·놀람·논란·오열·난리·대폭발·대반전 중 근거에 맞는 표현을 고른다.
비교·현장형은 ‘한국처럼 못하나’, ‘삼성으로 몰려가는 외국인’, ‘유럽인들 발칵’, ‘경악한 미국’, ‘무섭다’, ‘싹 다 쓸어갔다·망쳐놨다·무너졌다’처럼 비교 대상과 장면을 앞에 둔다.
국가 반응형은 ‘중국인 반응’, ‘일본은 경악’, ‘일본이 망연자실한 이유’, ‘중일 크게 당황’처럼 실제 반응 주체를 적는다. 인용·인원·반응 강도는 영상에서 확인한다.
참교육형: 한국 깎아내리던 외국인 / 한국보다 일본이 좋다던 외국인 + 참교육.
답을 바로 말하지 않는다: ‘~난리난 이유’, ‘~심각한 상황’, ‘~부르는 이유’, ‘왜 한국처럼 못하나?’, “맵다! 근데...”처럼 이유·상황·?·..·...로 끊는다.
숫자는 한글 단위: 4000 → 4천, 450000 → 45만, 1600 → 1천6백. 4000·323처럼 숫자로 적지 않고 반올림하지 않는다.
“큰따옴표”는 영상 속 실제 발언만. 제목에는 이모지(🔥😱😭🇰🇷)를 항상 넣는다.

🖼 화면 구성 — 꽉 차게

  1. 🧱 레이어 4~6개: 배경 사진 + 인셋 2장(하늘색·흰·빨강 테두리) + 국기·VS + 말풍선 (?!!)·(헐...)·(....)·똑똑히 보세요 + 빨간 화살표·노란 동그라미 + 빨간 태그 “해외 반응”.
  2. 🌄 배경은 화면 끝까지. 사진이 짧으면 같은 사진을 흐리게·어둡게 키워 뒤를 채운다.
  3. 🌫 글자 뒤가 복잡하면 그 띠만 블러 + 어둡게.
  4. 🙂 얼굴은 글자와 절대 겹치지 않는다. 얼굴은 위·아래 글자 사이 가운데 띠 안에 통째로. 눈만 보이는 과한 클로즈업·너무 작은 얼굴 금지 — 띠 높이의 40~80%.
  5. 📸 사진 우선순위: 놀람 2 › 소리침·충격·눈물·경악·공포 › 깔깔 웃음 / 우르르 인파 / 서양인·흑인·아나운서·기자·뉴스 화면. 영상에 박힌 자막은 잘라낸다.
  6. 🔤 폰트: 여기어때 잘난체 2만. 검정 외곽선 = 글자 크기 1/8 + 그림자. 색 노랑 #FFE51F · 흰 #FFFFFF · 하늘 #3DE6FF · 태그 빨강 #E8132B.

🎨 스타일 3종 (좋썸넬 분석)

A 뉴스 3줄형
위 2~3줄(첫 줄 흰 “인용”, 나머지 노랑) + 가운데 사진 띠(인셋 2·국기·화살표) + 아래 1줄 하늘색 질문·이유. 조회수 상위 다수.
B 리액션 인셋형
위 2줄 + 큰 현장 사진(군중·제품) 위에 반응 얼굴 인셋 2장 + 아래 “인용…”.
C 임팩트 2줄형
사진 한 장 크게 + 아래 2줄 아주 크게(흰 “인용” + 노랑 이유..) + 원형 인셋 1개 + 빨간 태그.
