# 사용·게시 기록 방식 비교 (by Claude Code · Opus, 2026-11-16)

원본을 다시 쓰지 않게 막고, 결과 폴더·이 페이지·채널 계정이 서로 같은 값을 보이게 하는 방법 3가지입니다.

| | ① 중앙 원장 + 자동 생성 (채택) | ② 구글 시트를 원본으로 | ③ 폴더마다 기록 파일이 원본 |
|---|---|---|---|
| 원본 위치 | GitHub `usage/게시기록.tsv` 하나 + 각 영상 `cut-list.csv` | 한국·일본 구글 시트에 열 추가 | 영상 결과 폴더의 `_사용기록` 파일 |
| 사용 구간(초) | cut-list에서 자동 추출, 사람 입력 0 | 손으로 옮겨 적어야 함 | 자동 추출 가능 |
| 게시 기록 | 한 파일에 한 줄씩 (채널·계정·URL) | 시트에서 바로 수정, 휴대폰 편함 | 33개 폴더를 하나씩 열어 수정 |
| 결과 폴더와 일치 | 빌더가 폴더에 `_사용기록.md` 다시 씀 | 수동 동기화, 어긋나기 쉬움 | 폴더 자체가 원본 |
| 이 페이지와 일치 | `usage.json` 자동 → ❌/🟡/🔵 표시 | 시트 내보내기 단계 필요 | 모아 주는 스크립트 필요 |
| 변경 이력 | git 커밋으로 남음 | 시트 버전 기록 (찾기 불편) | 없음 (덮어쓰면 끝) |
| Claude 자동화 | 지금 바로 가능 | 시트 쓰기 권한 연결 필요 | 가능하나 여기저기 흩어짐 |
| 단점 | 게시 기록은 TSV 한 줄 고치기(또는 Claude에게 말하기) | 이중 관리 | 전체 조회가 느리고 누락 생김 |

**채택: ①** — 사람이 고치는 곳은 `usage/게시기록.tsv` 한 곳뿐이고, 나머지는 `python3 -I usage/build_usage.py` 한 번으로 모두 다시 만들어집니다. 구글 시트는 나중에 이 원장을 그대로 붙여 넣는 "보기용"으로만 씁니다.

## 표시 규칙

| 표시 | 뜻 |
|---|---|
| ❌ EP코드 | 이미 영상에 쓴 원본·주제 (다시 고르지 않기). 빨간 X |

## 게시했을 때 할 일
`usage/게시기록.tsv`에서 해당 `영상코드` 줄의 `게시상태`를 `게시`로, `채널`·`계정`·`게시일`·`URL`을 채운 뒤 빌더를 실행하고 커밋합니다. (Claude에게 "EP02_옥탑방 유튜브 ○○채널에 게시했어"라고 말하면 같은 일을 합니다.)

## 파일 연결
- 영상 결과 폴더: `/run/media/yh/새 볼륨/_국뽕영상결과물/<영상코드>/_사용기록.md` · `_사용기록.tsv`, 맨 위 `_제작영상_원장.tsv`
