# ASIDE | 세계 방송국이 본 {대상국가} — 최근 1년 칭찬·감탄 보도 대규모 수집

너는 리서치 총괄이다. 세계 각국 공영·민영 방송국(TV·라디오·뉴스 채널)이 {대상국가}를 칭찬·감탄·벤치마킹·놀라움으로 다룬 뉴스·다큐·특집·클립을 최근 12개월 기준으로 찾는다. 목표: 100개국 이상, 방송국 200곳 이상 조사, 후보 1,000건 이상, 직접 열어 확인 300건 이상.

## 0. 실행 방식
- 검색·판단은 Opus 작업자, 번역·자막·시트 입력은 Sonnet/Haiku 작업자. 지역별로 나눠 2~3명씩 병렬, 끊기면 저장 파일에서 이어서. 10건마다 TSV 저장.
- CAPTCHA·로그인·유료벽 우회 금지(유료벽은 '유료벽'으로 표시). 영상 다운로드는 사용자가 허락한 것만.

## 1. 방송국 목록부터 만들기 (먼저 보고)
대륙별로 국가 대표 방송국을 표로 만든다: 국가, 방송국명(현지어), 유형(공영/민영/뉴스채널), 웹사이트, 유튜브 공식 채널, 검색 방법.
예시(최소 이 정도부터): 프랑스 France 2·France 24·TF1·Arte / 독일 ARD·ZDF·DW / 영국 BBC·Sky·ITV·Channel 4 / 스페인 RTVE·Antena 3 / 이탈리아 RAI·Mediaset / 스위스 SRF·RTS / 스웨덴 SVT / 노르웨이 NRK / 덴마크 DR / 핀란드 Yle / 네덜란드 NOS / 벨기에 RTBF·VRT / 폴란드 TVP / 체코 ČT / 터키 TRT·NTV·CNN Türk / 러시아 Russia-1·RT·NTV / 우크라이나 Suspilne / 미국 CNN·NBC·ABC·CBS·PBS·Fox / 캐나다 CBC / 멕시코 Televisa / 브라질 Globo·Record / 아르헨티나 TN·Telefe / 칠레 TVN / 콜롬비아 Caracol / 인도 NDTV·Aaj Tak·WION / 파키스탄 Geo / 방글라데시 BTV / 인도네시아 Kompas TV·Metro TV / 베트남 VTV / 태국 Thai PBS·Channel 3 / 필리핀 GMA·ABS-CBN / 말레이시아 Astro Awani / 싱가포르 CNA / 일본 NHK·TBS·Fuji / 중국 CCTV·CGTN·凤凰卫视 / 대만 TVBS·公視 / 홍콩 TVB / 중동 Al Jazeera·Al Arabiya·Gulf TV / 이집트 / 사우디 / 이란 / 이스라엘 / 아프리카 SABC·NTA·KTN / 호주 ABC·SBS·Nine / 뉴질랜드 TVNZ 등. 더 찾아서 200곳 이상으로 늘린다.

## 2. 검색 방법
- 각 방송국 사이트 검색 + 공식 유튜브 채널 검색 + 현지어 키워드("Corée du Sud", "Südkorea", "Güney Kore", "Coreia do Sul", "Южная Корея", "Hàn Quốc", "韓国" 등)와 주제어(기술, K-뷰티, 교육, 치안, 지하철, 반도체, K-팝, 드라마, 음식, 경제, 저출산 대책, 의료, 서울)를 조합.
- 기간: 최근 12개월 우선, 큰 화제작은 1~3년도 별도 표시.

## 3. 분류 (세부분류별 최신순)
기술·반도체·로봇·AI / 경제·기업(삼성·현대 등) / K-팝·연예인·해외 팬 함성 / 드라마·영화·예능·OTT / 뷰티·화장품·피부과 / 여행·도시·교통·치안·청결 / 음식·편의점 / 교육·사회 제도 / 의료 / 스포츠 / 방산·인프라 / 전통문화 / 기타(신규 분야)
반응유형: 칭찬 / 감탄·놀라움 / 벤치마킹(우리도 배우자) / 비교 / 비판(참고용).

## 4. 수집 항목 (실제 표시값만, 없으면 공란)
조회수, 좋아요, 댓글, 방송일, 기간(6개월), 국가, 방송국, 프로그램명, 카테고리, 세부분류, 제목 한국어, ▶바로가기 링크, 반응유형, 핵심 발언 원문(앵커·기자·인터뷰이) + 한국어, 영상 길이, 1~3초 훅 구간(자막·대본 근거 있을 때만, 아니면 '영상 확인 필요'), 유튜브 공식 업로드 여부, 검증상태, ID(맨 끝).
유튜브 영상이면 상위 댓글 12개(좋아요 6 + 대댓글 6) 원문·한국어.
