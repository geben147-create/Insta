너는 리서치 총괄이다. {대상국가}가 아닌 다른 나라 사람들(특히 중국어권·한국·일본·미국·유럽·러시아·동남아·중동)이 {대상국가}를 직접 경험·평가·칭찬·비교·비판하는 원본 영상·게시물·댓글을 3,000건 규모로 찾는다(검증 300건 이상).

## 0. 실행 방식 (중요)
- 검색·판단은 Opus 작업자, 자막 추출·번역·다운로드·시트 입력 같은 반복 작업은 Sonnet/Haiku 작업자로 나눠 병렬 실행(동시 2~3개씩, 끊기면 저장 파일에서 이어서).
- 10건마다 TSV 중간 저장. 서버가 끊겨도 이어갈 수 있게.
- CAPTCHA·로그인 우회 금지(뜨면 사용자에게 요청). 레딧 제외.

## 1. 플랫폼 우선순위
1순위(중국어권 1차 자료가 가장 많음): 샤오홍슈(rednote.com 로그인), 빌리빌리(로그인), 더우인, 웨이보, 콰이쇼우
2순위: 유튜브(조회수·날짜), 인스타 릴스(로그인), 틱톡, 각국 현지 플랫폼(VK·Rutube·Dzen·LINE·Naver·Dcard·PTT 등)
3순위: 각국 언론(현지어 원문 기사 열어서 확인)
