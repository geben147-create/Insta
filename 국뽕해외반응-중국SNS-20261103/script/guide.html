📋 대본 형식 비교 · 사용법 by Hermes · Opus

아래 비교는 편집 도구(Premiere·DaVinci·CapCut·Vrew)의 일반적인 가져오기 방식에 대한 Hermes의 지식으로 정리했습니다. 이번 작업에서 웹 검색으로 새로 확인한 내용은 아닙니다.

① 영상 편집용 대본 형식 5가지

#형식장점단점쓰는 곳
1SRT (한국어 / 중국어)모든 편집기에서 바로 가져옴. 타임코드 그대로 자막 트랙태그·메모를 넣을 수 없음CapCut·Premiere·DaVinci 자막 트랙
2이중 SRT (중국어+한국어 2줄)원문과 번역을 한 화면에서 대조. "한중 이중자막" 영상에 그대로 사용화면에 글자가 많아 가독성이 떨어짐검수, 이중자막 영상
3대본 TSV/엑셀 (번호·시작·끝·중국어·한국어·태그)정렬·필터·메모 가능. 구글 시트와 바로 호환편집기에 직접 넣을 수 없음대본 작성, 장면 고르기
4장(챕터) 단락 대본 (이 페이지)읽기 쉬움. 형광펜·핵심 표시. 흐름 파악이 빠름파일로 편집기에 넣을 수 없음나레이션 대본 짜기, 훅 찾기
5JSON 원본 (모든 정보)다른 형식을 모두 다시 만들 수 있는 원본. 자동화에 적합사람이 읽기 어려움재가공, 자동 편집

✅ 채택: JSON 한 벌을 원본으로 두고, 나머지 4가지 형식을 자동으로 만듭니다. 영상마다 한국어 SRT, 중국어 SRT, 이중 SRT, TSV를 내려받을 수 있습니다. 편집할 때는 한국어 SRT를 쓰고, 대본을 짤 때는 이 페이지와 TSV를 씁니다.

② 긴 대본을 페이지에 넣는 방법 3가지

방법장점단점
A. 한 페이지에 전부 나열Ctrl+F로 전체 검색. 구현이 단순함영상 10개 × 수백 줄이면 너무 길고 느림. 어디까지 읽었는지 잃어버림
B. 영상별 아코디언(접기/펼치기)한 페이지 안에서 깔끔함펼치면 결국 길어짐. 처음부터 전부 불러와서 무거움
C. 왼쪽 하위 메뉴 + 영상별 지연 로딩 + 장(챕터) 접기클릭한 영상만 불러와서 빠름. 분야별 색깔 메뉴. 챕터로 바로 이동. 링크(#BILI-112@줄번호) 공유 가능영상 간 통합 검색은 구글 시트에서 해야 함

✅ 채택: C. 분야별 배경색은 여행=와인 쇼핑=딥그린 게임/PC방=블랙 음식=브라운 가전 등입니다. 영상 사이의 통합 검색은 구글 시트 탭에서 합니다.

③ 표시 규칙

  • 노란 형광펜: 한국 평가 문장입니다. 👍는 좋다, 👎는 나쁘다, ⚖는 중국·일본과의 비교입니다.
  • 빨간 글씨: 대본에 꼭 쓸 핵심 정보, 반전, 결론입니다.
  • 타임코드를 클릭하면 "타임코드 + 한국어"가 복사됩니다. 편집기에서 그 지점을 찾을 때 씁니다.
  • "표시된 문장만 보기"를 켜면 형광펜과 핵심 문장만 남습니다. 대본 뼈대를 빠르게 잡을 때 씁니다.

  • 태그(좋음/나쁨/핵심)도 AI 판단이라 틀릴 수 있습니다.
