3. 편집 기법 (전문 용어 해설)

  • 락오프 연속 이어붙이기 (Locked-off chaining) — 카메라가 같은 자리에 누워 있으니 각 AI 클립의 마지막 프레임을 다음 클립의 첫 프레임으로 써서 이으면 점프컷이 거의 안 보임
  • 더치 90° 트릭 — 16:9 가로로 생성 → transpose=1로 90° 회전 → 9:16. 1위 영상과 동일
  • 카메라 넘어짐 전환 (Knock-over) — 4.0~4.6s 카메라가 바람/충격에 기울며 넘어짐 = 장면 전환 겸 긴장 폭발

  • 실루엣 엔딩 (Silhouette out) — 하얀 하늘을 배경으로 한 드래곤 배 쪽 실루엣으로 끝

ffmpeg -y -nostdin -i shots/s06.mp4 -t 4.20 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s06.mp4   # 21.80~26.00s EWS (하늘)

rm -f list.txt; for f in cut/s*.mp4; do echo "file '$f'" >> list.txt; done
ffmpeg -y -nostdin -f concat -safe 0 -i list.txt -c copy assembled.mp4

# ---- 3) 룩(색보정·필름 입자·할레이션·비네팅) ----
ffmpeg -y -nostdin -i assembled.mp4 -filter_complex "[0:v]eq=contrast=1.02:saturation=0.93,unsharp=5:5:0.35,noise=alls=4:allf=t[v]" -map "[v]" -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p graded.mp4

# ---- 3-2) (선택) 폰 낙하 전환을 AI 대신 합성할 때: 전환 직전 1.2초를 90° 회전+모션블러 ----
ffmpeg -y -nostdin -i cut/s_fall_src.mp4 -vf "rotate='min(t/0.8,1)*PI/2':ow=hypot(iw,ih):oh=ow:c=black,tmix=frames=6:weights='1 1 1 1 1 1',scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" -t 1.2 -an cut/s_fall.mp4

# ---- 4) 사운드: BGM + 효과음 타이밍 + (대사) + 덕킹 + 라우드니스 -14 LUFS ----
