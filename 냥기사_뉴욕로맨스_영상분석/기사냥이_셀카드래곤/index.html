1. 훅 & 떡상 공식

🎣 0초부터 '기사 갑옷 입은 아기고양이가 셀카로 밀크티 마시는' 비현실 조합. 첫 프레임에서 이미 스크롤이 멈춤

  1. ① 0~3.6s 일상 셀카 (귀여움 + 평화) → 시청자 긴장 0
  2. ② 3.6s 컵 휙 던짐 = '뭔가 온다' 신호 (행동으로 복선)
  3. ③ 5.4s 폰이 풀밭에 떨어지며 화면 90° 회전 = 편집 없는 전환(인카메라 트랜지션)
  4. ④ 7.2s~ 누워있는 폰 시점: 작은 고양이 vs 거대 드래곤 — 스케일 대비가 곧 펀치라인
  5. ⑤ 13s 드래곤 입 벌림에서 뚝 끝 → 결말 궁금 → pt.2(3위 영상)로 연결 + 반복재생

왜 터졌나

  • 크기 대비(스케일 갭): 손바닥만 한 고양이 vs 화면을 채우는 드래곤. 썸네일 한 장으로 설명 끝
  • POV 파운드푸티지: '진짜 폰으로 찍힌 것 같은' 셀카 → 떨어진 폰. AI 티를 오히려 현실감으로 덮음
  • 15초 짧은 길이 + 클리프행어 엔딩 → 완주율·재시청률 극대화
  • 대사 0, 자막 0 → 언어 장벽 없음 = 글로벌 확산

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점

프레임 간 화면 변화량(10fps 샘플). 뾰족한 봉우리 = 하드컷, 넓은 언덕 = 카메라 흔들림·모션블러 전환

3. 편집 기법 (전문 용어 해설)

  • 인카메라 트랜지션 (In-camera transition) — 컷 대신 '폰이 떨어지는 움직임' 자체로 장면을 바꿈. 5.4~7.2s 풀잎이 화면을 쓸고 지나가는 모션블러가 사실상 와이프 전환 역할
  • 더치 90° (Dutch angle 90°) — 땅에 누운 폰 시점. 16:9로 정상 생성한 영상을 FFmpeg transpose=1(시계방향 90°)로 돌려 9:16을 채움 → 제작 핵심 트릭
  • 셀카 POV + 전경 팔 (Foreground arm) — 왼쪽 하단 갑옷 팔이 화면을 가려 '들고 찍는' 증거가 됨. 광각 왜곡으로 얼굴 크게
  • 스케일 리빌 (Scale reveal) — 처음엔 고양이만 보여 주고, 전환 후에 드래곤 전체를 공개
  • 하드 엔딩 / 루프 (Hard out) — 포효 정점에서 페이드 없이 끊음 → 자동 반복 시 처음 셀카로 돌아가 대비 효과 재발생

4. 사운드 · 음악

BGM+SFX (가사 없음, Whisper 음성 미검출). 3.5s 컵 던짐 효과음 피크(-12.7dB), 5.6~6.4s 낙하 충돌음 연타, 13.1s 드래곤 포효 후 끝까지 -11dB 유지

# ===== 기사 아기고양이 셀카 → 폰 떨어짐 → 드래곤 등장 (🐱⚔🐉) — FFmpeg 재현 레시피 (총 15.25s, 샷 5개) =====
# 폴더 구조: shots/s01.mp4 … (AI로 생성한 원본 클립), audio/bgm.mp3, vo/dialogue.wav(대사 있을 때), sfx/sNN.wav
# 모든 명령은 창 없이 현재 셸에서 실행. 1080x1920 · 30fps · H.264 · yuv420p

# ---- 1) 샷별 정확한 길이로 자르기 + 규격 통일 (실측 컷 타이밍 그대로) ----

rm -f list.txt; for f in cut/s*.mp4; do echo "file '$f'" >> list.txt; done
