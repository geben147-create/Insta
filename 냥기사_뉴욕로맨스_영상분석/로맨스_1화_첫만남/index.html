1. 훅 & 떡상 공식

🎣 0~2.8초: 눈 내린 5번가, 책을 한가득 안은 여자와 남자가 부딪혀 책이 쏟아짐 = 로맨틱코미디의 고전 '미트 큐트' 공식을 2초 안에

  1. ① 0~2.8s 충돌 (미트 큐트)
  2. ② 2.8~8.9s 손이 닿는 인서트 → 남자 클로즈업 → 머리 넘기며 미소 (설렘 최고점)
  3. ③ 8.9~16.2s 가게에서 금발 여자친구 등장, 남자가 팔을 내어 줌 (급반전)
  4. ④ 16.2~25s 떠나는 커플을 보다가 책 사이 명함 발견
  5. ⑤ 25~27s 명함을 쓰레기통에 던지고 걸어감 = 자존심 엔딩 → 2화로

왜 터졌나

  • 누구나 아는 로코 공식 + 90년대 뉴욕 겨울 = 향수 자극
  • 명함 버리는 엔딩: '잘했다 vs 아깝다' 댓글 논쟁
  • 2화 대사 'I threw your number away'로 이어지는 시리즈 설계 (떡밥 회수)
  • 대사 2줄뿐 — 행동만으로 스토리 전달

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점

프레임 간 화면 변화량(10fps 샘플). 뾰족한 봉우리 = 하드컷, 넓은 언덕 = 카메라 흔들림·모션블러 전환

3. 편집 기법 (전문 용어 해설)

  • 숏-리버스숏 (Shot / reverse shot) — 두 사람 대화를 A 얼굴 → B 얼굴로 번갈아 보여 줌. 180도 규칙(카메라가 두 사람을 잇는 선을 넘지 않음)을 지켜 시선 방향이 일관됨
  • 리액션 샷 우선 (Reaction-first cutting) — 말하는 사람보다 '듣는 사람의 표정'에 더 오래 머묾 → 감정 전달
  • 인서트 (Insert) — 손, 카드, 컵 같은 소품 클로즈업을 1초 안팎으로 끼워 넣어 스토리 정보를 줌
  • 90년대 필름 룩 (Period look) — 35mm 입자, 따뜻한 텅스텐 조명, 버건디·크림·샴페인 색 배합. 로맨스 영화 한 장면처럼 보이게 함
  • 에피소드형 클리프행어 (Serial cliffhanger) — 마지막 샷에 반전 정보를 던지고 끝 → 'PART N 페이지에서 보기' 캡션으로 프로필 방문 유도
  • 미트 큐트 (Meet-cute) — 우연한 충돌로 두 주인공이 만나는 로맨스 장르 공식
  • 자연 와이프 (Natural wipe) — 8.75s, 10.75s 행인이 카메라 앞을 지나가며 화면을 가림 → 롱테이크 안에서 리듬 생성, AI 클립 이음새도 숨김
  • POV 리빌 인서트 — 20.2~25s 그녀 얼굴 아래에 명함이 올라옴 — 한 프레임에 얼굴+정보
  • 뒷모습 엔딩 (Walk-away ending) — 카메라에서 멀어지는 뒷모습 + 원경의 커플 = 두 갈래 길

4. 사운드 · 음악

음원명 메타데이터 없음. 대사: "Oh, I'm so sorry. I'm, um..." / "David?" (Whisper)

FFmpeg 명령
# ===== ACROSS THE STREET — Episode 1 (5번가 충돌, 명함을 버리다) — FFmpeg 재현 레시피 (총 27.24s, 샷 8개) =====
# 폴더 구조: shots/s01.mp4 … (AI로 생성한 원본 클립), audio/bgm.mp3, vo/dialogue.wav(대사 있을 때), sfx/sNN.wav
# 모든 명령은 창 없이 현재 셸에서 실행. 1080x1920 · 30fps · H.264 · yuv420p

# ---- 1) 샷별 정확한 길이로 자르기 + 규격 통일 (실측 컷 타이밍 그대로) ----
mkdir -p cut
ffmpeg -y -nostdin -i shots/s01.mp4 -t 2.80 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s01.mp4   # 0.00~2.80s MS 워킹
ffmpeg -y -nostdin -i shots/s02.mp4 -t 1.50 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s02.mp4   # 2.80~4.30s 인서트
ffmpeg -y -nostdin -i shots/s03.mp4 -t 1.30 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s03.mp4   # 4.30~5.60s CU
ffmpeg -y -nostdin -i shots/s04.mp4 -t 3.30 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s04.mp4   # 5.60~8.90s 2S
ffmpeg -y -nostdin -i shots/s05.mp4 -t 7.30 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s05.mp4   # 8.90~16.20s WS 롱테이크
ffmpeg -y -nostdin -i shots/s06.mp4 -t 4.00 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s06.mp4   # 16.20~20.20s OTS 뒷모습
ffmpeg -y -nostdin -i shots/s07.mp4 -t 4.80 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s07.mp4   # 20.20~25.00s CU + 명함
ffmpeg -y -nostdin -i shots/s08.mp4 -t 2.00 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s08.mp4   # 25.00~27.00s WS 뒷모습

# ---- 2) 하드컷으로 이어 붙이기 (원본 전환은 거의 전부 하드컷) ----
rm -f list.txt; for f in cut/s*.mp4; do echo "file '$f'" >> list.txt; done
ffmpeg -y -nostdin -f concat -safe 0 -i list.txt -c copy assembled.mp4

# ---- 3) 룩(색보정·필름 입자·할레이션·비네팅) ----
ffmpeg -y -nostdin -i assembled.mp4 -filter_complex "[0:v]colorbalance=rs=0.05:gs=0.01:bs=-0.05:rm=0.03:bm=-0.03,eq=contrast=1.04:saturation=0.88:gamma=0.98,curves=all='0/0.035 0.25/0.24 0.75/0.77 1/0.97',split[base][glow];[glow]curves=all='0/0 0.72/0 1/1',gblur=sigma=18,colorchannelmixer=rr=1:gg=0.35:bb=0.2[hal];[base][hal]blend=all_mode=screen:all_opacity=0.22,noise=alls=9:allf=t+u,vignette=angle=PI/5[v]" -map "[v]" -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p graded.mp4

# ---- 4) 사운드: BGM + 효과음 타이밍 + (대사) + 덕킹 + 라우드니스 -14 LUFS ----
ffmpeg -y -nostdin -i graded.mp4 -i audio/bgm.mp3 -i vo/dialogue.wav -i sfx/s01.wav -i sfx/s02.wav -i sfx/s05.wav -i sfx/s08.wav -filter_complex "[1:a]atrim=0:27.24,afade=t=in:d=0.3,afade=t=out:st=26.44:d=0.8,volume=0.8[bgm];[2:a]asplit[vo][key];[bgm][key]sidechaincompress=threshold=0.03:ratio=8:attack=20:release=300[bgmd];[3:a]adelay=0|0,volume=0.9[x1];[4:a]adelay=2800|2800,volume=0.9[x2];[5:a]adelay=8900|8900,volume=0.9[x5];[6:a]adelay=25000|25000,volume=0.9[x8];[bgmd][vo][x1][x2][x5][x8]amix=inputs=6:normalize=0,loudnorm=I=-14:TP=-1.5:LRA=11[aout]" -map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k -shortest final.mp4
#   효과음 목록(샷 시작 시각 기준): s01@0.00s 거리 소음, 책 떨어지는 쿵 | s02@2.80s 음악 강조음 | s05@8.90s 문 종소리, 행인 | s08@25.00s 종이 툭

# ---- 5) (선택) 자막 번인 — dreamfall 스타일(흰 산세리프, 화면 높이 82% 지점, 은은한 그림자) ----
