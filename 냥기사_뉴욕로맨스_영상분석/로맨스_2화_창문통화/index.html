1. 훅 & 떡상 공식

🎣 0~1초: 센트럴파크 단풍이 보이는 창가에서 수건 차림으로 머리를 빗는 뒷모습 → 1~3초 정면에서 '헉' 놀라는 얼굴. 무엇을 봤는지 궁금하게 만듦

  1. ① 0~3.2s 사적인 순간 + 충격 리액션 (무엇을 봤지?)
  2. ② 3.2~11.8s 창 너머 남자 공개 → 숨기/훔쳐보기 핑퐁 (리어 윈도우식 관음 구도)
  3. ③ 13.3~27.5s 전화벨 → 창문 사이 통화 (대사 핑퐁)
  4. ④ 28.9~34.8s 남자 뒤에 금발 여성 등장, 볼에 키스 = 반전 → 3화로 연결

왜 터졌나

  • 대사가 짧고 쉬운 영어라 자막 없이도 이해됨
  • 두 창문을 잇는 '길 건너' 공간 설정이 한 장면으로 이해됨 (23.6s 외부 설정 샷)
  • 평균 1.76초의 빠른 컷 = 90년대 영화 톤인데 속도는 릴스 속도
  • 마지막 3초 반전(다른 여자) → 댓글 논쟁 폭발 (댓글 1.4만)

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점

프레임 간 화면 변화량(10fps 샘플). 뾰족한 봉우리 = 하드컷, 넓은 언덕 = 카메라 흔들림·모션블러 전환

3. 편집 기법 (전문 용어 해설)

  • 숏-리버스숏 (Shot / reverse shot) — 두 사람 대화를 A 얼굴 → B 얼굴로 번갈아 보여 줌. 180도 규칙(카메라가 두 사람을 잇는 선을 넘지 않음)을 지켜 시선 방향이 일관됨
  • 리액션 샷 우선 (Reaction-first cutting) — 말하는 사람보다 '듣는 사람의 표정'에 더 오래 머묾 → 감정 전달
  • 인서트 (Insert) — 손, 카드, 컵 같은 소품 클로즈업을 1초 안팎으로 끼워 넣어 스토리 정보를 줌
  • 90년대 필름 룩 (Period look) — 35mm 입자, 따뜻한 텅스텐 조명, 버건디·크림·샴페인 색 배합. 로맨스 영화 한 장면처럼 보이게 함
  • 에피소드형 클리프행어 (Serial cliffhanger) — 마지막 샷에 반전 정보를 던지고 끝 → 'PART N 페이지에서 보기' 캡션으로 프로필 방문 유도
  • POV / OTS 창 너머 샷 — 그녀 머리를 전경에 걸치고 길 건너 창 속 남자를 보여 줌 → 두 사람의 물리적 거리 강조
  • 창틀 전경 프레이밍 (Frame within frame) — 남자와 여자 모두 창틀 막대가 화면 하단을 가로지름 = 유리를 사이에 둔 관계
  • 설정 샷 늦게 쓰기 (Late establishing shot) — 건물 외관은 23.6s에야 1초만 보여 줌. 감정을 먼저, 지리는 나중
