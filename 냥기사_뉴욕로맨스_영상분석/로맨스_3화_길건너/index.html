1. 훅 & 떡상 공식

🎣 0초: 센트럴파크가 보이는 방에서 수건 차림으로 버건디 드레스를 들고 고민 = '데이트 준비' 즉시 인식

  1. ① 0~12.5s 준비 몽타주 (수건 → 드레스 → 머리 올림 → 주얼리 뷰티샷)
  2. ② 12.5~19s 전신 공개 + 교차편집: 다른 방의 금발(복선)
  3. ③ 19~31.6s 호텔 앞: 길 건너 남자가 택시를 지나 달려옴 → 설렘
  4. ④ 31.6~41.3s 길 건너 친구가 벽돌폰으로 몰래 보고 통화 (10초 롱테이크)
  5. ⑤ 41.3~46.2s 전화 받는 금발 → 복도 → 문이 닫히며 암전 = 4화로

왜 터졌나

  • '준비 몽타주'는 릴스에서 검증된 포맷(GRWM)을 영화 톤으로 바꾼 것
  • 댓글 반응 핵심: '남자가 길을 건너 달려왔다' — 로맨틱 판타지 제공
  • 새 캐릭터(동양인 친구) 투입 = 시리즈 세계관 확장, 댓글 토론 유발
  • 문 닫힘 암전 = 확실한 에피소드 엔딩

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점 (연령 제한 영상이라 오디오 측정 불가)

3. 편집 기법 (전문 용어 해설)

  • 숏-리버스숏 (Shot / reverse shot) — 두 사람 대화를 A 얼굴 → B 얼굴로 번갈아 보여 줌. 180도 규칙(카메라가 두 사람을 잇는 선을 넘지 않음)을 지켜 시선 방향이 일관됨
  • 리액션 샷 우선 (Reaction-first cutting) — 말하는 사람보다 '듣는 사람의 표정'에 더 오래 머묾 → 감정 전달
  • 인서트 (Insert) — 손, 카드, 컵 같은 소품 클로즈업을 1초 안팎으로 끼워 넣어 스토리 정보를 줌
  • 90년대 필름 룩 (Period look) — 35mm 입자, 따뜻한 텅스텐 조명, 버건디·크림·샴페인 색 배합. 로맨스 영화 한 장면처럼 보이게 함
  • 에피소드형 클리프행어 (Serial cliffhanger) — 마지막 샷에 반전 정보를 던지고 끝 → 'PART N 페이지에서 보기' 캡션으로 프로필 방문 유도
  • 몽타주 점프컷 (Getting-ready montage) — 4.3~8.2s 소매·반지·목선을 0.3~1.4초 단위로 잘게 이어 붙임. 핸드헬드 디테일 샷
  • 교차 편집 (Cross-cutting) — 15.1s 다른 공간의 금발을 끼워 넣어 복선. 같은 시간 다른 장소
  • 전경 관찰자 롱테이크 (Observer foreground) — 31.6~41.3s 친구 옆얼굴 전경 + 원경 커플, 랙 포커스로 두 층을 오감
  • 문 닫힘 암전 (Door wipe to black) — 45.5~46.2s 문이 화면을 덮으며 검은 화면 = 자연스러운 와이프 전환
