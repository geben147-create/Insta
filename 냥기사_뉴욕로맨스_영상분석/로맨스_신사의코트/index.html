1. 훅 & 떡상 공식

🎣 0~1.5초: 택시 유리창에 도시 불빛이 흐르는 얼굴 클로즈업 — 뮤직비디오 같은 첫 장면, 공유 3.3만

  1. ① 0~4s 택시 → 하차 (유리 반사, 0.3초 급속 컷)
  2. ② 4~7.4s 사고: 차가 물웅덩이를 튀김 → 흰 코트에 흙탕물 → 기막힌 표정
  3. ③ 7.4~12.7s 리무진에서 내린 남자가 다가와 말을 검
  4. ④ 12.7~27.6s 그녀를 이끌고 부티크로, 그녀는 밖에서 기다림
  5. ⑤ 27.6~32.1s 유리창 너머 새 코트를 고르는 남자 → 그녀의 미소, 보케 (완결형 엔딩)

왜 터졌나

  • 공유 3.3만 = '나도 이런 남자' 판타지를 친구에게 보내는 공유형 콘텐츠
  • 시리즈 없이 한 편으로 완결 → 누구나 이해
  • 나쁜 일(흙탕물) → 구원(새 코트)의 감정 반전
  • 라운지 재즈 음악 + 90년대 룩 = 광고처럼 고급스러움

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점 (연령 제한 영상이라 오디오 측정 불가)

3. 편집 기법 (전문 용어 해설)

  • 숏-리버스숏 (Shot / reverse shot) — 두 사람 대화를 A 얼굴 → B 얼굴로 번갈아 보여 줌. 180도 규칙(카메라가 두 사람을 잇는 선을 넘지 않음)을 지켜 시선 방향이 일관됨
  • 리액션 샷 우선 (Reaction-first cutting) — 말하는 사람보다 '듣는 사람의 표정'에 더 오래 머묾 → 감정 전달
  • 인서트 (Insert) — 손, 카드, 컵 같은 소품 클로즈업을 1초 안팎으로 끼워 넣어 스토리 정보를 줌
  • 90년대 필름 룩 (Period look) — 35mm 입자, 따뜻한 텅스텐 조명, 버건디·크림·샴페인 색 배합. 로맨스 영화 한 장면처럼 보이게 함
  • 유리 레이어링 (Glass layering) — 택시 창, 부티크 쇼윈도, 빗방울 유리 — 반사·보케로 한 화면에 층을 겹침. 엔딩 샷의 하트 모양 보케가 감정 포인트
  • 스타카토 몽타주 (Staccato montage) — 2.7~4.0s 0.2~0.3초 컷 5개로 택시 하차를 쪼갬 → 음악 박자에 맞춘 리듬 편집
  • 원인-결과 인서트 (Cause & effect insert) — 물 튀김 와이드 → 얼굴 → 코트 얼룩 인서트 → 얼굴: 4컷으로 '사고'를 설명
  • 매치 온 액션 (Match on action) — 택시 문을 여는 동작을 여러 각도로 이어 붙여 움직임이 끊기지 않게
