1. 훅 & 떡상 공식

🎣 0초: 주황 고양이가 권총을 카메라에 겨누고 이를 드러냄 = 밈 포맷(고양이+총) 즉시 인식

  1. ① 0~2s 위협 (으르렁, 총구 정면) — 웃긴 밈처럼 시작
  2. ② 2~5s 감정 붕괴: 눈에 눈물이 차오르고 아랫입술 떨림
  3. ③ 5~6.5s 총을 천천히 내림(프레임 아래로 퇴장) = 포기
  4. ④ 6.5~10s 눈 감고 울음 참기 + 느린 푸시인 → 여운 남기고 끝 (자동 반복)

왜 터졌나

  • '웃긴 밈 → 슬픔'으로 뒤집히는 감정 반전이 10초 안에 완결
  • 공감 캡션('이별 후')이 댓글에서 자기 이야기를 꺼내게 만듦 → 댓글·공유 폭증
  • 컷 없는 단일 CU라 AI 생성 1회로 제작 가능 = 제작비 최소
  • 4:3 가로 원본이 오히려 '옛날 영화 한 장면' 느낌을 줌

2. 컷 타임라인 (실측)

색: 클로즈업 미디엄·OTS 와이드 인서트 · 아래 눈금 = 오디오 타격점

프레임 간 화면 변화량(10fps 샘플). 뾰족한 봉우리 = 하드컷, 넓은 언덕 = 카메라 흔들림·모션블러 전환

3. 편집 기법 (전문 용어 해설)

  • 원테이크 CU (Single-take close-up) — 편집 없이 연기만으로 감정 곡선을 만듦. 미세 표정 표현이 가장 좋은 모델을 써야 함
  • 슬로 푸시인 (Slow push-in) — 6초 이후 얼굴이 약 10% 커짐 = 감정 강조. FFmpeg zoompan으로 후반에 넣어도 됨
  • 얕은 심도 배경 (Shallow DOF) — 회색 실내가 완전히 흐림 → 얼굴과 총 두 요소만 남음
  • 오브젝트 퇴장 (Prop exit) — 총이 프레임 아래로 빠져나가는 것 = 대사 없이 '포기'를 전달
  • 음악 주도 편집 (Music-driven) — 효과음 없이 보컬곡 하나로 감정을 끌고 감

4. 사운드 · 음악

중국어 보컬 발라드 추정 (Whisper가 0~1s 구간에서 '真爱过' 인식). 음량 -15~-19dB로 일정 = 음악만 깔린 구조. 곡명은 확인 못 함

7. FFmpeg 편집 레시피

FFmpeg 명령
# ===== 이별 후 고양이 (Kitty after heartbreak) — 원테이크 감정 연기 — FFmpeg 재현 레시피 (총 10.03s, 샷 1개) =====
# 폴더 구조: shots/s01.mp4 … (AI로 생성한 원본 클립), audio/bgm.mp3, vo/dialogue.wav(대사 있을 때), sfx/sNN.wav
# 모든 명령은 창 없이 현재 셸에서 실행. 1080x1920 · 30fps · H.264 · yuv420p

# ---- 1) 샷별 정확한 길이로 자르기 + 규격 통일 (실측 컷 타이밍 그대로) ----
mkdir -p cut
ffmpeg -y -nostdin -i shots/s01.mp4 -t 10.03 -vf "split[bg][fg];[bg]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=40[bg2];[fg]scale=1080:-2[fg2];[bg2][fg2]overlay=(W-w)/2:(H-h)/2,fps=30,setsar=1" -an -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p cut/s01.mp4   # 0.00~10.03s CU 단일 테이크

# ---- 2) 하드컷으로 이어 붙이기 (원본 전환은 거의 전부 하드컷) ----
rm -f list.txt; for f in cut/s*.mp4; do echo "file '$f'" >> list.txt; done
ffmpeg -y -nostdin -f concat -safe 0 -i list.txt -c copy assembled.mp4

# ---- 3) 룩(색보정·필름 입자·할레이션·비네팅) ----
ffmpeg -y -nostdin -i assembled.mp4 -filter_complex "[0:v]eq=contrast=1.02:saturation=0.93,unsharp=5:5:0.35,noise=alls=4:allf=t[v]" -map "[v]" -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p graded.mp4

# ---- 3-1) 6.5초부터 느린 푸시인 (+12%) ----
ffmpeg -y -nostdin -i graded.mp4 -vf "zoompan=z='if(lte(on,195),1,min(1+(on-195)*0.0011,1.12))':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=1080x1920:fps=30" -c:v libx264 -crf 16 graded_push.mp4

# ---- 4) 사운드: BGM + 효과음 타이밍 + (대사) + 덕킹 + 라우드니스 -14 LUFS ----
ffmpeg -y -nostdin -i graded.mp4 -i audio/bgm.mp3 -filter_complex "[1:a]atrim=0:10.03,afade=t=in:d=0.3,afade=t=out:st=9.23:d=0.8,volume=0.8[bgm];[bgm]amix=inputs=1:normalize=0,loudnorm=I=-14:TP=-1.5:LRA=11[aout]" -map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k -shortest final.mp4
